# Seedance 2.5 Prompt 骨架（按任务类型）

T1–T9 是按任务裁剪的本地生产骨架，基于官方的素材指代、概述、情节和贯穿细节结构；编辑/转场不强填虚构镜头或起始画面。参数和真实素材记录见 `references/production-workflow.md`，仅套模板不等于生产就绪。
`{}` 内为槽位，全部来自分镜卡 C/E 层。校验脚本识别【】标签，请保留。

**不以导演、影片、摄影师名字代替可执行描述；通用技术名可配说明使用**（校验 W13）。透镜只写在文末 E 层参数表的「透镜」行，供多文件校验用。E 层节奏与变化字段（`duration-rhythm.md` §六）：`峰值镜 | N`（每条 clip 必填：最大物理动作或最大信息变化所在的镜，W32）、`语速词每秒`（默认 4；慢戏写 2.5–3 并在「语速理由」写说法；有成片按 `measure_clip.py` 校准值回填）、`节奏档`（对话 / 表演——选检查集，不是开关：对话 = W22–W33，表演 = W24 + W30–W33）、`无声段理由`（表演档必填，每段无声一个功能词）、`台词填充率`（默认 0.9；1.0 = 窗口 = 词数 ÷ 语速向上取整）、`台词轨`（窗口 / 连续；对话场默认连续）、`动作节拍秒数`、`台词密度`、`台词占比上限`，`衣着来源`（1.11.0：只有沿用形象图衣服的角色需要，写 `名字：形象图中的衣服（用户指定）`，W37），`运镜来源`（1.8.0：`镜N shot-XX 填写 / 原文`，用了运镜库才写；原文只在用户指定时，W34–W35），以及各阈值覆盖项；11 镜以上写「切点理由」行回应 W04。**节奏基准（1.12.0，`duration-rhythm.md` §十二）**：对话档默认按用户基准校验（R01–R04 = ERROR）；`长镜理由`（`镜N 持续动作 / 运镜 / 长句：…`，只为 >4 s 的镜写，脚本按类型核对）、`基准豁免`（`开头 / 结尾 / 镜N / 节奏档 / 全部：…（用户指定 日期）`，只写用户说过的）、`语速理由`（语速低于 3.5 词/s 时写说法）；E 层阈值行对基准只能收紧。**衣着（1.10.0，硬规则 21）**：有形象图的角色，【素材绑定】写本条衣着来源，三选一——`衣着一律按 @服装图` / `参考面部、发型与图中衣服：{衣物}` / `衣着一律按每一镜的文字：{衣物}`；【起始状态】、每一镜、【贯穿要求】里每个在画面里的角色（含监视器、画中画里的）第一次出现写 `{名字}（{形象引用} 身穿 {服装引用}：{衣物}）`，换装从那一镜起写新状态；群演可以集体写。下面各骨架里的 `{A 衣着}` 就是这一槽位。校验 E23 / W36。
每镜在景别标注之后同一行带变化字段 `【变化：景别 全→近｜机位 固定→推｜光 正→侧｜幅度 1→3】`（首镜写基线值；`=` 表示不变；重复构图加 `｜新增 X`；不要另起一行——行首的【】会被当作段落边界）。

## P 表演片段（不要求素材）

按用户指定镜头条件写一行；表演节拍数量与秒数按高光承载决定，不照模板固定分段。

```text
【表演条件】{总时长}秒；{镜头可见范围、声音等本次必要条件}。
【表演时间线】
节拍 {id}（{起}-{止}s）：{已确认的完整表演正文，含先后/同步/末态}
```

raw 原文直接交付所选完整正文，不套 P 骨架。production 可在镜头内嵌同样节拍；镜头边界与节拍不混用。记录接口见 `references/performance-record.md`。

衣着来源的三种写法（每个有形象图的角色选一种，写进它自己那一行绑定）。**默认形象图与服装图分开**（用户 2026-09-25 定）：有服装图用第一行，没有服装图用第三行；第二行只在用户指定时用，并在 E 层写 `| 衣着来源 | A：形象图中的衣服（用户指定） |`（W37）。

| 情形 | 【素材绑定】 | 镜头里第一次出现 |
|---|---|---|
| 有单独的服装图（默认） | `图1 = A外观，只参考面部与发型；本条A的衣着一律按图4` + `图4 = 本条A身上唯一的服装：{衣物}` | `A（图1 身穿 图4：{衣物}）` |
| 用户指定沿用形象图里的衣服 | `图1 = A外观与服饰参考：参考面部、发型与图中衣服：{衣物}{；下身按文字：…}` | `A（图1 身穿图中的{衣物}）` |
| 没有服装图，衣着只靠文字（裸上身、浴巾、还没做服装图） | `图1 = A外观，只参考面部与发型；本条A的衣着一律按每一镜的文字：{衣物}` | `A（图1，{衣物}）` |

服装图引用写在服装图自己那一行和每一镜里，不只夹在形象图那一行的括号里。"不参考图中的衣服"可以留作补充，但不能是唯一的一句（E23）。

## E 参数与交付状态

每条生产 Prompt 后附 S6 的 E 表，任务类型使用 production-workflow.md 的 task 标识，填写实际 role、ratio、duration、输出格式；节奏与变化行示例：`| 峰值镜 | 4（转身贴近：全片最大物理动作，配唯一一次推） |`、`| 语速词每秒 | 4 |`、`| 节奏档 | 对话 |`、`| 无声段理由 | 开头 2 s 建立；结尾 2 s 出画停留 |`。T2 中的侧面图/音频、T4 的额外角色图均按现有资源选用，不要求凑齐。文件级生产记录不粘贴进模型 Prompt。
