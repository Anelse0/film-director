剧本原文：夜里十点，面馆打烊。秋姐在擦最后一张桌子，把凳子一张张倒扣上桌。外卖员小北推门进来，还她落在车筐里的保温袋。小北：秋姐，袋子落我车上了。秋姐：放那儿吧。吃了没？小北：吃了。我明天就不跑这片了，回老家。秋姐：面还有一把。坐。

### 核对
1. 左右：一律写画左 / 画右。
2. 换边：镜 2、4 是反打，空桌从画左换到画右，因为机位掉头朝北。
3. 动作可行：每个动作都在可达范围内，镜 4 的三个动作连着做 4 秒够。
4. 参考图视角：镜 1、3 和 @面馆 同视角；镜 2、4 反方向，绑定行写不参考视角，正文只写画面里有什么。
5. 上一条成片：无上一条。

## 镜头 1（0-3s）

**A 创作决策**（不进 Prompt）：让观众先看见来的人，秋姐只给背影。
**C 可观察信息**（进 Prompt）：
- 景别 / 运镜：中景，平视，固定，朝玻璃门拍
- 可见画面：小北正面，腰部以上，画面中间偏左；画右前景是秋姐的背和肩，虚着，只占画面右下角。画面深处是玻璃门，门外路灯下停着他的电动车
- 焦点在谁：小北的脸
- 主要事件：小北右手拎着红色保温袋，左手推开玻璃门走进来两步
- 视线：小北看着画右的秋姐
- 表演翻译：不当回事 → 外化词典「随口 / 不当回事（轻松）」→ 可见：边推门边说，眼睛看着秋姐；声音：声音不高
- 有序表演块：0-3s 推门、迈两步，话在迈步的时候说完
- 台词：小北 / "秋姐，袋子落我车上了。" / 0-3s / 中文普通话 / 声音不高；秋姐闭着嘴，背对着他
- 结束状态：小北站在门内两步

## 镜头 2（3-5s）

**A 创作决策**（不进 Prompt）：她照常招呼，手上不停。
**C 可观察信息**（进 Prompt）：
- 景别 / 运镜：中近景，平视，固定，朝出餐口拍
- 可见画面：秋姐正面，腰部以上，画面中间偏左，右手的抹布在桌面上推。画面深处是出餐口，里面是亮着灯的厨房
- 焦点在谁：秋姐的脸
- 主要事件：秋姐朝画右的空桌抬一下下巴，擦完这一下直起身
- 视线：秋姐先看桌面，再看向画右的小北
- 表演翻译：不当回事 → 外化词典「随口 / 不当回事（轻松）」→ 可见：手上不停，朝空桌抬一下下巴；声音：声音平常
- 有序表演块：3-5s 先抬下巴说第一句，直起身时说第二句
- 台词：秋姐 / "放那儿吧。吃了没？" / 3-5s / 中文普通话 / 声音平常
- 结束状态：秋姐站直，抹布在手里

**C 可观察信息**（进 Prompt）：

## 镜头 4（8-12s）

**C 可观察信息**（进 Prompt）：

## 贯穿要求
- 保持一致：人物按各自素材；画面里只有小北和秋姐两个人；红色保温袋从镜头 3 起留在东墙边的空桌上
- 空间与机位：镜头 1、3 朝玻璃门拍，画左是东墙和空桌；镜头 2、4 朝出餐口拍，画右是东墙和空桌；拍人角度以正面为主
- 表演约束：打烊后的平常说话，两个人都不抬高声音；眼神始终有落点；说话的人手上有事在做
- 画面基调贯穿：主光来自天花板的暖白吊灯；人物光落在脸的一侧和肩上
- 声音：环境声、节奏指令、无 bgm、不要字幕；全条只有这五句台词，此外没有人说话；排除错误人物发声、多人同时说话、重复台词、漏词
