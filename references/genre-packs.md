# 类型包：难题、机制、选择与执行风险

按本场需要读相关包，可以组合（本 skill 用于 S4–S5；创意阶段用法由 film-creative 承担）。每包写：这类段落的核心难题 → 起作用的机制（`director-grammar.md` §八）→ 可选手法 → Seedance 执行风险。以下为设计选项 [推论]，不是类型配额；技术要求以能力表和任务契约为准。类型标签不能覆盖用户锁定内容。

## G1 动作 / 打斗

**难题**：观众看不懂谁在哪、谁打了谁，冲击力就变成噪音。
**机制**：地理清晰优先于冲击力（Jackie Chan："be clear in your shots"，动作与反应同框；Mann《盗火线》枪战出自像音乐剧一样的排练；Bayhem 的模仿者失败在没有尺度 / 视差 / 地理）。
**选择**：
- 第一镜全景建立地理：起点、障碍、终点各一个可见地标（S5 §5.10）。
- 每镜写两人相对位置与运动方向；攻与受尽量同框；切点落在击中而非挥出。
- 普通动作概括写，记忆点（一次关键接触、一次代价）细写；同时发生的运动不机械拆串行。
- 精确动作交给动作参考视频（"严格参考视频 1 的动作与运镜"），文字只补表情、台词、声音、场景。
- 升级、代价、慢动作（"回弹变速"）可以使用，但不强制每拍加武器或伤痕。
**风险**：模型弱项是复杂运动的物理合理性与多主体互动稳定性 `[官方]`；快动作形变、快切、遮挡分别登记；真实血迹按任务描述，不用"污渍"偷偷替换。

## G2 悬疑 / 恐怖

**难题**：观众与人物知道得一样多，就只有惊吓没有悬念。
**机制**：先告诉观众（Hitchcock 桌下炸弹：十五秒惊奇 vs 十五分钟悬念）；戏剧反讽 = 人物不知道观众知道的事（Mackendrick）；画外的威胁靠听者的脸放大（Ramsay）。
**选择**：
- 前 1–3 秒用插入镜头、前景或声音交代威胁与时钟；此后每镜写威胁在画内哪里、人物看不看得见。
- 可用画外声、负空间、背后留空的构图、局部揭示、直接呈现或突然切换；不规定必须三次揭示或一场只吓一次。
- 需要持续等待时让等待成立（固定机位、长镜、环境声），不强加事件。
- 光线写明实际来源、方向与变化，可有主光 / 辅光；低调光说明哪一侧受光。
**风险**：怪物、黑暗与快速变化效果未验证时标风险；不把画外作为规避用户目标的默认解法。

## G3 UGC / 广告 / 产品

**难题**：产品形态与卖点必须稳定可见，同时像真人在说话。
**机制**：产品是"此刻最重要的东西"时就让它最大（Hitchcock 尺寸规则）；动作证明卖点比形容词有效。
**选择**：
- 先锁定产品形态与参考职责（产品图只参考产品，不参考背景）；让动作证明本次卖点。
- 依据目标平台与真实人物口吻设计；可以干净流畅，也可以有停顿 / 手持感，不强制"三个不完美"、竖屏或结尾不笑。
- 台词按能力表 §7 预算，说话者正面或 3/4 侧的中近景锁机位口型最稳。
**风险**：产品文字、精细手部与口型需成片检查；不能为了降低风险抹掉用户必须展示的标识。主体 / 产品 / 场景参考按需要映射，不堆无关素材。

## G4 蒙太奇 / 音乐驱动

**难题**：镜头之间的关系是什么，没有关系就只是幻灯片。
**机制**：并置产生含义（Mamet / Kuleshov）；对比 / 亲和（Block）让序列有强弱；节奏的变化才被感知（Lumet）；剪切与重音同步或错位（官方"踩着节拍硬切，每次切换双重反差"范例）。
**选择**：
- 明确镜头间是对比、积累、因果还是韵律关系；常量 / 变量、形状匹配、动作接续和声音桥都可用，不要求只变一个变量或镜长单调变化。
- 音乐描述可包含类型、乐器、节奏、强弱及进入位置，具体到足以支持剪辑；不把风格名本身禁掉。
- 多场景可以在同一 clip 中，以清晰的空间 / 时间转换衔接，不默认每换地点就拆任务。
**风险**：模型能否精确踩点需验证；官方范例用 2–3 秒一镜的硬切序列，可作写法参考，不作稳定性保证。

## G5 视觉喜剧（可与以上组合）

**难题**：笑点写成台词就只剩台词。
**机制**：笑点来自进出画的时机、匹配转场、精确到帧的音效、动作与音乐同步（Wright 工具箱）；反应比事件小一号（Coen）。
**选择**：三拍（看见 → 关上 → 再关一层）、去而复返、擦画转场、音效落在具体动作上；固定机位让进出画成为事件。
**风险**：音效与动作的精确对位需成片验证；甩镜与急推变焦写清方式与终点。

## G6 暧昧 / 爱情

**难题**：把感情说出来、拍出来就廉价；不说不拍又没有情绪。
**机制**（`director-grammar.md` §8.5）：欲望被礼仪 / 处境压到只剩一个泄漏点，观众为这一个点屏息；情绪来自省略与并置，不来自展示。
**选择**：
- 视线：错位的注视（一方看时另一方移开，最后才对上或始终不对上）；对等的凝视（两人景别 / 机高 / 时长对称）；直视镜头只用一次。
- 空间：并肩不面对面；距离作为刻度（一臂 → 半臂）；隔着玻璃 / 门框 / 倒影看；平齐的双人镜头是关系镜，单人镜头是分离。
- 身体：接触 ≤1 秒，戏在接触之后（手指收紧、停顿、一次呼吸）；切到手不切脸。
- 省略：吻 / 告白放画外或不发生；拍门、走廊、事后一个人的脸。
- 声音：无 bgm；音乐只作画内音源并给进入秒数；环境声（衣料、打火机、虫鸣）承担节奏。
- 时间：不切或少切；慢放只给日常动作；同一构图重复第二次**必须多一样东西**（一个眼神、半步距离、一次触碰的余波），且该元素写进该镜的变化字段 `【变化：…｜新增 X】`——只重复不新增是校验 W30 报的项（`duration-rhythm.md` §二 变化轨）。
- 一条片段最多叠三条机制。
**风险**：手指相碰等精细动作、1 秒停留、"她看他时他正低头"的视线错位都需成片核对；两人同框轮流说话给不重叠的时间窗；画外台词写"画外"。

## 与旧样例的关系

旧三拍喜剧、先声后形或强烈争吵可以保留，只要它们在该故事中有效。取消硬配额不是删除这些方法。缺少具体领域事实时先检索资料，创作选择明确标为设计而非调研结论。
