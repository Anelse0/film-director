# S6 Seedance 2.5 Prompt 编译

输入：`04_shots/scene-XX-clipYY.md`（分镜卡 C 层 + E 层）+ `05_assets/asset-plan.md`（已回填）。
输出：`06_prompts/scene-XX-clipYY.prompt.md`（D 层 Prompt + E 层参数表）。骨架见 `templates/prompt-templates.md`。

编译是**确定性翻译**，不是再创作。C 层没有的信息不能凭空出现在 D 层；D 层出现的每个可观察量都能回溯到某张分镜卡。

## 6.0 表演保真与交付范围

performance/raw 按 `emotion-performance.md`，不强制下面的生产骨架。原文正文不翻译或润色；时间说明在正文外。production 中的有序表演块从 S4/C 层逐节拍原样进入 D，不能总结为情绪名，不能为结尾好看新增平静。

**情绪层是本 skill 约定的必备产出 `[推论]`，不是官方 Prompt 结构**（官方结构见 `seedance-2.5-capabilities.md` §4.1，不含情绪弧线字段；W20 是本地审阅提示，WARN 级、只提示不拦）。production 每条 Prompt 有三样：①【整体情绪弧线】块（一句话 clip 走向 + 每角色逐镜递进）；②每镜段首〔情绪〕标；③每句台词括注〔说法〕（交付情绪）。这三样都是**定位标签**：它们与逐镜的动作/视线/表情/节奏正文**并存**、给意图定位；**绝不替代或省略表演正文**。"不总结为情绪名"针对的是"用一个情绪词换掉可见表演"，不是禁止写情绪标签——标签在、证据也在，两者缺一即不合格。缺可见证据支撑的情绪词按硬规则 7 删，缺情绪标签的表演正文按本节补标。

使用 `templates/performance-record.json` 时按 `references/performance-record.md` 比较编译前记录与最终正文；元数据不进 Prompt。不要从 D 倒填 C 来制造通过。语义改动回 S4 记录；仅有素材绑定的格式变化不改变表演。

镜头与节拍分别编排；镜头内节拍使用 clip 绝对秒数，不能跨越镜头边界。表演的同步关系用“同时/随着”或原句保留，不按动作数自动改成箭头链。

完整生产交付接口与任务参数检查见 `production-workflow.md`。以下是通用生成任务的本地结构化实现，编辑、延长等按任务模板省略不适用段落。

## 6.1 编译顺序（基于官方结构的本地骨架）

```
【素材绑定】     ← E 层素材表（编号 = 上传顺序；明确参考范围；写"参考什么 / 不参考什么"）
【总述】         ← 主体 + 地点 + 事件 + 题材/风格 + 特殊运镜 + 时长 + 画幅（一句话）
【画面基调】     ← 媒介/质感、主光源与方向、镜头质感、色调（全部可见量；无空泛词）
【起始状态】     ← clip 第一张分镜卡的起始状态：谁在哪、朝向、持物、机位、轴线
【整体情绪弧线】 ← 从 S4 有序表演块提炼：一句话 clip 情绪总走向 + 每角色逐镜递进；每一步锚定可见证据的落点（眼神/身姿/口型/节奏/走位），标签定位意图、不替代表演正文
【分镜时间线】   ← 每张分镜卡一段：镜头 N（a-bs）：【景别 角度 运镜 构图】〔本镜情绪〕动作；视线；表情；台词（含〔说法〕交付情绪）；声音；结束状态
【贯穿要求】     ← 连续性锁（外观锁 / 空间 / 轴线 / 物件 / 服装）+ 声音策略 + 字幕负向
```

英文 Prompt 同样顺序，标签改为 REFERENCES / OVERVIEW / LOOK / OPENING STATE / TIMELINE / GLOBAL RULES。

## 6.2 逐段规则

### 【素材绑定】
本段即官方"素材指代"（`seedance-2.5-capabilities.md` §4.1）：只列每个素材的**编号（=上传顺序）＋主体＋职责（参考什么／不参考什么）**，一行一个，措辞简明；每个参考只赋一个职责（§4.2）。
- **人物：形象与服饰硬拆两条**（每人两图，identity 与 costume 是两个职责）：
  - `图N = {角色} 人物形象，只参考面部、发型、体型，不参考服装、背景与姿势`（跨场稳定、全程锁定）。
  - `图M = {角色} {本场}服装造型（{服装/配饰简述}），只参考服装与配饰，不参考面部、背景与姿势`。
  - 换装动线：每个服装态各一条服饰参考（如出场态、球服态），人物形象条仍只一条。
- 场景：`图X = {场景} 布局与光，只参考空间与光，不参考人物`。
- 音色：`图1 使用 音频1 音色`。
- 动作/运镜参考：`视频1 只参考运镜与节奏，不参考人物与场景`。
- 关键帧任务：首句必须是 `以图片1至图片N的顺序作为关键帧`。`[官方]`
- 宫格分镜：`图1 = 故事板分镜，只参考镜头结构、景别与顺序，不渲染格线与文字`。`[官方]` + `[第三方]`
- 首尾帧走 reference_image 方式时：`图片1为首帧`（不锁画幅）。`[官方]`
- 无素材的纯文生视频（兜底）：写 `无参考素材`，角色外观锁必须在【起始状态】里完整写出，E 层标"兜底路径"，S7 风险登记跨 clip 不一致。
- **本段严禁给人看的注释**：约定、数量小计（"共 N 张 ≤6"）、草稿状态、"待回填／需 S5b"、"用户提供"等来源与规划说明都是 E 层，写进文末 E 参数表或 `07_qa/`，**不进 D 层 Prompt**（五层分离；§4.1 素材指代只含编号＋用途）。校验 W24 提示此类泄漏。
- 图数与稳定度：官方 §3 稳定度按**主体（角色）数**计、不按图片数——≤5 个主体单/多视图均可（每角色"形象＋服饰"属多视图）、1–8 个主体更稳、9–12 个主体需抽卡；图片硬上限 30 张、素材合计 50。抽卡风险来自**角色数 >8**（S7 登记），每角色两图只增图不增主体、不触发抽卡（例：4 角色 = 4 主体、8 张图，仍稳）。
- **示例 Prompt（examples/01–04）为 1.4.0 前旧约定**，绑定写作合并式"外观（面部/发型/服装）"，保留用作台词/情绪/参数示例；新 Prompt 一律按上面的形象／服饰两条。

### 【总述】
一句话简明概述，不设字数硬上限。含时长与画幅："30 秒 16:9 横屏"。

### 【画面基调】
- 只写可见量：媒介（35mm 胶片 / iPhone 实拍 / 2D 手绘 / 3D 动画）、光源与方向、色调、景深、颗粒、镜头质感。
- 优先正向写清画面范围；可按需求补明确排除，不宣称视觉负向不受支持。官方明确展示声音/字幕负向及风格排除，但不保证任意排除都被执行。行为保持“不眨眼”不能因此删掉。

### 【起始状态】
- 谁在哪（画左/画右/中心；前景/背景）、面朝哪、手里拿什么、机位与景别、主光源方向。
- 连续接续时与上游末态核对；明确时间跳跃、地点转换或独立片段不要求状态相等。

### 【整体情绪弧线】（必备，W20）
- 一句话总走向（例："权力的玩味 → 众目的聚焦 → 新血的硬扛 → 残忍的轻松收场"），再逐角色列递进。
- 每角色一行：`{角色}：{起态}（镜X，{可见落点}）→ {发展}（镜Y，{可见落点}）→ {末态}（镜Z，{可见落点}）`。
- 每一步都点一个**可见落点**（眼神/下颌/身姿/口型/节奏/走位/目光），不写"很悲伤/很紧张"这类无证据形容词。
- 弧线是从 S4 有序表演块**提炼**的索引，不新增上游没有的情绪节点；与逐镜正文冲突时回 S4 改，不在此另写。
- 引用镜头写"镜1/镜2"，不要写成"镜头1（0-4s）"以免与分镜段落混淆。

### 【分镜时间线】
每镜格式（中文）：

```
镜头N（a-bs）：【景别，角度，运镜，构图位置】〔本镜情绪：角色·情绪词｜对手/全场情绪〕起始动作 → 主要动作（主语+部位+动词+对象）→ 结束动作。视线：…。表情：…（部位）。台词（角色，a-bs，语言）："……"（说法：交付情绪｜音量/语速/停顿）；此时 B 闭着嘴，看着…。声音：…。
```

规则：
- **〔本镜情绪〕**：段首标注之后紧跟〔…〕，写本镜谁是什么情绪、对手/全场是什么情绪；随后的动作/视线/表情正文必须能看到对应证据。标签是索引，不替代正文；确为无表演的空镜/插入镜写〔空镜/插入〕并在 QA 注明。
- **每句台词的〔说法〕**：引号后括注先写交付情绪（如"慢、带钩、尾音微扬""干脆、一记定音"），再写音量/语速/停顿；听者的可观察反应紧跟其后。逐句情绪递进落在这里。
- 时间戳整数秒、连续、首镜从 0 开始、末镜结束 = duration。`[官方]`
- 运镜清楚且与表演兼容；复合运镜交代同时或先后，不把单一运镜建议当禁令。多部位同步不串行化。
- 表情写部位；动作写主语与部位；数量写数字（"停 2 秒"）。
- 台词：说话人 + 引号 + 时间窗（clip 绝对秒）+ 语言（首次出现时写，后续同语言可省）；非说话者嘴部状态；台词后紧跟听者可观察反应。
- 不用时间戳控频（"3 秒内眨眼 5 次" ❌）。`[官方]`
- 镜头边界标明所需转场；可用“硬切 / Hard cut”（Higgsfield 指南使用），非硬切写时间及可见过渡。它是指令，不是精确执行保证。
- 遮挡 / 出画再入画：入画时重复外观锁一行。`[第三方]`

### 【贯穿要求】
- 外观锁：每个角色一行。
- 空间与轴线：“起初 A 在画左、B 在画右；走位和机位变化后的屏幕位置依镜头说明；窗光方向按实际空间保持”。
- 物件锁只描述实际恒定属性；发生持物、开合变化时写状态转移，不能再写“全程不变”。
- 声音策略：三选一 —— "无 bgm，只生成环境音、动作音与台词" / "只有环境音，无对白无 bgm" / "bgm：〈可见描述〉，从第 Xs 起淡入"。
- 字幕："不要字幕"。`[官方]`
- 字幕与声音负向为指南明确支持；其他负向按目标和风险使用，不设词汇白名单。

## 6.3 任务类型模板差异

| 任务 | 差异 | 参数（E 层） |
|---|---|---|
| **R2V 主体 + 场景参考（核心路径）** | 素材绑定 + 外观锁精简为"与图1一致，补充：…"；场景写"与图3布局与光一致" | ratio 自定 / duration 自定 / role=reference_image |
| T2V（兜底） | 只在 S5b 判定无资产且用户接受风险时；声明无参考素材；外观锁写全；E 层标"兜底路径" | ratio 自定 / duration 自定 |
| R2V 主体参考（仅角色图） | 素材绑定 + 外观锁精简为"与图1一致，补充：…" | ratio 自定 / duration 自定 / role=reference_image |
| R2V 动作/运镜参考 | "严格参考视频1的动作与运镜，顺序一致"，不复述细节 `[官方]` | 同上 / role=reference_video |
| 关键帧 | 首句固定；每镜写"参考图片N" | 同上；图片按顺序上传 |
| 宫格分镜 | 素材绑定 + 故事梗概 + 逐格补齐动作/运镜/风格 `[官方]` | 同上 |
| 首尾帧（严格） | 分镜时间线首镜/末镜对齐图 | role=first_frame/last_frame，ratio=adaptive，两图画幅建议一致（否则尾帧拉伸） |
| 编辑 | 一句话写清 A→B、范围（秒段 / 对象）、"其余不变"；关键词：编辑/修改/替换/增加/删除 | role=reference_video，ratio=adaptive，duration=-1，MOV 建议 |
| 延长 | "向后延长 @视频1 N 秒" + 续写内容 + "画面与声音无缝衔接"；关键词：延长/续写/延续 | role=reference_video，ratio=adaptive，duration=N，MOV 建议 |
| 无缝转场 | "将视频1和视频2衔接起来，…不改变两个视频" | role=reference_video |

## 6.4 语言选择

- 改编 Prompt 默认语言 = 台词语言；无台词时 = 用户语言。原文直用保持原语言，翻译应标为改编。`[未验证]` 两种语言效果差异。
- 不混写：整段 Prompt 一种语言，台词引号内可以是另一种语言并注明。

## 6.6 编译后自检（跑脚本前）

- D 层每一句能指回某张分镜卡？
- 有【整体情绪弧线】块吗？每镜标了〔情绪〕、每句台词写了〔说法〕吗？（W20 只查在场，质量仍需人审）
- 情绪意图是否有充分可见证据？逐节拍语义审阅，脚本不能证明质量。每个情绪标签是否都能在同镜正文里看到对应证据，而非空泛形容词？（标签定位意图，不替代证据）
- 每个引用的素材编号都在【素材绑定】里？
- 【素材绑定】只有"编号＋主体＋职责"，没有约定/数量/草稿/来源（用户提供）等给人看的注释？（W24；这些进 E 层）
- 人物的**人物形象**与**服饰**是否各成一条（换装态各一条服饰）？identity 条不含服装、costume 条不含面部？
- 总秒数 = duration？
- 对象排除与行为保持是否区分？不因“不眨眼”改写表演。
- 有没有"电影感"类空泛词？
- 正文是否用导演/影片名代替可执行描述？通用技术名不作此类误报。（W13）
- 重复是持续/推进还是无变化复制？W14 只提示整块相同待审阅。
- 按交付范围审阅过了吗？（`anti-mechanical.md` §7）
