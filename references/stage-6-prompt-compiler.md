# S6 Seedance 2.5 Prompt 编译

输入：`04_shots/scene-XX-clipYY.md`（分镜卡 C 层 + E 层）+ `05_assets/asset-plan.md`（已回填）。
输出：`06_prompts/scene-XX-clipYY.prompt.md`（D 层 Prompt + E 层参数表）。骨架见 `templates/prompt-templates.md`。

编译是**确定性翻译**，不是再创作。C 层没有的信息不能凭空出现在 D 层；D 层出现的每个可观察量都能回溯到某张分镜卡。

## 6.0 表演保真与交付范围

performance/raw 按 `emotion-performance.md`，不强制下面的生产骨架。原文正文不翻译或润色；时间说明在正文外。production 中的有序表演块从 S4/C 层逐节拍原样进入 D，不能总结为情绪名，不能为结尾好看新增平静。

使用 `templates/performance-record.json` 时按 `references/performance-record.md` 比较编译前记录与最终正文；元数据不进 Prompt。不要从 D 倒填 C 来制造通过。语义改动回 S4 记录；仅有素材绑定的格式变化不改变表演。

镜头与节拍分别编排；镜头内节拍使用 clip 绝对秒数，不能跨越镜头边界。表演的同步关系用“同时/随着”或原句保留，不按动作数自动改成箭头链。

完整生产交付接口与任务参数检查见 `production-workflow.md`。以下是通用生成任务的本地结构化实现，编辑、延长等按任务模板省略不适用段落。

## 6.1 编译顺序（基于官方结构的本地骨架）

```
【素材绑定】     ← E 层素材表（编号 = 上传顺序；明确参考范围；写"参考什么 / 不参考什么"）
【总述】         ← 主体 + 地点 + 事件 + 题材/风格 + 特殊运镜 + 时长 + 画幅（一句话）+ 声音一句（无 bgm，只有环境音与台词；官方 FAQ：音频约束开头结尾各一遍）
【画面基调】     ← 媒介/质感、主光源与方向及动机、镜头质感、色调（全部可见量；无空泛词）
【严格排除】     ← 可选：媒介/风格级排除（黑白、手绘、线稿、塑料 CG…），官方范例段位 `[官方]`；不放行为保持项
【起始状态】     ← clip 第一张分镜卡的起始状态：谁在哪、朝向、持物、机位、轴线
【分镜时间线】   ← 每张分镜卡一段：镜头 N（a-bs）：【景别 机高/角度 运镜→终点 构图 焦点在 X】主要事件 + 记忆点；虚实；视线；表演；台词；声音；结束状态
【贯穿要求】     ← 五个桶：保持一致 / 空间与机位 / 表演约束 / 画面基调贯穿 / 声音（穷举同义词）+ 不要字幕
```

英文 Prompt 同样顺序，标签改为 REFERENCES / OVERVIEW / LOOK / EXCLUDE / OPENING STATE / TIMELINE / GLOBAL RULES。官方四段式（素材指代 → 一句话概述 → 具体情节 → 贯穿细节）是骨架；【画面基调】【严格排除】【起始状态】是本地增段，官方范例里对应「整体风格 / 严格排除 / 首镜描述」。

## 6.2 逐段规则

### 【素材绑定】
- 格式：`图1 = 角色A外观（只参考面部、发型与服装；不参考背景与姿势）`。
- 音色：`图1 使用 音频1 音色`。
- 动作/运镜参考：`视频1 只参考运镜与节奏，不参考人物与场景`。
- 关键帧任务：首句必须是 `以图片1至图片N的顺序作为关键帧`。`[官方]`
- 宫格分镜：`图1 = 故事板分镜，只参考镜头结构、景别与顺序，不渲染格线与文字`。`[官方]` + `[第三方]`
- 首尾帧走 reference_image 方式时：`图片1为首帧`（不锁画幅）。`[官方]`
- 无素材的纯文生视频（兜底）：写 `无参考素材`，角色外观锁必须在【起始状态】里完整写出，E 层标"兜底路径"，S7 风险登记跨 clip 不一致。
- 服装图与场内穿着状态不同（脱下 / 搭在凳上 / 敞开 / 卷袖 / 换装）：绑定行选写状态的那一种——人物行 `X 的衣着一律按每一镜的文字：上身 @服装名 的白色礼服衬衫（黑色衬衫扣），礼服外套落座时脱下搭在凳上，下身 @服装名 的礼服长裤`，服装行 `@服装名：X 身上的衬衫与长裤；礼服外套只在开场穿着、之后搭在凳上，不穿回`；开场状态只写在【起始状态】，分段状态写在【贯穿要求】。「身上唯一的服装 / 衣着一律按 @服装名」是图 = 状态时的写法；「不参考 X」只用于本条从不出现的衣物（S5b §5b.3，W45）。

### 【总述】
一句话简明概述，不设字数硬上限。含时长与画幅："30 秒 16:9 横屏"。末尾加一句声音策略（"声音：无 bgm，只有环境音、动作音与台词"）——官方 FAQ 要求音频约束在开头与结尾各写一遍（W37）；强情绪的 clip 在这里加「人物为正常人眼，不发光」`[官方]`。

### 【画面基调】
- 只写可见量：媒介（35mm 胶片 / iPhone 实拍 / 2D 手绘 / 3D 动画）、光源与方向与动机（窗 / 灯 / 火）、高调或低调、色调、景深、颗粒、镜头质感（广角 / 长焦感）。
- 优先正向写清画面范围；不宣称视觉负向不受支持。行为保持"不眨眼"不能因此删掉。
- 默认景深在这里声明一次（深 / 中等 / 浅景深；官方范例写法"主体清晰，背景自然虚化" `[官方范例]`）；镜内只写焦点落在哪（W43）。

### 【严格排除】（可选）
- 官方九宫格范例用【严格排除】列媒介 / 风格排除（「黑白、单色、灰度、去色；手绘、素描、线稿、插画、漫画、动画；分镜稿 / 故事板、草图；移轴微缩、玩偶感、塑料 CG、油腻过曝 CG」）`[官方]`。当风格参考图易带偏媒介时用它；只列媒介 / 风格 / 文字叠加类，不列行为，不当作执行保证。

### 【起始状态】
- 谁在哪（画左/画右/中心；前景/背景）、面朝哪、手里拿什么、机位与景别、主光源方向。
- 地标以镜头为参照 `[实测]`：人物要去或离开的门、车、吧台、窗不在画里时，写它相对镜头的位置（"大门在镜头身后" / "吧台在画面深处" / "车停在画左"），不写"前面的门"；人物朝向也写相对镜头（"脸朝镜头方向，门在镜头身后"）。
- 每人一句（官方 FAQ 范例【站位设定】的写法 `[官方]`）：在画面哪一侧、面朝哪、看着谁、贴着图里的哪个元素（"坐在画面左侧过道的椅子上，面朝画面右侧"）。
- 连续接续时与上游末态核对；明确时间跳跃、地点转换或独立片段不要求状态相等。

### 【分镜时间线】
每镜格式（中文）：

```
镜头N（a-bs）：【景别，机高/角度，运镜与终点，构图位置，焦点在 X（换空间时加 日/夜·内/外）】（标注 ≤ 60 字，脚本按此识别；末尾带焦点）运镜 + 终点一句 → 虚实（只在有一层虚时写：哪一层虚、在画面哪个角、占多少）→ 起始状态（只在变化处写）→ 主要事件（主语+部位+动词+对象；一镜一个）→ 记忆点细节（至多一个）→ 结束状态（只在变化处写）。视线：看着 X（画左 / 画右 / 镜头后方）。表演：按 S4 翻译的拍子逐拍写（每拍一句：眼神先，一两个部位，先后；几拍写几句；只在可见景别写部位）。台词（角色，a-bs，语言，语气 / 音量）："……"；此时 B 闭着嘴，看着…。声音：…。
```

规则：
- 时间戳整数秒、连续、首镜从 0 开始、末镜结束 = duration。`[官方]`
- **焦点**：每个有画内人物的镜在标注末尾只写「焦点在 X（部位）」（深景深双人镜写这一镜为谁的反应而拍的人）；过肩 / 有虚化层的镜在镜头行写那一层在画面哪里、占多少、主体在哪里清楚；焦点变化写在镜头行，先后 + 秒（`camera-vocabulary.md` 移焦写法，不写进标注）；默认景深在【画面基调】。焦点与虚实是每镜内容，W38 的删减顺序不碰它（S5 §5.2 第 3 步，W43；E 层 `焦点理由` 可保留）。
- 运镜清楚且与表演兼容；复合运镜交代同时或先后，不把单一运镜建议当禁令。多部位同步不串行化。
- 表情按心理拍子写，每拍一句：眼神先（落点 + 变化），再一两个部位，按先后写，不堆同时的部位清单，不用情绪 / 判断词和强烈情绪词（`stage-4` §4.4c；W57）；一镜有几个可见的拍子就写几句，不合并；动作写主语与部位；数量写数字（"停 2 秒"）。
- 镜头行里省的是运镜的动机叙述与重复的起止状态（动机留在 A 层，运镜 + 终点一句，起止状态只在变化处写）。表演不在省的范围：视线、心理拍子、小动作、呼吸、台词语气按 S4 §4.4c 翻译后的内容写全，一镜有几个可见的拍子就写几句，不因"镜头行要短"而合并或缩写。官方范例每镜一两句是因为范例没有表演设计，不是镜头行的上限。
- 台词：说话人 + 引号 + 时间窗（clip 绝对秒）+ 语言（首次出现时写，后续同语言可省）+ 语气 / 音量（都在冒号前的括号里；单句不写快慢——语速快 / 飞快 / 赶 / 捂着话筒压低会让模型把整句挤着说（证据 #8），节奏只由【贯穿要求】的全局语速句给，W47；引号后只接「；此时 B 闭着嘴」，不写语气括号、不复述台词片段——官方 FAQ 字幕约束不生效 `[官方]`，W36）；长度按能力表 §7 预算，窗口按 `duration-rhythm.md` §三（建议窗口 = 估时 ÷ 0.9 向上取 0.5 s，写进 Prompt 取整数秒，松弛 ≤1 s）；非说话者嘴部状态；承接上游已选的倾听反应或持续状态，不为每句新编反应。重叠窗口保留并登记风险，不为消警告自动轮流、加速或改词。括号内容 = 语言 + 距离（画外、隔门、远远地）+ 情绪的**声音翻译**：音量 / 音色 / 可执行声音词（轻声 / 顿一拍 / 带笑 / 随口 / "啊？"的口气），抄分镜卡表演翻译第三段的"声音："那一半；**情绪 / 判断 / 意图词本身不进括号、不进镜头行**（W57）——它们是分镜卡 A 层词，经外化词典翻成脸手一半（镜头行）和声音一半（括号）后才进 D；是翻译，不是删词（官方「角色台词（情绪）：内容」允许情绪词 `[官方]`，本条是设计选择 `[推论]`，证据 #12）；官方格式也允许语速，本 skill 单句不写快，慢戏的"语速慢"只给 INFO）；动作（抬眼、看向、笑一下、抬杯）不进括号而写进镜头行（开口前或开口时，由导演定）；意图词（真诚 / 不推销 / 认出熟客——不是轻松 / 随口这类口气词）必须在同镜有这个人的一个可执行拍子——眼神 / 脸、手与身体、声音与停顿（括号里的 轻声 / 放慢 / 顿一拍 也算）、对对方的动作，载体按 S4 / S5 的设计，不限于眼神，在台词窗口内；画外 / 背对 / 后景的句子的意图拍子落在听者反应或下一镜，中景以上用身体 / 互动 / 停顿写在本镜或留给下一个近景（S4 §4.4c 第 7 条，W44）——但画外句本身不能落在另一人的近景脸上（W55）。
- **每镜负载**：一个主要事件 + 至多一个记忆点细节，其余概括（官方：概括优先、内容过多会被过度剪切或遗漏）。概括的是无关动作与背景活动，不是表演：S4 开发并经 §4.4c 翻译的表演全文进镜头行。部位级表情只写在近景 / 特写；全景写位置与动线。运镜必须有终点。
- **变化字段不进正文**（S5 §5.1f）：分镜卡的"变化"行汇总为 E 层 `| 变化轨 | 镜1：景别 …｜机位 …｜光 …｜幅度 …；镜2：… |`（首镜写基线；`=` 不变；重复构图 `｜新增 X`），E 层带 `峰值镜 | N`；校验 W30–W33 读 E 行。它是 C / E 层元数据，模型会把「机位 固定→推」「新增 X」当指令执行，所以不留在镜头行。编译器不替 S5 补变化——分镜卡没有的，回 S5。
- 参考绑定可写在时间段内：「镜头 3（6-10s，参考 图片4）」——官方白模与关键帧范例的写法 `[官方]`。
- 不用时间戳控频（"3 秒内眨眼 5 次" ❌）。`[官方]`
- 对话场台词轨默认连续（无需 E 层字段；写 `台词轨 | 窗口` 才退回逐窗口）：每句写在起点所在的镜，窗口 = 起点到镜末或下一句起点；**一句不跨镜**（W54）：不写「后半句画外接上 / 最后几个词落在下一镜」，`台词轨溢出容差` 只是 W29 的估时松弛；语速用成片校准值（`duration-rhythm.md` §二、§十）。
- 一句台词不分两段引号跨镜（W54）。画外台词（括号写「画外」）只在画里没有别的近景人脸时用；用项目的画外整句镜时，整句在本镜说完、镜长 ≥3 s、写明听者闭着嘴，【贯穿要求】写「排除错误人物发声、多人同时说话、重复台词、漏词」（官方四人案例【排除内容】的写法 `[官方]`，不是执行保证），W55 降 INFO 并登记风险。证据 #10。
- 镜头边界标明所需转场；可用“硬切 / Hard cut”（Higgsfield 指南使用），非硬切写时间及可见过渡。它是指令，不是精确执行保证。
- 遮挡 / 出画再入画：入画时重复外观锁一行。`[第三方]`
- **左右写画左 / 画右**（W46；证据 #8）：不写人物自己的左右肩、左右边（"门框在他右肩旁边"：人面对镜头时右肩在画左，模型两种都可能画）；要指哪只手写"靠门那只手（画左那只）"；过肩镜写"画 X 下角是他虚化的肩"，写了左右肩就要和下角同侧（背对镜头的人右肩在画右）；地标的左右（门右边那截窄墙）只在【素材绑定】的场景行定义一次并写明画左 / 画右，"走廊左侧"这类随机位转向会换边的说法不用。
- **手里的东西写哪只手、怎么握**（W48；证据 #8）：手机、杯子、瓶子、话筒写"右手拿着手机，正常握法：四指托在背面，拇指在屏幕一侧；左手自然垂着"，或在【贯穿要求】写一行"手："；不写"捂住话筒"（会被生成成捂嘴）。
- **轻松场不写慌张类表演词**（W57，原 W49；证据 #8）：慌慌张张、瞪大眼、牙关一咬、狼狈会被演成瞪眼张嘴、整张脸皱起来；写平常的样子加一个小动作（一愣、闭一下眼）。
- **镜头身后的东西只提一次**（W52；证据 #9）：反打镜里，镜头身后的物件（镜台、窗、床）在本镜和提到本镜的全局句里各只留一句方向句，不描写它、不拿它当光源（"灯泡镜的暖光"也算）。参考图的视角比文字强，多提一次模型就把机位放回图的位置。
- **接上一条末帧的第一镜接着动**（W51；证据 #9）：从末帧那一刻正在做的事的下一步开始，不把上一条最后一拍再演一遍。
- **方向以镜头为参照** `[实测]`：人物朝向或远离某个地标（门、车、吧台、窗）时，同一句里写地标相对镜头的位置（在镜头身后 / 画面深处 / 画左 / 画右）和人物相对镜头的运动（朝镜头走来 / 背对镜头走远）；地标不在画里时不能只写"前面的 X / 朝 X 走 / 退向 X"，视线落点同理（"看着他要去的方向（镜头后方）"，不写"看向前面的门"）。全局写一次不够，每镜重写（证据 #6：【起始状态】写了"机位背对大门"，镜内仍写"朝大门走"，人物就背对镜头走远）。校验 E23，ERROR 级：停下改写，不能附理由保留（`director-grammar.md` §3.7）。

### 【贯穿要求】
按官方"结尾贯穿细节"的桶写（机位 / 运镜、环境 / 场景、声音、氛围 `[官方]`）：下面五个桶按序写，前四个不能为篇幅删（W38 的删减顺序不含它们），不复述图里看得见的外观。
- **保持一致**：每个角色一行"脸、发型、衣着与 @名 / 图N 一致"（不重列衣物）；穿着状态与服装图不同时在这里写分段状态（"镜头1 起礼服外套脱下搭在旁边的凳子上，之后不穿回"——这是状态转移，不是重列衣物，W45）；人数（"画面里只有 A、B；群演只在背景"）；可选的相对身高关系（"A 比 B 高半个头"——官方 FAQ 范例的写法 `[官方]`，只在两人同框且身高关系要紧时写，不写绝对身高体型）。
- **空间与机位**——轴线：“起初 A 在画左、B 在画右；走位和机位变化后的屏幕位置依镜头说明；窗光方向按实际空间保持”。
- 方向句 `[实测]`：场景图定了机位朝向时必写一句，说清画面是哪一侧、人物在画内朝哪走、这段运动是进还是出——"方向：镜头 1–7 机位在雨棚下背对大门朝街道拍，画面里是街道一侧，Theo 始终从街道那边朝镜头走来，越走越近，他是在走进大楼"。正文有朝镜头 / 背对镜头或朝地标的走位而没有这一句时校验给 INFO。
- 物件锁只描述实际恒定属性；发生持物、开合变化时写状态转移，不能再写“全程不变”。
- **表演约束**：状态基线一句；眼神始终有落点；呼吸看得见；每镜一个自发小动作；走路有状态；强情绪镜加「人物为正常人眼，不发光」（官方 FAQ `[官方]`）。
- **画面基调贯穿**：主光一句、人物光一句、环境亮度按图不提亮。
- **声音**：策略三选一并穷举音乐类同义词（官方 FAQ 背景音乐约束不生效 `[官方]`，W37）—— "无 bgm：不要音乐、背景音乐、配乐、器乐、旋律与铺底音，只生成环境音、动作音与台词" / "只有环境音，无对白无 bgm" / "bgm：〈可见描述〉，从第 Xs 起淡入"；【总述】末尾已写过一句，这里是第二遍。多人对白的 clip 再加一句「排除错误人物发声、多人同时说话、重复台词、漏词」（官方四人案例【排除内容】的写法 `[官方]`，不是执行保证；W55 的条件之一）。
- 字幕："不要字幕"。`[官方]`
- 字幕与声音负向为指南明确支持；其他负向按目标和风险使用，不设词汇白名单。
- 节奏指令（对话场默认，`duration-rhythm.md` §八）："每句在窗口起点即开口，语速约 N 词/秒（默认 3.5），句内连读、句尾不拖音；上一人话音落下时下一人已起音；换镜硬切；动作正常速度、利落，不做慢动作"。不写"不要求撑满每一秒 / 可在边界停顿"这类留空许可；停留只写秒数与功能。

## 6.4 语言选择

- 改编 Prompt 默认语言 = 台词语言；无台词时 = 用户语言。原文直用保持原语言，翻译应标为改编。`[未验证]` 两种语言效果差异。
- 不混写：整段 Prompt 一种语言，台词引号内可以是另一种语言并注明。

## 6.6 编译后自检（跑脚本前）

- D 层每一句能指回某张分镜卡？
- 情绪意图是否有充分可见证据？逐节拍语义审阅，脚本不能证明质量。
- 每镜是否只有一个主要事件？运镜有没有动机与终点？画面里最大的东西是不是此刻最重要的东西？（`director-grammar.md` §九）
- 峰值镜声明了吗、拿到最可见景别和首要运镜了吗？每一次切至少换一维？镜长最长 ≥ 2× 最短？（`director-grammar.md` §4.1，W30–W33）
- 每个引用的素材编号都在【素材绑定】里？
- 总秒数 = duration？
- 对象排除与行为保持是否区分？不因“不眨眼”改写表演。
- 有没有"电影感"类空泛词？
- 正文是否用导演/影片名代替可执行描述？通用技术名不作此类误报。（W13）
- 人物朝向 / 远离的地标都标了相对镜头的位置？朝镜头走的镜里有没有"前面的 X / 朝 X 走 / 退向 X"？场景图定了机位朝向时【贯穿要求】有方向句吗？（E23）
- 重复是持续/推进还是无变化复制？W14 只提示整块相同待审阅。
- 按交付范围审阅过了吗？（`anti-mechanical.md` §7）
- 变化字段都在 E 层 `变化轨` 行、没留在镜头行？台词引号后没有语气括号、没复述片段？声音策略开头结尾各一遍并穷举同义词？篇幅在预算内且删减没碰表演？角色素材按首次出场顺序、声明的都引用了？（W36–W41）
- 每个 S4 表演要素在 D 里都有可见写法或写明了去处？（`stage-4` §4.4c）
- 每个画内人物镜写了焦点在谁？过肩 / 虚化层写了在画面哪里、占多少？默认景深在【画面基调】？（W43）
- 台词括号里没有快慢词、声音行没写"快"（W47）？左右都写画左 / 画右、过肩的肩和下角同侧（W46）？手机 / 杯 / 瓶写了哪只手怎么握、没写捂话筒（W48）？轻松场没有慌张 / 瞪眼类词（W49）？接上一条末帧的第一镜接着动（W51）？镜头身后的东西只提一次、没有只服务一个反向镜的场景图（W52）？
