# 验证账本

记录具体条件下的成片观察，不把少量样本当作通用能力证明。用户对文本的认可单独标“文本偏好”，不是成片验证。

## 记录规则

- 一次生成可按关键节拍分行。记录平台/模型版本、时长、参考条件、Prompt 版本及改动变量；多变量样本可以记录但不能单独归因。
- 逐项记“可见执行/部分执行/未执行/不可观察”。画面裁掉或遮挡的部位属于不可观察，不能据此断言没演。
- 重复结果只积累条件化经验；能力标签变更需要相应证据，不因固定样本次数自动升级。

## 待验证队列（按影响排序）

1. 画外音 + 画内单人：`台词 (女儿，画外)` 写法是否稳定产生画外声音且画内人不动嘴（`stage-4` §4.5，example-02 B）。**部分有结果（2026-10-19）**：拆句的后半句画外落在听者的中景上时，听者替说话人开了口（offset EP06 s02 clip01 v1.6，上表；1.11.0 W54 / W55）；整句画外 + 听者闭嘴 + 排除句（example-02 B 现在的写法）仍未验证 → 待验证 24。
2. 移焦"术语 + 描述"写法是否被执行（`camera-vocabulary.md`）。
3. 出画停留 ≥ 3 秒是否被执行，还是模型会补人进来（`stage-5` §5.1d）。
4. 20 秒一镜到底两人走位三次构图变化的稳定性（example-02 C）。
5. 外化词典中"部位级"表情（下唇内收、吞咽）是否可见，还是被放大成夸张表情。
6. 中文 vs 英文 Prompt 同一场景差异（`stage-6` §6.4）。
7. 画面级负向词（英文 no logo）是否有效（`capabilities` §4.4）。
8. 切镜密度：6 镜 / 30s 与 10 镜 / 30s 的稳定性差异（`capabilities` §5 冲突记录）。
9. 文字驱动的反向跟拍 5 秒是否稳定收口到关键帧构图（example-05 镜头 4）。
10. 英文台词按 2.5 词/s × 2/3 占比预算时口型是否完整（能力表 §7.3）。
11. 【严格排除】段对媒介漂移的实际效果（S6 §6.2）。
12. 白模视频"只参考运镜不参考画面"的执行程度（T3b）。
13. 变化轨 A/B：同一场景 v2.1（等长固定微动作）与 v3（峰值镜 + 四维变化 + 镜长对比）各生成一次，用户盲选——只有这样才能把 1.4.0 从"非盲呈现改善"升为"效果提升"。
14. `measure_clip.py` 视觉变化谱阈值（Δ直方图 0.12、镜内运动 0.08）在更多成片上的假阳 / 假阴率。
15. 方向以镜头为参照（`director-grammar.md` §3.7 / E23）：v2.1 的"门在镜头身后 + 朝镜头走来 + 方向句"写法是否让人物稳定朝镜头走进大楼；只改方向写法、不改其他变量时再核一次（本表 2026-10-13 行）。
16. 基调线索（S4 §4.4b / W35）：clip02 v1.6 / 补拍 clip02b 的"继续嚼 + 抬头下巴放平看一眼 + 压着笑 + 来人有状态"是否读成轻松；"低头抬眼看镜头"与"头不动只转眼珠"是否确实读成阴狠 / 怀疑，需要一次只改这一项的对照（本表 2026-10-13 第二行）。
17. 1.6.0 编译格式（官方 FAQ 对齐，`[官方]` 规则但本项目未实测）：语气写到冒号前、引号后不接括号（W36）是否影响口型与语气执行；声音策略首尾各一遍 + 穷举同义词（W37）对 bgm 泄漏的实际效果；变化字段移出正文后成片的切点与变化是否不变（对照 1.4.x 同一 clip）；篇幅从 2300 字降到 2000 字以内时表演细节是否仍被执行。每项只改一个变量各生成一次。
18. 焦点在谁（S5 §5.2 第 3 步 / W43）：同一镜写与不写「焦点在 X」各生成一次，看主体是否清楚、过肩前景是否只占一角虚焦；焦点变化（先后 + 秒）的写法是否被执行（与待验证 2 合并核）。
19. 台词括号里的意图（S4 §4.4c 第 7 条 / W44）：括号里写「真诚，不推销」而镜头行无任何拍子 vs 镜头行各加一种载体（眼神「开口时眼睛留在对方脸上」/ 身体「手指在台面上点一下」/ 停顿「句尾顿一拍再接」/ 互动「把酒单推过去一点」），各生成一次，看哪种载体被执行得稳；括号里的动作（抬眼，笑一下）是否被执行。
20. 服装图与穿着状态（S5b §5b.3 / W45）：绑定行写「唯一的服装 / 一律按图」+ 【贯穿要求】分段状态（clip03 r1：外套未穿回，反例）vs 改写状态的写法，各生成一次看有无差别；无差别则 W45 降为 INFO。

21. 台词括号快慢词（S6 §6.2 / W47）：同一条只删"语速快 / 飞快 / 捂着话筒压低"、时长与窗口不变，台词是否不再挤；"压着声音"是否也会压快语速（offset EP06 clip01 v1.5 待生成）。
22. 参考图视角（S5 §5.1g / W52）：只服务一个反向镜的场景图，在绑定行写"不参考视角"、正文只写画面里有什么、扶手椅做前景时，反打是否成立（offset EP06 clip02.1，5 s）；不成立时比较"改选现有图覆盖的机位"和"不绑这张图"。
23. 绝对方位（S5 §5.1g / C09）：分镜卡写方位与朝向后，Prompt 里的画左 / 画右是否和成片一致（下一条新地点的 clip 起记录）。
24. 画外整句镜（1.11.0，用户定的例外）：听者近景 + 他人整句画外、镜长 ≥3 s、写明听者闭着嘴、【贯穿要求】有「排除错误人物发声、多人同时说话」时，听者是否仍开口；先用 5 s 验证条试，再决定能否当默认（W55 降 INFO 的条件）。
25. A 层词边界 + 词典轻松变体（1.12.0）：分镜卡按三段表演翻译写、Prompt 正文与括号无 A 层词（W57 0 命中）后，轻松场成片是否不再读成对质 / 悬疑；对照 offset EP06 s02 clip02 v3（有）与 v3.1（无）。
