# 镜头要求表（编写和检查共用一张）

写镜头交付物时照这张表写，查的时候照这张表查。S5 / S6 / S7、§5.11 收口对照表、`checks.md` 和脚本消息提到这五件事时只引行号（R1–R5），不各写一套说法。来历在 `validation-log.md`（证据 #n），这里只留指针。

## 镜头交付物

四样：分镜卡的 `## 镜头纵览`（镜头表）、分镜卡每镜的 C 层行、Prompt 正文、停靠回显里的镜头表。它们只写镜头里的事：每个人在镜头里做什么、说什么，画面里看得见什么（R4）。

创作决策、表演翻译的前两段、透镜、手法、证据、事实标签、校验结果都保留，写在卡头、A 层、E 层和 QA，不进这四样。

每镜必有两格：

- **可见画面**：画里看得见谁、在画面哪里、露到身体哪儿、前景是什么。
- **画面深处**：这一镜画面最深处是什么（R3）。

## R1 展开：对白段形状与画外手法

**形状**（S5 方案阶段、拆镜之前定，一段对白选一种或几种）：

- 抢话叠在同一画面：两人同框，按秒轮流说。
- 双人镜一来一回：双人 / 过肩，说话人和听者都在画里。
- 反应写进说话镜：听者在画里，反应写成动作，不另成镜。
- 句中切听者、先闻其声、画外整句：见下表。
- 单人说话镜可以用；镜头表连续 3 行「单人镜、画里只有说话人、各一句」就改（证据 #33）。

**画外手法**（台词格式不变：`台词（角色，…）："逐字"`；画外音、V.O.、旁白写在括号里，括号第一项就是「谁的声音」，脚本按这个标签认）：

| 手法 | 写法 | 依据 |
|---|---|---|
| 句中切听者 | 在分句处切。前半句写在说话人镜：`台词（A，a-bs，语言，语气）："前半句"`。后半句写在听者镜：`台词（A，画外音，b-cs，和镜头 N 同一个声音）："后半句"`；同镜写「此时画面里只有 B，B 闭着嘴」和 B 听到这句时的可见反应。画外段宜短（约 2 s 以内） | 无范例；由官方的画外音标签、闭口写法、排除句拼成 `[推论]` `[未验证]` |
| 先闻其声 | 先在听者镜或空镜写 `台词（A，画外音，…）："前半句"`，切到 A 出镜后写 `台词（A，…）："后半句"` | 同上 |
| 画外整句 | 整句落在听者、物件或空镜。画里没有人脸时直接写 `台词（A，…）："…"`；画里有别人的脸时按画外音写，并写明那人闭着嘴 | 官方 30 秒范例（说话人不在画里的镜）、官方广告范例的画外音 `[官方范例]` |
| 旁白、内心独白 | `台词（旁白，a-bs，声音描述）："…"` 或 `台词（A，V.O.，a-bs）："…"`；同镜写明画里的人嘴唇闭合 | 官方 V.O. 范例 `[官方范例]` |

四种共用：

1. 【贯穿要求】声音桶写「全条只有这 N 句台词，此外没有人说话」和排除句「排除错误人物发声、多人同时说话、重复台词、漏词」。
2. 有音色参考音频时，在【素材绑定】把音色绑给说话人。
3. 镜头表「台词」列每句标画内 / 画外音 / V.O.，画外音写是谁的声音。
4. 引号后只接听者的嘴部状态，不复述台词片段（W36）。

**状态**：2026-11 核对火山指南（10 月、11 月版）、官方在线教程、Dreamina 指南、Higgsfield、Runway、fal、WaveSpeed，没有一份出现「一句话跨切点落到另一个人脸上」的范例。句中切听者和先闻其声用到的头几条成片回来后，各记一行 `validation-log.md`。

## R2 展开：台词动作表

分镜卡 `## 台词动作表`（A 层，不进 Prompt；S5 方案阶段、走位表之前写）：

```
| 句 | 说话人 | 这句在戏里做什么 | 说的时候在做什么 | 出处 |
```

「出处」按顺序取，取到为止：

1. 剧本这一刻写明的动作。
2. 剧本处境里人物本来就在做的事（在收摊、在赶路、手里拿着什么）。
3. 这句话在戏里对对方做的事（表演设计稿的心理拍子），落到剧本已有的物件和位置上。

三处都取不到就不编：写「站定：原因」（这一下停住就是戏），或写「缺口」。缺口同时登记进卡头「剧本回写待办」，在停靠回显「要你定的事」里提出。不新增剧本里没有的道具、任务、走位。

镜头行写法：动作先起，台词落在动作中间，动作在台词窗口内收。手上的小动作（搅、捏、摸）不算。这个动作就是本镜的主要事件或记忆点，不另加负载（硬规则 15）。近景里迈步读不出，步子放在开口前或换景别（证据 #24）。

## R3 展开：画面深处与镜头身后

- 每镜一句「画面深处是 X」，写在可见画面之后；参考图里看得见也写。
- 机位朝向靠这一句交代。「X 在镜头身后」只用于人物要去的、不在画里的地标（E23），每镜至多一句（W52），同镜必须有画面深处。
- 只写「镜头背靠 X / 背对 X 朝屋里拍」而没写画面深处，会被拍成朝 X（证据 #32）。

## R5 展开：光线与眼神的界线

- **不写（光线）**：眼睛里或眼睛上的光、亮、闪、反光、映着什么、泪光、眼神光、发亮；「光落进 / 照进眼睛」；「眼睛一亮」「眼睛亮起来」「眼神一亮」字面是亮，同样不写。
- **照写（眼神）**：看哪里、怎么动、开合——看向、落在、转向、对上、躲开、抬眼、垂眼、眯起、眨眼、盯住。「眼神」「视线」「目光」这些词本身不受限。泪水写位置和动作（积在下眼睑、滑落），不写它发亮。
- 「人物为正常人眼，不发光」这类防护句也是写眼睛光线的句子，不写进 Prompt（官方 FAQ 的记录留在 `seedance-2.5-capabilities.md` §4.6、§8）。
- 写了就会被画成眼睛发光，哪怕写的是现实里的台灯反光、哪怕排除句里写了不发光（证据 #25）。
