# 运镜库：执行语法，不是导演决策（1.8.0）

`assets/camera-library.json` 是用户的《AI 运镜提示词库》的原样副本（46 条、7 类、英文；复制时 SHA-256 `0f3136a5…88ec` 与源文件一致，保护区锁定）。每条把一种运镜拆成五段：**Camera**（名称）/ **Movement**（怎么动）/ **Speed**（多快）/ **Framing**（运动中什么保持不变）/ **End**（止于什么）。`references/camera-index.json` 是中文阅读索引，不是另一份原文：每条写叙事职能（指回 `director-grammar.md` §2.2 的行；库外新增的标 `[推论]`）、什么时候不用、与人物运动的关系、载体与风险、在能力表 §4.5 官方术语里的写法、在 `camera-vocabulary.md` 里的对应行。

这个库回答"机器怎么动、动的时候什么不变"；**什么时候动、为什么动**仍由 `director-grammar.md` §二、S5 §5.4 与硬规则 8 决定。库不会让一场戏多出运镜：写不出动机就固定机位（库里的 shot-01 也是固定）。

```bash
python3 scripts/camera_library.py --list
python3 scripts/camera_library.py --query 侧跟
python3 scripts/camera_library.py --slots shot-19     # 五段填写模板 + 索引说明
python3 scripts/camera_library.py --raw shot-19       # 原文，只在用户指定时用
```

## 一、S5：决策顺序不变，库只进最后一步

1. **观众此刻需要什么**（§5.2 第 1 步）。
2. **机器要不要动**：写出动机（揭示 / 内部变化 / 陪伴 / 孤立 / 失衡 / 在场感……，§5.4）；写不出就固定。
3. **哪一类运动**：按 `director-grammar.md` §2.2 的叙事职能与"什么时候不用"选。
4. **从库里选一条**（可选）：`--query` 找候选，读索引的"什么时候不用"与"人物"两栏再定。
5. **按五段填写成这一镜的内容**：

| 库里的段 | 从哪里取 | 落到哪里 |
|---|---|---|
| Camera | 条目名 → 中文术语（索引 `zh`、`camera-vocabulary.md`） | 分镜卡"运镜"；Prompt 的【景别，…，运镜→终点】标注 |
| Movement | 走位表的画左 / 画右、轴线、机位在哪一侧、从哪里到哪里 | 标注之后"运镜的动机与展开"那一句 |
| Speed | 跟人物速度，或秒数（`duration-rhythm.md`） | 同一句 |
| Framing | **具体**：谁在画面哪里、谁离机位近、什么保持不变 | 同一句 |
| End | 本镜结束状态里的构图（止于……）——**不用库里的通用句** | 标注的"→终点" |
| （库里没有）动机 | A 层一句 | 分镜卡 A 层；不进 Prompt |

例（THE ORDER EP03 场 4 clip01 镜 1，shot-19 侧跟拍）：
- 照抄（反例）：`Camera: side tracking shot. Movement: move parallel beside the subject along their direction of travel. … End: continue the parallel movement with clear horizontal motion.`——一整队人里 "the subject" 指谁不清楚，End 是通用句，本镜真正的终点没进运镜，中英混写。
- 填写：`【全景，侧跟拍，队伍从画右跑向画左】机位在跑道内侧与队伍平行移动，速度跟慢跑一致；Beckett 保持在画面中间偏左、侧脸对镜头，队伍在他身后排开，机位距离不变；止于 Beckett 喊完转回身、整排侧影横穿画面。`

6. **场级**：视觉方案写"本场运动逻辑"一行（全固定 / 只在人物走位时动 / 峰值给哪一次推），库不决定这件事。峰值镜仍拿"本 clip 首要的有动机运镜"（§5.1f）；运镜名写进【变化】字段的机位维度。
7. **载体**：索引"载体"栏写了关键帧 / 白模 / 特效 `[未验证]` 的条目（大角度环绕、穿过前景的精确构图、特效类），按 S5 §5.0 换载体或登记风险。

## 二、三种来源（E 层 `运镜来源`）

| 方式 | 何时 | Prompt 里 |
|---|---|---|
| 填写（默认） | 用了库里的条目 | 五段都写成本镜内容，语言跟 Prompt 一致 |
| 原文 | **只在用户明确指定时**（如"镜 1 用这段运镜"） | 条目 `prompt` 原样；中文 Prompt 里也可保留英文 |
| 库外 | 没用库 | 按 `camera-vocabulary.md` 写 |

写法：`| 运镜来源 | 镜1 shot-19 填写；镜3 shot-08 填写 |`。只写用了库的镜；没有这一行等于全部库外。

## 三、检查（`validate_prompt.py`，W34–W35）

- **W34**：某镜照抄了库里 Movement / Speed / Framing / End 的通用句（≥5 词的英文原句），或中文 Prompt 里夹着英文五段骨架（Camera: … Movement: … End:），而这一镜没有声明原文。改法：按本镜填写；确要原文，在运镜来源写「镜N shot-XX 原文」。
- **W35**：运镜来源一行不成立——条目编号不在库里、镜号不存在、原文没写条目编号、方式读不出。
- 查不到的：逐字翻成中文的通用句（"保持主体在侧面或四分之三侧面、距离稳定"）脚本认不出，靠 S7 审阅；运镜动机是否成立、终点是否是这一镜的构图，属语义审阅。
- 2026-09-23 对 THE ORDER 与 reckless 48 条已出 Prompt 回扫：只有 EP03 场 4 clip01 镜 1（用户指定的原文段，当时未登记）报 W34，无误报。
