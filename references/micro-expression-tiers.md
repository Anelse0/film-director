# 微表情分档：眼眉骤变的风险、三档判定与改写

25 条原文与库外新编里的"骤变"类描述——瞳孔骤变、眼睛突然睁大、眉毛一闪、眨眼加快、反复吞咽、颜色瞬间上脸——在生成里容易被放大成夸张、显假的表情。本文件给出分类、三档判定与改写方法，是 S4 / S5 的判断工具；**具体词表、阈值与 FAIL / WARN 由项目或工作区闸门维护**（例：工作区 `tools/scene_gate.py`），不进入 `validate_prompt.py`。

依据：
- 官方要求表情写描述性语句、只在有记忆点处写细节、不重复 `[官方]`（`performance-grammar.md` §1）。
- Ekman / Friesen 的微表情为 1/25–1/2 秒；本 skill 已推论"亚秒级的闪过既不可靠执行也难以看见，不写"（`performance-grammar.md` §4）`[推论]`。本文件把这条原则落到可判定。
- 2026-09-15 用户实测：一处"瞳孔微睁"被生成放大为明显瞪眼、读作假 `[推论·单样本]`；已登记 `validation-log.md` 待验证队列，成片对照后升级或修订。

## 1. 两类骤变（分类是判断规则，不是穷举词表）

| 类 | 内容 | 为什么 |
|---|---|---|
| **A 类·眼眉骤变** | 瞳孔骤变（微睁 / 一缩）、眼睛突然睁大 / 微睁、眼白露出、眉一次升落 / 一挑 / 一跳 | 幅度小、时间短、部位在脸的最高注意区，模型倾向放大成可见事件 |
| **B 类·次级信号** | 眨眼加快、同一镜内第二次吞咽、颜色"走"上脸（往颧骨 / 耳根蔓延）、嘴角一抽、鼻翼一张、睫毛一颤、"眼睛不眨"作为硬指令 | 可控但易过：要么被放大，要么被渲染成抽动 / 瞪视 |
| 不属于骤变（可正常写） | 眼睑降低并保持、单侧嘴角慢慢挑起并停住、目光钉住 / 掉下 / 移动、一次吞咽、呼吸停一拍或一口可见呼气、下颌 / 肩线 / 手的变化、耳根泛红作为持续状态 | 慢变或保持，模型执行稳定，观众也读得到 |

## 2. 三档

| 档 | A 类 | B 类 | 适用 |
|---|---|---|---|
| 严 | 一律不写 | 一律不写 | 特写多、克制情绪、抽卡敏感 |
| **中（默认）** | 特写 / 近景不写；其余景别可写但需理由，全 clip ≤1 处 | 可写但需理由，全 clip ≤1 处 | 对白场默认 |
| 宽 | 可写，全 clip ≤2 处并写理由 | 不限，记录即可 | 动作场 / 喜剧夸张语域 / 远景为主 |

紧景别＝特写、近景（中近景不算）。上限按 clip 计，不按镜。

## 3. 定档流程

1. 创作侧在台词设计表给"建议档"，依据：景别构成、情绪克制度、抽卡敏感度。
2. S5 停靠时随场景参数卡一起定档，写进分镜卡 E 层；改档要写理由。
3. S6 落盘文件头部写「微表情档：X ｜ 理由」；项目闸门按档判定。
4. 默认 中；未声明时闸门按中判。

## 4. 原文不豁免：hinge 本身是骤变的条目怎么用

索引里 hinge 为骤变的条目（#2 震惊：眼白露出；#3 惊恐：眉上提不眨；#14 领悟：眼睁、眉跳；#25 假笑：眨眼加快……）在中 / 严档下按 §2"压缩留 hinge"的思路改写：

- **骤变 → 到达后的保持**："眼睛睁大"写成"上眼睑抬起后停住不动、目光锁定"；"眉跳"写成"眉抬起后保持一拍再落"。保持是可见证据，闪过不是。
- **闪过 → 慢变**："眨眼加快"写成"目光在两处之间来回、停不住"；"颜色走上脸"写成"耳根的红作为持续状态"。
- hinge 若无法改成保持或慢变（条目的识别性就在那一下），要么改档为宽并写理由，要么改标 free 另写。改写后仍记 adapt，记录里写"骤变 → 保持"。
- 已有示例（如 `examples/performance/08`）写于分档之前，按当时规则成立，不回改；重用时按当前档位改写。

## 5. 替代通道

慢而连续的变化 · 保持状态 · 身体与呼吸（下颌、肩线、手停住、呼吸停一拍）· 视线转移 · 物件与空间（换手拿东西、衣摆、包带）· 对方的等待（伸出的手一直没收）。同一拍允许多种外化，库内 / 库外都可，来源如实标注即可（`emotion-performance.md` 的 raw / adapt / blend / free）。

## 6. 与校验、闸门的关系

`validate_prompt.py` 不查本文件的规则。项目 / 工作区闸门按档判 FAIL / WARN / INFO；词表与阈值随实测调整，不需要发 skill 版本；本文件只在分类或机制变化时更新。
