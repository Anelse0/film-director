# 导演透镜库

透镜是把 `director-grammar.md` 的语法用于**具体场景问题**的方法，不是导演姓名触发器，也不是风格预设。保留 L1–L18 编号以兼容旧项目。每条写：它解决的场景问题 → 作用机制（观众此刻经历什么）→ 可操作的选择 → 检查与边界 → 语法依据。导演名字只在"语法依据"列，用于研究与内部交流；模型正文描述实际画面与声音（硬规则 10）。

## 选择与执行

先用 Mackendrick 三问（`director-grammar.md` §零）明确观众需要看见 / 听见什么，再确定人物、空间、机位与时间。可选固定、运动、coverage 或长镜，不为新颖改变锁定台词和表演。一场戏用一两个透镜就够，不必每次选主 / 副或做反向表；同一场戏保持一种运动逻辑是正常的一致性。

| ID / 方法 | 场景问题 | 作用机制 | 可操作的选择 | 检查与边界 | 语法依据 |
|---|---|---|---|---|---|
| L1 信息差 | 紧张从哪里来 | 观众比人物多知道一件事，之后每个平淡动作都带着"他不知道"的压力（悬念 vs 惊奇） | 前 1–3 秒用插入镜头 / 前景 / 声音让观众先知道危险，再看人物接近或错过它；此后每镜写危险在画内哪里 | 不必每镜重写危险，确保观众记得且因果可理解 | Hitchcock 桌下炸弹；Mackendrick 戏剧反讽（§8.1） |
| L2 纵深调度 | 不切镜能否讲清关系 | 人物在前 / 中 / 后景移动，遮挡与显露自动引导注意力；大小变化就是关系变化 | 走位表先定站点；人物前后移动、遮挡解除、摇移或焦点转移形成新构图；只能一镜时用走位换景别 | 起止位置、走位距离与焦点可执行；15 秒以上的纵深走位交给关键帧或白模 | Spielberg oner；Bordwell 纵深调度（§2.1、§3.2） |
| L3 静止的理由 | 哪个变化值得凝视 | 固定机位让持续的压力自己发生；全片唯一一次运动因此有分量 | 固定镜头突出持续压力或细微推进；必要时小幅靠近，动机是人物内部变化 | 可保留联动表演；静止不是反应不足的自动证据 | Fincher 全知机器；Lumet 节奏变化（§二、§四） |
| L4 画外 | 省略什么更有力 | 事件在画外时观众用听者的脸补全它；比直接拍更大且更稳 | 事件在画外，以声音、物件或听者承接；人物出画后镜头停留 | 不隐藏用户要验证的哭泣高光；延迟时长依据反应 | Ramsay 动作画外脸画内；Haneke 式停留（§8.4、§3.3 出画） |
| L5 实时与背景 | 环境怎样参与故事 | 前景表演与背景活动同时存在，观众自己发现威胁或世界 | 前景静止对话，后景一条动作线从远走近；每镜至少一层非人物运动 | 背景不必固定两条，避免抢走关键表演 | Kurosawa 三层运动；Cuarón 实时长镜（§2.3、§3.3） |
| L6 尺度与沉默 | 人物与环境如何对比 | 大远景里的渺小与近景细节 / 声音的反差 | 远景的渺小与近景细节 / 声音反差；机器"保持距离" | 大小、停留、台词数依意图，不固定比例或限一句 | Villeneuve 保持距离；Kubrick 慢拉（§二、§五） |
| L7 几何与冷面 | 秩序与人物是否冲突 | 平面调度 + 对称 + 常态语气，让异常内容在秩序里显得荒诞 | 人物与后墙平行等距，一点透视，罗盘剪辑（只在 90° / 180° 切）；常态语气与异常内容并置 | 几何不要求每人无表情或所有动作机械重复 | Bordwell 平面调度；Anderson / Kubrick（§3.2、§五） |
| L8 反讽落差 | 期待怎样被改变 | 先建立观众期待，再用动作、语言或结果偏离；落差在并置里产生 | 建立预期，以动作、语言或结果回应 / 偏离；反应可以比事件小一号 | 落差须可理解，不限制只能平静反应 | Mamet 并置；Coen 反应比事件小（§零） |
| L9 视觉喜剧 | 画面或声音怎样制造笑点 | 笑点来自进出画的时机、匹配转场、精确到帧的音效，而不是站着说台词 | 选择出入画、重复变义、剪辑与音效的时机；三拍是选项 | 语言喜剧同样有效，不设镜数上限 | Wright 工具箱（§8.2） |
| L10 主控意图 | 各部门如何属于同一部片 | 一句可裁决的意图协调光、表演、调度随故事发展（Lumet："style is the way you tell a story"） | 用可裁决的意图协调光、表演、调度；一场戏一种运动逻辑与光的性格 | 连贯不等于所有镜头同光、同节奏 | Lumet 镜头情节；Block 对比 / 亲和（§一、§五） |
| L11 镜头并置 | 顺序能否形成含义 | Kuleshov：同一张脸接不同镜头含义不同；情绪来自 A+B | 选择观众看到的信息及其关联；反应放下一镜或下一节拍，不在一镜堆表情词 | 不因为选择并置就删掉用户确认的表演 | Mamet 未加修饰的镜头；Hitchcock POV 三联（§零、§四） |
| L12 可演的策略 | 人物在对对方做什么 | 动词让表演有目标，可见行动由此产生；不映射固定肌肉动作 | 以恳求、试探、回避等目标组织行为，留在 A 层；C 层写人物实际做的事 | 目标不一对一映射动作，纯状态不硬加策略 | Weston 动词不给结果（§3.6） |
| L13 切点取舍 | 为什么在此切 | 观众想看别处的一刻就是切点；情绪 > 故事 > 节奏 > 视线 > 空间 | 比较情绪、信息、节奏、视线与空间代价；切在动作中最隐形；迟进早出 | 可在动作前 / 中 / 后切；选错需有具体证据而非配额 | Murch 六准则与眨眼；Goldman（§四） |
| L14 视点归属 | 观众跟谁看 | 推到观看者的脸把客观事件变成主观体验；POV 三联决定观众成为谁 | 决定看谁、知道多少、何时转移视点；先给反应脸再给所看之物 | 多方反应不等于没有视点，不强制主观镜头 | Spielberg face；Hitchcock 后窗（§一、§四） |
| L15 动能分层 | 热烈如何仍可读 | 尺度、视差、运动三层同时存在才有能量而不乱；缺地理就是噪音 | 前中后景运动、低角度、机器与人物反向转动、色光与声音共同组织能量；先一镜建立地理 | 不填满三层，不用背景运动覆盖主角关键细节 | Bayhem 配方；Jackie Chan 清楚镜头（§五、§8.3） |
| L16 节奏与镜头 | 音乐 / 动作节拍怎样入镜 | 剪切与重音同步或有意错位；观众感知的是节奏变化 | 镜头运动、剪切与重音可以同步（官方"踩着节拍硬切"范例），也可形成反差 | 指明实际接点；不把动作频次精确执行当保证 | Lumet 节奏变化；官方说唱范例（§四） |
| L17 色彩与情节剧 | 怎样容纳外放情绪 | 对比 / 亲和：高潮前亲和蓄势，高潮处唯一的对比色或逆向运动 | 服装、陈设、色彩、姿态与声音可放大关系；一个主光方向与动机光源 | 大哭和大笑可持续，不强制对称配色或平视机位 | Block；Storaro 写光（§五、§六） |
| L19 凝视与克制 | 暧昧 / 爱情怎样不廉价 | 欲望被压到一个泄漏点；错位或对等的凝视、隔层观看、画外的吻让观众自己完成推断 | 并肩不面对面；视线错位或对称正反打；接触 ≤1 秒后切手不切脸；无 bgm；关键动作画外；最多叠三条机制 | 不把克制写成无表情；用户要的告白 / 吻不因本透镜移到画外 | Sciamma 对等凝视；Lachman 隔玻璃；Lubitsch 关门；Wright 手部一抖（§8.5） |
| L18 群戏 | 多人怎样各有生活 | 主交流 + 次交流 + 焦点转移；观众知道该看谁 | 决定主交流、次交流与焦点转移；需要时安排重叠对白；先分组再拆镜 | 身份参考按实际人数绑定，非主角也能有台词；多人嘴型另标风险 | Altman 式群戏为通识；Gerwig 重叠对白（DGA 访谈） |

## 从已核实资料到本地决策

- 语法层面的一手与第三方来源统一登记在 `director-grammar.md` §十，含核实状态；本表"语法依据"列只指向那里。
- [Lumet / DGA](https://www.dga.org/craft/dgaq/issues/0305-may-2003/under-the-influence-sidney-lumet)：视觉与表演随作品意图变化；排练时连走位、道具一起走。对应 L10 与跨镜连续性。
- [ASC：Camera Movement](https://theasc.com/article/shot-craft-camera-movement/)：器材 / 运动从剧本与导演意图出发；推轨与变焦可以是明确的复合动作。对应 L2 / L3 / L15，不把复合运镜一律判错。
- [Gerwig / DGA](https://www.dga.org/craft/dgaq/issues/1802-spring-2018/gen-next-greta-gerwig)：剧场经验与重叠对白参与创作，并尊重写定台词。对应 L18。
- 用户指定某位作者时按所问手法补查第一手资料，不凭本表泛化。

## 误用信号

每个情绪自动选相同透镜；没有需要却多加运镜 / 道具；把画面左右当作角色永久物理位置；为了套名导标签牺牲台词和可见高光；把稳定性建议写成技术禁令；对一张不变的脸缓推（没有内部变化的推近是装饰）。处理时回到具体镜头的三问，不建立更多禁词表。
