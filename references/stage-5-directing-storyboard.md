# S5 导演与分镜设计

输入：已确认剧本页的 S4 有序表演块，或直接表演需求。完整流程按运行模式停靠并附资产清单；直接测试只检查关键部位可见，不触发故事或资产停靠。

产出：`04_shots/scene-XX-clipYY.md`，每个 clip 一个文件，内含若干张分镜卡（模板 `templates/shot-card.md`）。本阶段完成 **A–C 层 + E 层**，D 层留给 S6。

决策依据统一读 `director-grammar.md`（景别 / 运镜 / 动线 / 剪辑 / 构图 / 光 / 载体）；透镜（`director-lenses.md`）是把这些语法用于具体场景问题的方法；术语写法查 `camera-vocabulary.md`。

## 5.0 决策载体（每场戏先定）

Seedance 2.5 的价值在多素材参考。拆镜头前先决定每类导演决策交给什么载体（`director-grammar.md` §七）：

| 决策 | 默认载体 | 换载体的条件 |
|---|---|---|
| 景别、角度、单一运镜、起止状态、台词、声音 | 文字 | — |
| 精确构图、人物在画面的位置、一点透视、前景层次 | 文字 + 场景空镜 | 构图必须严格 → 关键帧图（每镜一张，T4） |
| 复杂走位与机器运动的时序（一镜到底、纵深调度、环绕） | 关键帧 | 需要连续运动 → 粗粒度白模视频（T3 白模变体） |
| 具体动作与节奏（打斗、舞蹈、精细手部） | 动作参考视频（T3） | 无视频 → 文字概括 + 记忆点细写，登记风险 |
| 镜头结构与顺序（不要求精确构图） | 文字"镜头 N" | 用户已有分镜图 → 线稿宫格（T5，≤15 格） |
| 角色外观、场景光与陈设 | 主体图 + 场景空镜（S5b） | 无图 → T1 兜底并登记高风险 |

写进分镜卡头部"决策载体"一行；S5b 据此列资产。用文字驱动 15 秒以上的纵深走位或环绕是高风险项 `[推论]`。

## 5.1 先切生产单元（clip）

规则：

1. 一个 clip ≤ 30 s，整数秒。`[官方]`
2. **clip 边界落在"空间或时间可自然断开"的地方**：人物出画、门关上、转场、黑场、视线离开。不要在一句台词中间切 clip。
3. **每个 clip 有自己的起始状态与结束状态**（谁在哪、朝向、持物、机位）。连续衔接时核对末态与下一初态；有意跳时空（省略、换场）则明确新状态与省略了什么，不强行接成同一瞬间。
4. clip 衔接策略（三选一，写入 E 层）：

| 策略 | 何时用 | 做法 | 标签 |
|---|---|---|---|
| 延长（续写） | 同一空间、动作连续、需要声画无缝 | 上一 clip 输出 MOV → 作为 `@视频1` 输入，Prompt 写"向后延长 @视频1 N 秒，……"；ratio=adaptive；延长可换景别与速度（官方蜜蜂案例），也可引用其他视频作为目标空间（官方美术馆案例） | `[官方]` |
| 尾帧接首帧 | 换镜头 / 换机位但空间一致 | 抽上一 clip 末帧图 → 下一 clip 的 `first_frame`（锁宽高比）或 `reference_image` + "图片 1 为首帧" | `[官方]` + `[第三方]` |
| 独立重生成 | 换场景 / 换时刻 | 只带角色 / 场景参考素材，各自独立生成，靠外观锁与光源描述保持一致 | `[推论]` |

5. 长 clip 后段失败会增加返工成本；先检查负载及局部编辑可行性，再考虑拆 clip，不固定拆成两个 15 s。

## 5.1b 视觉方案（每场戏一个，先于任何镜头）

在拆镜头之前，用 Mackendrick 三问（`director-grammar.md` §零）写这场戏的**观众问题**与**主要调度意图**，并写它回答的场景问题与所用透镜。例：

- "全片唯一一次镜头主动靠近母亲，其余全部固定。"（L3 静止的理由；问题：怎么让一次推近有分量）
- "女儿出画后镜头再停 5 秒不切。"（L4 画外；问题：分别拍不好）
- "观众先于母亲看见包里的车票。"（L1 信息差；问题：不紧张）

规则：
- 用连贯的视觉意图协调多个手法；不因有两个想法就强制拆场。
- 有主控句或导演意图（创意侧概念卡、`ip.md`、用户说明）时指回它；没有时用本场戏的观众问题替代，不因缺创意产物阻塞。
- 写反向测试一行（`anti-mechanical.md` §2）。
- 视点归属：说明观众此刻跟谁、知道什么；可持续或有意转移，不强制全部反应镜头只拍一人。
- 景别序列：写一行本场的微型"镜头情节"（开始广结束窄 / 相反 / 保持），并说明理由（`director-grammar.md` §一）。

## 5.1c 走位表（先于镜头）

按 `director-grammar.md` §3.1，先写走位表，镜头从走位推导：

```
| 秒 | 谁 | 从哪 → 到哪（画面位置与物理位置） | 面朝 | 手里 | 动线含义（§3.3） |
```

持续不动也是一行。轴线在此定：两主体连线，机位在哪一侧；每镜写画左 / 画右。走位表之后做机位设计（§5.1g，必做）。

## 5.1g 机位设计（必做，1.8.0）

走位表定了人在哪，机位设计定**每一镜的摄影机在哪、朝哪拍、画面里左右各是什么**。逐镜设计（§5.2）之前做；之后改了任何一镜的机位或人物位置，回来更新。颗粒度按 clip：一张分镜卡（一个 clip）一段 `## 机位设计`，机位表每镜一行；同一场景的几条 clip 各写各的空间锚点，因为每条的起点取决于上一条的**成片**。分镜卡里写成 `## 机位设计` 段（模板 `templates/shot-card.md`）。查两次：S5 停靠前跑 `python3 scripts/camera_plan_check.py --stage s5 <分镜卡>`，有 ERROR 不停靠；编本条 Prompt 前（S6 入口）再跑一次，不带 `--stage`，复核没做是 ERROR，不进 S6。脚本只查做没做，设计对不对靠下面的核对与复核。

1. **空间锚点**：场景图的视角（这张图是站在哪、朝哪看）；固定物件（门、墙、窗、家具）在主机位画面里的画左 / 画右；门往哪开、门把手在哪一侧；人物的固定站位（例：人站在门右边那截窄墙前，门在他画左）。有上一条 clip 的成片时，以成片末帧为准，不以上一条的 Prompt 为准。
2. **机位表**，每镜一行：

```
| 镜 | 机位在哪（相对固定物件） | 朝哪拍 | 画左有什么 | 画右有什么 | 人物在画面哪里、脸朝哪 | 动作做得出来吗 | 和参考图视角 |
```

3. **核对**，五项逐项写结论：
   - 左右：画面里的左右一律写画左 / 画右，不写人物自己的左右肩、左右手；要指哪只手写"靠门那只手（画左那只）"。人面对镜头时他的右肩在画左，写"右肩旁边"会被生成到反方向 `[实测]`（offset EP06 clip01）。
   - 换边：反打、机位绕到另一侧时，哪个物件 / 谁的视线换了画面边，为什么；能不换就不换。
   - 动作可行：每个动作在这个位置物理上做得到吗（够得着门把手吗、贴墙站的人转身看到的是墙）；一镜的动作塞得下这几秒吗。
   - 参考图视角：机位朝向和场景图视角相反时（反打、屋里朝门拍），正文只写画面里有什么，用这一侧的物件做前景标明机位在哪，不在正文里描写镜头身后东西的样子（地标方向照 E23 写一句"门在镜头身后"即可）；绑定行写"只参考材质与光色，不参考视角和构图"；还压不住就出一张反方向的场景图（S5b）。参考图的视角比文字强 `[实测]`（offset EP06 clip02 镜 8：写了"镜台在镜头身后"，成片照图把机位放回了门外）。
   - 上一条成片：本条首帧的站位、朝向、景别和上一条成片的末帧一致吗。
4. **复核**（每条 clip 一次；上一条成片回来后、编本条 Prompt 前；空间锚点里"上一条成片末帧"写"无"时不用）：同一场景的几条 clip 往往在任何一条生成之前一起设计，起草时只能按上一条的 Prompt 推；上一条成片回来，先抽末帧，再把本条的空间锚点和机位表逐项对一遍，写成 `### 复核` 小节四行：
   - 上一条成片：文件名，生成它的 Prompt 版本；
   - 末帧：人物在画左 / 画右、地标在人物哪一侧、朝向与视线、景别、衣着状态、画面瑕疵（错字等）；
   - 对照：和本卡空间锚点、机位表逐项比，哪里不一致；顺带把整张机位表按成片重推一遍左右；
   - 改动：改了哪几镜（没改写"无"）；发现但按用户决定不改的，写明并在 QA 记一行。
   不一致时先改空间锚点（以成片为准），再改机位表和正文。`[实测]` offset EP06：clip01 成片和它的 Prompt 左右相反，clip02 起草时按 Prompt 写，整条重做；复核时还查出 clip02 镜 2 / 5"机位略偏走廊左侧"和"门在画面中间偏左"互相矛盾（朝门拍时机位偏左，门会落到中间偏右），镜 3 背对门却写"走廊左墙"在画左——用户 10-19 定留作错误样例，见 `tests/test_camera_plan.py` 的 wrong case：脚本只查做没做，这类错照样通过，要靠复核时人重推。

## 5.1d 节奏曲线与声音叙事

**节奏曲线**：先保证表演高光有时间完成且可见，再按信息与情绪选择切点（Murch：情绪 > 故事 > 节奏 > 视线 > 空间）。Lumet：观众感到的是节奏的**变化**——30 秒里安排至少一次镜长或运动的对比，除非有意单调。无需必有静止、最快切、单调镜长或固定停顿；表演时间段不等于镜头切换。

**声音叙事**：按需选择有意义的环境 / 动作声音；纯表演可只留呼吸，不强制声音母题或两次出现。

## 5.1e 调度模式候选

coverage 与长镜调度都是候选，按信息与表演可见性选择；下表是 `director-grammar.md` §3.3 动线语法与 §3.5 三种对话图形的组合示意，不是动作次数 / 停顿配额：

| 模式 | 人物做什么 | 镜头做什么 | 适合的问题 |
|---|---|---|---|
| 逼近与退让 | 一人向前一步，另一人退半步；反复，最后一次不退 | 固定，让距离变化自己说话 | 权力转移 |
| 交叉 | 两人从画面两侧走向中央，擦身而过，各自到对方原来的位置 | 横移跟其中一人 | 立场交换 |
| 揭示 | 前景遮挡物（门框、肩膀、柜子）移开，露出后景的人或物 | 缓慢横移或人物走开 | 信息差引爆 |
| 镜像 | 两人做同一个动作，一先一后 | 双人固定 | 关系对等或讽刺 |
| 前景遮挡 | 主体被前景部分遮住，只露一部分（手、半张脸） | 固定，焦点在被遮者 | 隐忍、偷看 |
| 背景动作 | 前景静止对话，后景一条动作线从远走近 | 固定或极慢推 | 世界感、威胁临近（L5） |
| 出画停留 | 人物出画后按余韵需要停在空景 | 固定 | 分别、失去（L4） |
| 单向长镜 | 一个镜头跟一个人从 A 走到 B，途中经过站点；走位换景别 | 跟拍 | 纵深调度（L2） |
| 几何阵列 | 三人以上等距站位，一人打破阵列 | 全景固定，平面调度 | 制度、荒诞（L7） |
| 三拍 | 看见 → 关上 → 再关一层 | 固定，切在动作上 | 视觉喜剧（L9） |
| 推到观看者 | 人物看向画外，机器推到脸；下一镜才给所看之物 | 缓推止于近景 | 惊奇、恐惧、发现（§一 Spielberg face） |
| 反向跟拍 | 人物朝镜头走，机器后退 | 跟拍 | 不知目的地的张力（§二 Kubrick） |

选模式后再决定镜头数。很多模式一个镜头就够，不要为了"有分镜"而切。

表里的「背景动作」「推到观看者」「反向跟拍」自带类型读法（威胁临近、惊奇 / 恐惧、不知目的地的张力）。轻松场里新人物入场不用它们的原形 `[实测]`：来人写状态（手里、步子、肩膀、神情），发现的人继续手上的事、抬头下巴放平顺着对方的方向看一眼，镜头轻轻跟一点，而不是固定正面近景里慢转头、手停在半路、盯着一个方向压低声音（S4 §4.4b，校验 W35；offset EP05 场 03 clip02 v1 的结尾就是这样被读成惊悚的）。

## 5.1f 变化轨：镜与镜之间的变化（第三条设计轨，与画面轨、台词轨平权）

两条时间轨（`duration-rhythm.md` §二）回答"在哪切、什么时候说"；它们对"切过去以后画面变了没有"什么都不说。1.4.0 的触发案例（`validation-log.md` 2026-09-20）切点逐镜跟随 Prompt、口型都对，用户仍判"画面始终没有变化的感觉"：七镜全固定机位、从镜 3 起全是近景 / 特写、光全程正面、每镜一个同等幅度的微动作、镜长 3/3/2/3/3/3/3、最大动作放在越监视器的中景里且镜头开始时已做完。硬规则 8（机器只在人物动时动）、硬规则 15（一镜一事件）、G6（同构图重复）各自正确，合力就是这串"等长固定机位微动作序列"。变化轨是对它们的第四条约束，在拆镜之后、填分镜卡之前做：

1. **峰值事件**：每条 clip 先声明一个峰值事件——全 clip 最大的物理动作（转身、贴近、出画、击打）或最大的信息变化（看见、认出、被点名）。写 E 层 `峰值镜 | N`。峰值镜拿**最可见的景别**（正面近景 / 双人正面 / 特写，不是全景，不是越肩——前景的肩会吃掉动作幅度）和本 clip **首要的有动机运镜**（如果整条 clip 只允许一次机器运动，就给它）；峰值动作要在镜内发生，不能镜头开始时已经做完。
2. **四维变化**：每镜相对上一镜声明四个维度——景别 / 机位或运镜 / 光 / 动作幅度（0–3）。写在 C 层，格式固定可解析：`【变化：景别 全→近｜机位 固定→推｜光 正→侧｜幅度 1→3】`，首镜写基线值，`=` 表示不变，重复构图第二次加 `｜新增 X`。字段只在分镜卡；S6 汇总到 E 层 `变化轨` 行，不进 Prompt 正文（1.6.0——模型会把「固定→推」「新增 X」当指令）。幅度刻度：0 静止（只有呼吸、眼睛）；1 部位级微动作（嘴角、手指、视线、一滴汗）；2 头 / 手 / 上身的一个动作（低头、递物、转头、挪一步）；3 全身位移或大动作（转身贴近、走位、出画、击打）。
3. **设计下限**（校验 W30–W33，都是审阅项，写明理由可保留）：镜长有对比（最长 ≥ 2× 最短，Lumet："it's the change in tempo we feel"）；至少两个维度在 clip 内各变一次；连续三镜四维零变化要有意为之并在 A 层写明；峰值不落在全景 / 远景或越肩；**无台词段同样受此约束**——`节奏档 | 表演` 选的是检查集，不豁免变化轨。
4. **和其他规则的关系**：机器不动（硬规则 8）时变化要从景别 / 光 / 幅度 / 镜长来；一镜一事件（硬规则 15）管的是镜内负载，镜与镜之间仍要变；G6 的"同一构图重复"第二次必须多一样东西，且写进 `新增`。

写完变化轨再回头看走位表（§5.1c）：峰值动作是不是真的有一段走位在支撑它；四个维度里"光"最容易被忘——同一空间不无故换光（`director-grammar.md` §六），但人物转身、靠近光源、走出主光区都是有动机的光变化。

## 5.2 镜头设计的顺序

对每个节拍，按这个顺序决定，**不要先想运镜**：

1. **观众此刻需要知道 / 感到什么**（信息）→ 决定拍谁、拍哪个部位、画面里最大的东西是什么。表演按 `stage-4` §4.4a 先写满设计稿，再在本镜的"表演翻译"行逐要素翻成模型看得见的写法并写明去处（§4.4c）——拆镜不能把表演拆薄。
2. **机器要不要动** → 只在人物移动或人物内部发生变化（意识到 / 决定 / 被击中）时动；动就写动机、动作、终点。人物静止而机器推近，动机必须是"变化"，不是"有情绪"。
3. **景别、焦距与焦点** → 信息量大用全 / 中景，情绪与部位用近景 / 特写；广角贴脸与长焦压缩是两种情绪；按本场的景别序列决定是否变化，不设跳变要求。**焦点与虚实**（每个有画内人物的镜，1.7.0）：写 焦点在谁（部位）；深景深的双人镜也写——写这一镜为谁的反应而拍的人（offset EP04 s01-clip02 镜1「焦点在 Theo」）；有一层虚（过肩前景、虚化的背景）时写那一层在画面哪里、占多少、主体在哪里清楚（offset 的做法：过肩前景放一个下角、虚焦、只露肩膀 / 发梢 / 下颌线，主体在画面中间清楚——`[推论]` 前景只占角落时变形风险小，`[未验证]`）；焦点变化写先后与秒（"前 1 秒焦点在前景拿杯的手，他抬眼时转到脸上"，`camera-vocabulary.md` 移焦写法 `[官方示例]`）。默认景深在【画面基调】声明一次（深 / 中等 / 浅），镜内只写焦点落在哪；官方范例的写法是"主体清晰、背景自然虚化" `[官方范例]`。清楚的那一层就是观众读的那一层，焦点是可见性条件的最后一环（S4 §4.4 摄影行）。物件 / 身体局部插入镜和关键帧镜（虚实在图里）不要求。校验 W43，E 层 `焦点理由` 可保留。
4. **轴线与视线** → 从走位表与机位设计（§5.1g）取轴线与机位侧；逐镜写画左 / 画右；有意越轴用镜内越过、中性镜头或人物走位重画轴线交代，不能写与走位冲突的"永远画右"。地标与运动同样以镜头为参照 `[实测]`：人物要去的门、车、吧台不在画里时，分镜卡写"门在镜头身后，人物朝镜头走来"，不写"朝门走 / 前面的门"；场景图定了机位朝向时，clip 头部写一句方向（画面是哪一侧、人物在画内朝哪走）供 S6 带进【贯穿要求】（`director-grammar.md` §3.7，校验 E23）。
5. **相对上一镜的变化** → 按 §5.1f 写四维变化字段；这一镜和上一镜至少有一维不同，峰值镜的景别与运镜按 §5.1f 第 1 条。
6. **起止状态与切点** → 核对位置、持物与动作阶段；切点可在动作前 / 中 / 后，动作中最隐形。对话场按 `duration-rhythm.md` §九：切点跟信息走，不跟句号走——一句可跨两镜、尾段画外落在听者 / 插入 / 视线对象；固定机位整句一镜 ≥4 s 触发 W28。
7. **每镜负载** → 一个主要事件 + 至多一个记忆点细节 + 台词与嘴部状态 + 起止状态，其余概括（官方：概括优先、内容过多会被过度剪切）。
8. **时长** → 先安排台词窗口（能力表 §7 预算）和关键动作，再检查同镜同步与前后依赖；不按景别分配固定秒数。clip 总长从内容推导（`duration-rhythm.md` §二 两条轨：台词轨 = Σ词数 ÷ 校准语速 一次取整、连续不断；画面轨切在信息上、整数秒、每镜 ≥2 s；能并进台词镜的动作不单独成镜；时长 = 台词轨 + 无法并轨的无声 + 动作节拍），30 s 不是默认值；对话场镜长目标 2–4 s、无声段 ≤20%（§四、§五）；镜长之间要有对比（最长 ≥ 2× 最短，§5.1f）。

## 5.3 覆盖逻辑（Coverage，可选方案）

按需要选择这些角度，理由是"多个信息点需要分别看清"，不是"有对话"：

```
建立（全 / 中景，两人＋空间＋光源）
→ 关系镜（越肩 或 双人中景，谁主动谁在前景）
→ 说话者近景（台词）
→ 听者反应（按意图呈现变化或有控制的持续状态；反应是 POV 三联的第三件事）
→ 细节插入（手、物件；转折点用）
→ 收束（回到全景 或 单人出画）
```

不是每场都要全部；转折也可以在同一近景中由表演呈现，不强制换景别。双人镜头（two-shot）是关系镜的基本形式，多人口型风险另行登记，不因风险默认拆成单人。

## 5.4 运镜有动机

| 动机 | 运镜 | 写法（动机 → 动作 → 终点） |
|---|---|---|
| 揭示信息 | 摇 / 横移 / 后拉 | "镜头向右缓摇 2 秒，露出门口站着的第二个人，止于两人同框中景" |
| 人物内部变化（意识到 / 决定） | 缓推 | "她看见钥匙的瞬间，镜头用 3 秒从中景缓推到面部近景，止于眼睛在画面上三分之一" |
| 孤立 / 揭示处境 | 缓拉 | "镜头从手部特写缓拉到全景，止于她一个人站在空走廊中央" |
| 跟随行动 | 跟 / 横移 | "手持跟拍，保持人物在画面左三分之一，走到门前停下，镜头随之停" |
| 关系失衡 | 环绕 / 机高变化 | "镜头从平视缓慢降到低角度仰视，止于他占满画面上半" |
| 在场感 / 不确定 | 手持 | "轻微手持晃动，中近景" |
| 审判 / 无处可逃 / 对比基础 | 固定 | "固定机位，全程不动，人物在画内走位" |

**每镜明确主要运动与终点；复合运镜写清同步或先后，避免矛盾。** 热门运镜可直接写，小众术语加描述 `[官方]`。同一场戏保持一种运动逻辑（全固定、或只在人物走位时动）是正常的导演一致性，不是单调。

## 5.5 连续性锁（每个 clip 写一次，易漂移节拍重复）

- 角色外观锁（S1 提炼的一行）
- 空间：主光源方向、主要陈设、门窗位置；画外地标写相对镜头的位置（镜头身后 / 画面深处 / 画左右）
- 轴线：谁在画左谁在画右，机位在哪一侧；人物在画内朝哪走（朝镜头 / 背对镜头 / 画左 → 画右）
- 物件状态：谁拿着、放在哪
- 服装、发型、道具颜色；穿着状态与服装图不同（脱下 / 搭在凳上 / 敞开 / 卷袖 / 换装）时写分段状态（镜 N 起 …，不穿回），绑定行写状态（S5b §5b.3，校验 W45）
- 声音环境

### 关键事件的物理可见性

先验证 C 层自身成立，再核对 D 是否忠实。只对影响事件的空间关系追踪：物件从哪到哪、谁的手在操作、可否同时完成、观众通过哪一机位看见。戏中手机镜头与拍摄本片的摄影机是两个视点。改可见性牵动锁定走位或表演时回上游协商；不要为每句对白塞递物和走位。镜头、表演节拍、台词窗口共用 clip 时间轴，同步时间不相加，串行动作不伪装为同步。

## 5.6 分镜卡（五层）

每镜一张，字段见 `templates/shot-card.md`。clip 头部按需要记录视觉方案、观众问题、决策载体、视点、轴线与节奏；透镜、调度模式和声音母题不是填满清单。表演块正文从 S4 原样承接；其他字段只补缺项，不能拆散已有先后与同步关系。C 层检查项：

```
镜号 / 起止秒 / 景别 / 机高与角度 / 焦距感（可不指定）/ 运镜（动机 → 动作 → 终点；复合时说明关系）/ 构图位置
焦点在谁（部位）/ 虚实分布与位置（有一层虚时）/ 焦点变化（先后与秒）——有人物的镜必写焦点（§5.2 第 3 步，W43）
变化（相对上一镜）：【变化：景别 a→b｜机位 a→b｜光 a→b｜幅度 n→m｜新增 X】（§5.1f；C 层 / E 层，不进 Prompt）
起始状态：谁在哪、朝向、持物
主要事件（一个）+ 记忆点细节（至多一个）；其余动作概括
视线
表演（按 S4 翻译的拍子逐拍写：每拍一句，眼神先，一两个部位，先后；几拍写几句；只在可见景别写部位）
表演翻译：S4 要素 → 本镜可见写法；不可见要素的去处（`stage-4` §4.4c）；台词括号里的意图词（真诚 / 认出熟客 / 不推销）→ 同镜这个人的一个可执行拍子，载体写明（眼神 / 身体 / 声音与停顿 / 互动，由分镜定；轻松 / 随口这类口气词留在括号里即可），"放在语气里"不是去处（§4.4c 第 7 条，W44）
台词：说话人 + 引号原文 + 时间窗 + 语言；非说话者嘴部状态
声音：环境 / 动作音 / 有无 bgm
结束状态
光源方向
```

## 5.7 单镜快车道

用户要"一个镜头 N 秒"：只用一张镜头卡，但保留必要的镜内表演节拍。直接测试按 `emotion-performance.md` 交付，不强制完整卡；起止状态和高光可见性仍需核对。

## 5.8 从已有分镜 / 镜头表进入

用户给了镜头表：逐镜映射到分镜卡字段，缺什么补什么（最常缺：起止状态、运镜终点、视线、非说话者嘴部、光源、声音）。保持用户镜头顺序与景别。快切、镜头过密或多人同框对白属于执行风险，不自动当作硬限制；说明风险与可选调整，不擅自覆盖锁定设计。

## 5.9 常见问题

| 问题 | 可能原因（按顺序排查） | 改法 |
|---|---|---|
| 成片"画面始终没有变化"，切点与口型都对 | 设计本身平：镜长等长、全固定、景别一路相近、光不变、每镜同等幅度微动作、峰值放在最不可见的镜里（成片 = 设计 `[实测]`） | `measure_clip.py` 视觉变化谱确认平在设计还是渲染；平在设计回 §5.1f：先定峰值镜与运镜，再逐镜排四维变化与镜长对比（W30–W33） |
| 生成结果两人对视不动 | 有意持续（先确认）；已写反应未执行；反应写在了不可见的景别；表演块缺状态推进 | 对照 C 层与成片；可见性问题改景别；表演缺口回 S4；剧本层缺口登记交回，不自动添加物件或走位 |
| 切镜后人物无故换边 | 轴线未逐镜写；越轴没有交代；走位后轴线变了没重画 | 逐镜核对画左 / 画右与机位侧；有意越轴用 §3.4 三种合法方式 |
| 成片里人物走反方向（背对镜头走远，像在离开） | 地标写在人物"前面"（朝门走 / 前面的门 / 退向门）而场景图与机位把它放在镜头身后；全局写了机位朝向，镜内仍按人物前方写（`[实测]` offset EP05 clip01 v2） | 门等地标一律写相对镜头的位置，运动写朝镜头 / 背对镜头，视线写"他要去的方向（镜头后方）"；【贯穿要求】加方向句；每镜重写（E23，`director-grammar.md` §3.7） |
| 成片像惊悚（基调是轻松日常） | 反应镜用了悬疑语法：手停在半路、固定正面近景里慢转头看画外来人、盯着一个方向压低声音、来人长焦朝镜头直走没写状态、低头抬眼 / 只转眼珠（`[实测]` offset EP05 场 03 clip02 v1） | 每个反应镜带日常证据（嚼、手上的活不停、压着笑），来人写状态，【贯穿要求】写基调句；S4 §4.4b，W35 |
| 情绪镜头空 | 只写情绪词；或写了部位但景别看不见 | 查外化词典；把部位放到可见景别 |
| 语气没出来 / 表演平（括号里写了真诚、随口） | 态度只在台词括号里，镜头行没有紧挨台词的可执行拍子（任何载体都没有）；动作（抬眼、笑一下）写进了括号 | S4 §4.4c 第 7 条：按分镜定的载体（眼神 / 身体 / 声音与停顿 / 互动）写一拍进镜头行，动作移出括号（W44） |
| 该清楚的脸虚了 / 焦点在错的人 / 过肩前景占得太多 | 标注没写焦点在谁；过肩或虚化层没写在画面哪里、占多少（峰值镜放在越肩里是 W33） | 每个人物镜写 焦点在 X；过肩 / 虚化层写位置与占比、主体在哪里清楚；默认景深在【画面基调】（§5.2 第 3 步，W43） |
| 成片里脱下的外套又穿回去 / 卷起的袖子放下了 | 服装图是整套的样子，绑定行写了"唯一的服装 / 一律按图"，穿着状态只在镜头行 | 绑定行写参考范围与起始状态，【贯穿要求】写分段状态；整条偏离另出一张该状态的服装图（S5b §5b.3，W45） |
| 动作被压缩 | 无关事件挤占时间或高光窗口不足；本镜负载超过一个事件 | 减少无关事件或增时；同一行为的多部位联动不按动作数量删减 |
| 运镜乱动或不动 | 没写终点；复合运镜没写同步 / 先后；文字承载了应交给白模 / 关键帧的时序 | 补终点；换载体（§5.0） |
| 长 clip 后半崩 | 身份漂移、遮挡后未重复外观锁、动作负载过高、时序超载 | 先定位实际失败原因并局部修正（编辑 / 延长）；拆分须保护台词、高光与状态，不默认两段 15 s |

## 5.10 群戏、追逐与大空间

透镜和调度模式偏向两三人的室内戏。以下三种段落需要先画"地图"再拆镜头（`director-grammar.md` §8.3）。

### 群戏（≥ 4 人）
1. 按剧情关系分组，说明主要交流对象与背景活动；人数 / 分组数不固定。
2. 按叙事选择焦点（可单人或群体），画面里其他人按需要给位置（"左后景三人围桌"）。
3. 按实际主体逐一绑定参考；主体图 1–8、主体音视频 1–5 是指南较稳定区间，>4 人稳定性下降（2.0 FAQ）；真正媒体上限见能力表。
4. 台词按人物需要分配，重叠对白与多人口型属于执行风险，给时间窗 / 画内外安排，不自动删除。
5. 群体反应写成一个可观察量："桌边三人同时停下筷子"，不写"大家很惊讶"。

### 追逐 / 打斗
1. 地图三点：起点、一个障碍、终点（或转折点），各给一个可见地标；第一镜建立地理。
2. 明确运动方向，反向时交代空间与触发事件。
3. 每镜写两人的相对位置与方向："被追者在画右三分之一向右跑，追者在画左边缘刚入画"，距离用身位数；攻与受尽量同框。
4. 常规动作概括，关键接触点细写；切点落在击中而非挥出。
5. 精确动作交给动作参考视频；文字只补视频里没有的（表情、台词、声音、场景）。
6. 快动作、快切与复杂物理分别登记执行风险，不设置统一镜数和秒数配额。

### 大空间（跨越多个房间 / 街区）
1. 同一 clip 可以跨空间；明确路径、切点和新空间，超出时长承载才拆 clip。
2. 每个空间开场一镜交代出入口与主光源。
3. 人物穿过门 / 转角时重复外观锁一行。`[第三方]` 遮挡后重复身份。
4. 声音环境随空间变化，写清变化的秒数（"第 6s 穿过门后街道噪音进入"）。
