## 2. 任务类型与"锁定"规则 `[官方]`

三种场景互斥：图生视频-首帧、图生视频-首尾帧、全模态参考生视频（含参考图 / 视频 / 音频）不可混用。Seedance 2.5 按"传入素材是否锁定输出属性"把任务分为两类：

### 有锁定（素材成为输出时间轴的一部分）

| 任务 | 触发条件 | 锁定内容 | 参数要求 |
|---|---|---|---|
| 视频编辑 | 至少一个 `reference_video` ＋ 提示词含"编辑视频 / 增加 / 加上 / 删除 / 去掉 / 修改 / 替换 / 改成"其一 | 宽高比对齐待编辑视频；时长基本对齐（输出可能非整数秒，可能略短，误差 ≤0.4 s；PDF 写 0.3 s） | `ratio = adaptive`，`duration = -1`，建议 `output_format = mov`；输入视频 [4, 30] s |
| 首帧 / 首尾帧 | `content.role` = first_frame / last_frame | 宽高比对齐首帧图 | `ratio = adaptive`；时长可自定义或 -1；首尾帧画幅需一致否则尾帧被拉伸 |
| 视频延长 | 至少一个 `reference_video` ＋ 提示词含"向前 / 向后延长、延续、续写"其一 | 宽高比对齐待延长视频 | `ratio = adaptive`；时长可自定义或 -1；建议 mov |

多输入视频时由模型根据提示词判定哪一段是待编辑 / 待延长对象。编辑 / 延长任务中直接用 `@视频1` 指代，不要写"参考 @视频1"，以免被判为参考任务（2.0 指南）。

### 无锁定（仅语义参考，用户自定 ratio / duration）

- 主体参考（图 / 音视频 / 图＋音色）
- 运动参考（动作 / 表情 / 运镜 / 创意 / 特效）
- 白模参考 / 渲染（粗粒度：简单几何体；细粒度：完整建模"白模上色"，不含轨迹线 / 坐标线 / 相机 cone）
- 风格参考（图 / 视频）
- 音频参考（音乐 / 台词 / 音色；可仅音频）
- 多宫格分镜 / 故事板参考：**不严格对齐分镜图**，只提供大致剧情；约 15 格以下更适合（建议）；推荐火柴人 / 线稿；分镜图上少写字
- 关键帧参考：**相对严格对齐**；按顺序传入独立图片；Prompt 第一句写"以图片 x 至图片 x 的顺序作为关键帧"
- 一键成片、视频无缝转场、以上能力自由组合

也可用 `reference_image` role 并在 Prompt 中写"图片 1 为首帧 / 图片 3 为首帧，图片 5 为尾帧"——不锁定宽高比，效果相近但不完全匹配。

## 3. 素材数量与稳定性 `[官方]`

| 场景 | 建议 |
|---|---|
| 主体音视频参考 | 1–5 个主体效果好；6–10 稳定性下降需抽卡；单段 5–10 s 效果好 |
| 主体图参考 | 1–8 个主体效果好；9–12 需抽卡；≤5 主体单视图 / 多视图均可；>5 主体建议单视图，多视角拆成多张图而非一张拼图 |
| 宫格分镜 | 约 15 格以下更适合（建议）；18 宫格易静止、顺序错乱；不推荐过度锐化 / 杂乱的 AI 直出分镜图 |
| 白模 | 粗粒度（简单几何体）效果好；主体只保留躯体，含四肢 / 翅膀需补全动作序列；细粒度白模不要含轨迹线 / 坐标线 / 相机 cone |
| 视频编辑输入 | ≤20 s 效果好 |
| 视频参考图编辑 | 1–5 张参考图效果好；6–8 需抽卡 |
| 延长 | 输入输出均用 mov；用 2.5 自己生成的视频做延长音量变化更小、衔接更好；延长后音量可能轻微变化 |
| 参考人物数 | >4 人稳定性下降（2.0 FAQ）→ 可分组生图再图生视频 |

## 4. Prompt 写作规则

### 4.1 官方结构 `[官方]`

2.5 指南四段式：
1. **素材指代**：每个图 / 视频 / 音频的编号（按上传顺序）与用途（谁是形象、谁是音色、谁是动作、谁是场景）。
2. **一句话概述**：主体 + 地点 + 事件 + 题材 / 风格 + 特殊运镜。
3. **具体情节**：用时间戳或"镜头 N"切分，逐段写画面、运镜、动作、台词、音效；正向描述。
4. **结尾**：贯穿始终的细节（机位 / 运镜、环境、声音、氛围）。

2.5 教程"基础公式"：**主体 + 动作 / 事件 + 场景与环境 + 视觉风格 + 运镜 / 切镜 + 声音**，不需要的部分可省略。官方心法："把 Seedance 2.5 当作一个视觉内容生产者，用导演的思维书写结构化 Prompt。"

官方范例（PDF p.20 九宫格案例）另用了 【主体设定】【整体风格】【严格排除】【分镜头】 四个标签，其中【严格排除】列媒介 / 风格排除（黑白、单色、手绘、线稿、分镜稿、塑料 CG…），是**风格级负向的官方示范**。

### 4.2 素材指代 `[官方]`

- 按上传顺序编号：图 1 / 视频 1 / 音频 1（`@图片1` / `@视频1` / `@音频1` / image1 / `<video1>` / `<2pic>` / img1-2 等写法指南内混用，均可）；不支持用 Asset ID 指代（2.0 教程）。
- 每个素材文本绑定；**不建议只在图片里写名字**然后 Prompt 直接用名字——易混淆或重复角色。
- 多主体逐一列清映射；人多用清单。示例："img1-2 是人物 1，对应音频 1；img3-4 是人物 2，对应音频 2"；"图片 1 是主角张三，图片 1 使用音频 1 音色"。
- 分工具体到"参考什么 / 不采用什么"："参考视频 1 中施法的动作，视频 2 的环绕式运镜"；"参考图片 1 的光影和滤镜"。
- 参考素材本身足够精准时只做指代、少复述："严格参考视频 1 的动作与运镜，顺序与视频保持一致"。
- 官方案例把参考绑定写在每个时间段内：白模案例"0-3s（首帧参考 <2pic>）……5-8s（参考 <4pic>）"；关键帧案例每镜写"@图片N"。**分段绑定是官方写法**，不只在开头列表。
- 越需要精准参考的素材放在提示词里越靠前（2.0 FAQ）。
- 数字粘连防歧义：`@图片1跑向…` 易误读，写 `图片1 中的女子` 或先定义主体名（2.0 官方 Skill）。

### 4.3 时间戳 `[官方]`

- 以 1 秒为单位；写整数秒。
- 区间必须连续："0-3 秒……3-7 秒……7-15 秒" 或 "[1s-4s]…[4s-8s]"；避免"0-3 秒…5-6 秒"这种断裂。
- 支持时间点（"第 5s 快速向左横移转场"）和相对时间（"3 秒后周围的人纷纷摇头"、"按下快门后画面定格 1 秒"）。
- **时段内容太少 → 模型自由发挥；太多 → 过度剪切或剧情遗漏。** 这是官方对信息密度的唯一定量表述，本 Skill 的每镜负载规则（`stage-6` §6.2）据此推导。
- **不要用时间戳控制频次**（"一秒摇头 3 次"）。
- 官方 30 秒范例的镜头密度：9 镜 / 30 s，最短 2 s（PDF p.20）；20 秒说唱范例 8 镜 / 20 s，最短 2 s，全部硬切（教程多语言案例）。据此本 Skill 不设"≤8 镜"之类硬限，只对 <2 s 的镜头与 >10 镜 / 30 s 提示审阅 `[推论]`。

### 4.4 负向控制 `[官方]`

- 指南明确支持字幕和音频的负向控制："不要字幕" / "不额外加入对白字幕"；"无 bgm，只生成环境音和动作音" / "不要任何声音"。没有独立 negative prompt 参数，全部写在正文。
- 音频可分维度单独控制：音效、bgm、对白。
- 画面尽量正向描述；官方范例也有媒介 / 风格排除段（§4.1）和"无字幕、无文字叠加、无叠化转场、无重复人物"之类句子（教程说唱案例）。这些是官方示范的写法，不是执行保证；2.0 FAQ 承认"目前无法直接做到 100% 避免生成字幕"。"不眨眼 / 忍住不哭"是行为控制，不为正向改写破坏语义。

### 4.5 镜头语言 `[官方]`

- 通识术语可直接写：景别（大全景 / 全景 / 中景 / 近景 / 特写）、运镜（推 / 拉 / 摇 / 移 / 跟 / 环绕 / 俯冲 / 后拉 / 上摇 / 手持晃动）、机位（低角度 / 俯视 / 第一人称）。1.0 指南另列：升、降、变焦、水下、航拍、高机位俯拍、低机位仰拍、微距、"以 xx 为前景的镜头"。
- 热门运镜可直接写：一镜到底、希区柯克变焦、航拍视角、FPV、子弹时间、手持镜头、回弹变速。
- 小众术语 → **术语 + 描述性解释**："移焦，画面焦点发生平滑转变，原本在前景清晰的树木变模糊，背景中的人物由模糊逐渐变得清晰。"
- 转场写清触发时间与方式："第 5s 快速向左横移转场（向左擦除＋自然叠化）"；教程范例在每镜末尾写"硬切"/"HARD CUT"。
- 2.0 指南："一个镜头里尽量只指定 1 种运镜方式"——2.5 指南未重申；本 Skill 视为降低复杂度的建议，复合运镜写清同步 / 先后即可 `[推论]`。
- 教程说唱案例的运镜写法可直接借鉴："低角度大远景定场，斯坦尼康在黄金夕照与海雾中缓缓推进"、"微距插入镜头，固定机位"、"3/4 侧中景，缓慢潜行环绕"、"快速横移轨道掠过他"、"手持快速上摇"、"紧凑猛推，富攻击性的手持"——即 **景别 + 机位 / 角度 + 运镜方式 + 速度 + 质感** 五要素。

### 4.6 动作与表情 `[官方]`

- 动作优先概括描述（"连续做了几组高抬腿和空翻"），只在有记忆点的动作上写细节；不重复写相同动作。
- 表情写描述性语句，少用成语："津津有味地吃饭" → "脸上带着满足的笑容，大口地吃饭"。
- 2.0 指南："肢体细化 + 程度量化"；"优先低缓连续小动作，规避狂奔、大跳、剧烈翻滚"；"补充动作过渡衔接"。
- 博客承认的弱项：复杂运动的物理合理性、多主体互动场景的稳定性。

### 4.7 编辑类 `[官方]`

- 明确修改范围与内容，可配时间戳；尽量写 A → B 的过程。
- 示例："仅编辑视频 1 中男人的台词，修改为「你不要过来啊」，口音调整为东北口音"；"把视频 1 中 4-6 秒男人喝咖啡的动作改变为拖地，其余内容不要变化"；"将视频中的人声台词翻译成中文，无字幕，口型做出对应的精准改变，其余均保持不变"；API 示例 "视频编辑：删除 @视频1中的所有人，除了主角。"
- 延长示例："在 @视频 1 的基础上续写 5 秒的视频，讲一只蜜蜂飞来落在画上，接着微距特写……慢镜头中……"（延长可换景别与速度）；API 示例 "延长@视频1，窗户打开后进入@视频2的美术馆室内，最后镜头进入@视频3的画内"（延长可引用其他视频作为目标空间）。

### 4.8 台词与声音

- 官方范例写法：`台词 (老奶奶): "Fly safe, my child. Come back to me."`，逐镜绑定 `[官方]`；API 文档："建议将对话部分置于双引号内以优化音频生成效果" `[官方]`。
- 2.5 教程 / 2.0 指南的**符号规范**：台词 `{}`、音乐 `()`、音效 `<>`、字幕 `【】`；非中文台词在台词前明确语言（"用日语说道{こんにちは}"）；台词语言统一，避免中英混用（专有名词除外）`[官方]`。本 Skill 的 `台词（角色，a-bs，语言）："…"` 写法与官方引号范例同源；`{}` 是可选等价写法，两者不混用 `[推论]`。
- 音色："使用 @音频1 …的音色说"；台词风格与参考音频语气相近；音色不准时补文字音色描述 `[官方]`。
- 多音字 / 生僻字读错 → 换同音常用字（"螭龙山"→"吃龙山"）`[官方]` 2.0 FAQ。
- 口型：中文最稳，英文其次，日 / 韩长句偶有漂移 `[第三方]`；多人口型同步与偶发音频失真是 2.0 技术报告承认的未解决问题，2.5 博客仍列"多主体互动稳定性"为待改进 `[官方]` → 多人同框同时说话是高风险，但双人镜头本身不是禁区；按 `stage-4` §4.5 给时间窗与画内外安排 `[推论]`。
- **官方没有给台词长度 / 语速规则**（2.5 指南、2.0 指南、API 文档均未说明）`[官方未说明]`。官方 30 秒范例隐含速率：8 句英文台词中 7 句在 0.75–3.0 词/s，第 9 镜要求 2 s 内说 10 词（5 词/s），说明范例本身不按语速预算。本 Skill 的每秒台词预算见 §7。

## 7. 台词每秒预算（英文 / 中文）

官方未给规则（§4.8）。以下是本 Skill 的估时假设 `[推论]`，依据一手语音学与行业标准，用于 `validate_prompt.py` 的 W05 估时与 S5 的时间窗设计；可用 E 层 `语速词每秒` / `语速字每秒` / `台词占比上限` 覆盖。

### 7.1 一手依据

| 来源 | 数值 | 标签 |
|---|---|---|
| NCVS（美国国家嗓音与言语中心）Voice Qualities 教程：“The average rate of speech for English speakers in the United States is about 150 words per minute” | 150 wpm = 2.5 词/s | `[一手]` https://ncvs.org/tutorials/voice-qualities/ |
| Tauroza & Allison 1990 *Speech Rates in British English*（Applied Linguistics 11(1)）：广播独白 150–170 wpm；访谈 160–210；日常对话 190–230 | 2.5–3.8 词/s | `[一手]`（经转引核对） |
| Yuan, Liberman & Cieri 2006 *Towards an integrated understanding of speaking rate in conversation*（电话对话语料）：英语 Fisher 约 193 wpm，CallHome 约 214 wpm；话题影响 152–170 wpm；陌生人之间更慢 | 2.5–3.6 词/s | `[一手]` 论文 |
| Netflix Timed Text Style Guide（英语）：成人字幕阅读速度 ≤20 字符/s，儿童 ≤17；每行 ≤42 字符 | 20 cps ≈ 3.3–4 词/s（含空格，英文均词长约 5–6 字符） | `[一手]` 行业标准 |
| 中文配音行业经验：配音员正常语速约 4 字/s；旁白 200–220 字/分（3.3–3.7 字/s）；新闻播音 280–300 字/分（4.7–5 字/s） | 3.3–5 字/s | `[第三方]` 行业站点，数值互相一致 |
| Banse & Scherer 1996（JPSP 70:614）：情绪影响发音速率，热怒 / 惊恐更快，悲伤 / 厌倦更慢 | 方向性结论，不给固定倍率 | `[一手]` |
| 第三方 Seedance 经验：一句 5–10 词最稳；一镜最多两句；长句 8 s 后口型变糊 | 与 2–2.5 词/s 一致 | `[第三方]` |

### 7.2 本 Skill 取值

- **英文默认 2.5 词/s**（NCVS 均值；对话语料更快，但影视台词含停顿、呼吸与反应，取均值偏保守）；**中文默认 4 字/s**（配音语速）。
- 快语速 / 争吵可显式写 3.0–3.5 词/s、5 字/s；慢语速 / 悲伤 / 低声可写 1.5–2.0 词/s、3 字/s。情绪只决定你显式写的语速，脚本不从情绪词推算。
- **台词占比上限默认 2/3**（密对白 3/4）：一镜里台词不占满，留起音延迟、句间停顿与反应。

### 7.3 英文词数预算表（按默认 2.5 词/s；含停顿的"净说话时间 = 窗口 × 占比"）

| 镜头 / 时间窗 | 慢（1.5 词/s） | 默认（2.5 词/s） | 快（3.5 词/s） | 说明 |
|---|---|---|---|---|
| 2 s | 2 词 | 3–4 词 | 5 词 | 只够一个短句或感叹 |
| 3 s | 3 词 | 5 词 | 7 词 | 官方范例 "Don't look up. I've got you."（6 词 / 3 s）在此档 |
| 4 s | 4 词 | 6–7 词 | 9 词 | 官方范例 "Fly safe, my child. Come back to me."（8 词 / 4 s）偏上沿 |
| 5 s | 5 词 | 8 词 | 12 词 | 第三方"5–10 词一句"的甜区 |
| 8 s | 8 词 | 13 词 | 19 词 | 超过 10 词应拆两句并留停顿 |
| 10 s | 10 词 | 17 词 | 23 词 | 一镜两句的上限 |
| 15 s | 15 词 | 25 词 | 35 词 | 多句，需要写句间停顿与听者状态 |

算法：词数 ≈ 窗口秒数 × 语速 × 2/3；表中已取整。中文把语速换成 3 / 4 / 5 字/s 同法计算（5 s 默认约 13 字）。超出预算的台词在 W05 出现"接近或超过窗口"提示；处理顺序：先延长时间窗或拆到下一镜，再考虑显式提速，不删改用户锁定台词。
