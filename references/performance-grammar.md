# 表演语法：把 25 条情绪原文用到极致

`assets/emotion-library.json` 的 25 条原文是**单一情绪、单张脸、一次完成**的部位级描述。真实的人物表演却是叠层的（面具下有泄漏）、过渡的（从一种状态滑进另一种）、被看见的（景别决定哪个部位可读）、被剪辑赋义的（前一镜决定观众怎么读这张脸）。本文件给出把原文组合成人物表演的语法，是 S4 的判断工具，不是新的配额或模板；`emotion-performance.md` 的模式（raw / adapt / blend / free）、保真契约与交付规则不变。

标签：`[官方]` 火山方舟 2.5 指南原文 · `[官方示例]` 指南案例展示的写法 · `[一手·摘要]` 导演 / 摄影师 / 研究者本人或 DGA · ASC · BFI 等机构的一手材料，本次仅读到搜索摘要、未通读原文 · `[推论]` 本 skill 的设计推论。

## 1. 为什么这 25 条正好是模型要的写法

- 指南要求表情"写描述性语句，减少成语"，动作"优先概括、只在少数有记忆点的动作上写具体细节、不建议重复写相同的动作" `[官方]`。25 条原文全部是部位级描述句（眉、眼睑、嘴角、下颌、肩、呼吸），没有成语，没有情绪名——它们就是官方要的那种句子。
- 官方线稿分镜案例把情绪词与可见证据并写："眼眶泛红，泪珠缓缓滑落，神色感伤"、"温柔浅笑……眼底带着怅然" `[官方示例]`；编辑案例把一条情绪弧写成渐变链："眼神里的隐忍慢慢化开，泪光滑过眼角，嘴角一点点扬起，最后破涕为笑" `[官方示例]`。这印证了本 skill 的"标签定位、证据成立"与"渐变词是执行信息"两条写法。
- **部署密度**：由"只在有记忆点处写细节、不重复"推出——完整原文（或译写）只放在高光节拍；铺垫与余韵节拍写概括与衔接（"仍低着头"、"呼吸慢下来"），用相对时间把顺序钉住。把三条原文首尾相接塞进 10 秒，是"时段内容过多→过度剪切或剧情遗漏"的典型 `[官方]`。

## 2. 可靠信号：压缩时留什么

Ekman 把难以自主做出的面部动作称为 reliable facial expressions（可靠信号），并在《Emotions Revealed》中给出恐惧、愤怒、惊讶、悲伤的可靠信号；最著名的一条是 Duchenne 笑：真笑时眼轮匝肌参与（眼角出纹），做出来的笑没有 `[一手·摘要]`。25 条原文里对应的位置：条目 1 的"眼睛挤成带笑纹的细缝"与条目 25 的"眼角没有笑纹"是同一条信号的正反面；条目 19 的"内眉角上提聚拢"、条目 3 的"眉上提并拢 + 不眨眼"、条目 4 的"上唇掀开 + 鼻翼 + 颈腱"是各自家族里最难伪装、也最难被换掉的部分（部位对应关系为本 skill 的阅读 `[推论]`）。

每条的识别性信号记在 `references/emotion-index.json` 的 `hinge` 字段。用法：

- **时间不够 / 景别太紧 / 要合并两条**时，先删外围动作（手的位置、身体转向），最后才碰 hinge；删到 hinge 就不再是这条了，应改标 free。
- **改编时** hinge 是 `keep` 的默认候选，理由不用重复写"识别性细节"，写它在这场戏里为什么重要。
- 索引里的 `hinge` 不是"必须出现的通道数"，一条只需一个 hinge 成立。

## 3. 可读性地板：景别决定 hinge 能不能被看见

Hitchcock 说他坚持"影像的尺寸随其情绪重要性而变化" `[一手·摘要]`；Bergman 说"我们在电影里的工作从人脸开始"，正确打光、导演、表演的特写是电影摄影的顶点 `[一手·摘要]`；Villeneuve 在《沙丘 2》里主要用大远景与大特写，为的是"尽可能贴近保罗的情绪体验" `[一手·摘要]`。这些都指向同一个决定：**景别先服从此刻的情绪重要性，再服从信息量。**

反面同样成立：Sonnenfeld 说"没有什么比特写更能扼杀喜剧"，喜剧在全景或双人镜里最好，因为动作与反应在同一镜里 `[一手·摘要]`。所以"情绪 → 近景"不是定律，是要与语域一起判断的默认。

索引的 `readability` 字段给每条 hinge 的最小可读景别（特写 / 近景 / 中近景 / 中景，本 skill 估算 `[推论]`），`wider_parts` 列出脸框以外才看得见的部位：

- 镜头比地板紧：把 `wider_parts` 从正文删掉（在特写里写"肩膀向后展"是浪费秒数，也是执行风险），或把它放进一个插入镜。
- 镜头比地板松：hinge 可能读不出来（全景里的单侧嘴角），要么切进一个特写落在 hinge 上，要么换一条 hinge 更大的条目（如把 9 怀疑换成 5 厌恶的整头后缩）。
- 一条原文里同时有面部 hinge 和身体扩展（16 坚定：下颌绷紧 + 肩后展 + 点头）时，在"特写→中近景"两镜里拆开写，比在一镜里挤更稳。

## 4. 时间包络：起动、保持、消退

Ekman 与 Friesen 把微表情定义为 1/25 到 1/2 秒的极快面部动作，宏表情通常持续半秒到四五秒 `[一手·摘要]`。对模型的含义 `[推论]`：亚秒级的"闪过"既不可靠执行也难以看见，不写；每条原文的最短可读时长记在索引 `min_seconds`（本 skill 估算），渐进类（6 哭、12 无聊、15 敬畏、22 疲惫、23 释然）需要比骤发类（2 震惊、7 疼痛）更长。

**顺序关系用相对时间写，比亚秒时间戳更忠实也更稳** `[官方]`：指南支持"3 秒后周围的人纷纷摇头"、"按下快门后画面定格 1 秒"这类相对时间控制，也支持"第 5s"时间点。原文里最重要的关系正是这类："只有在这口气吐完之后，笑容才出现"（23）、"冻住直到眨了一次眼"（2）、"吞咽没有改变表情"（19）。写法：

```
节拍 b2（4-8s）：……一口大而可见的呼气把胸口排空，肩膀向下塌。呼气完全结束后 1 秒，一个细小、发颤的笑容才出现，并保持到节拍结束。
```

不写"4.0s 呼气、5.5s 笑"，也不写"一秒内眨眼 3 次"（指南明确不建议用时间戳控频次 `[官方]`）。

## 5. 家族阶梯：同一情绪的强度递进与"控制失败"的铰链

库里几对条目本来就是同一家族的不同强度，把它们按序排开就是一条弧；关键不是"越来越大"，而是**哪个部位先失控**。以下铰链为本 skill 的阅读 `[推论]`，索引 `ladder` 字段记录位置：

| 家族 | 阶梯 | 失控的铰链（从上一级到下一级，最先变的部位） |
|---|---|---|
| Sadness | 19 悲伤 → 6 哭泣 | 19 的"吞咽没能改变表情"是最后一道控制；失控从**下眼睑积泪**开始，然后嘴拉成方形、下巴皱缩，肩最后才抖。憋住 = 停在积泪与吞咽之间，见示例 02；失守 = 走完，见示例 03。 |
| Fear | 18 焦虑 → 3 惊恐 | 18 的眼是"左右快扫"，3 的眼是"睁大锁死不眨"；铰链是**视线停止扫动并锁定**，同时呼吸从浅快变成可见的胸口起伏。 |
| Anger | 17 挫败 → 4 暴怒 | 17 的下颌"左右滑动"、闭眼；4 的眼睁开、**上唇从牙上掀开**。铰链是眼睛睁开的那一刻。反向（4 → 17）是露出的牙被合拢、下颌开始左右滑。 |
| Joy | 25 假笑 / 21 害羞 → 1 大笑 | 铰链是**眼角出纹**（25）或**压住的双唇分开**（21）；示例 04 走的是 21 → 1。 |
| Physical | 22 疲惫 ↔ 12 无聊 | 两条都以长眨眼、下颌松为底；区别在 22 的"头沉再慢抬"与 12 的"身体安顿进静止"。 |
| Surprise | 13 困惑 → 14 领悟 → 2 震惊 | 13 的**不对称眉归位**是进 14 的铰链；14 的慢点头如果被眼白露出、下颌全开打断，就是 2。 |

用法：需要"从 A 到更强的 A"时，不把同一条原文写两遍再加"更剧烈"，而是走阶梯：上一级正文 → 一句铰链 → 下一级正文。

## 6. 过渡铰链：跨情绪时哪个部位先变、哪个部位持续

跨家族的过渡（愤怒 → 委屈，怀疑 → 领悟）需要一句"中间态"，它既不是 A 的原文也不是 B 的原文，而是**A 的一个部位松开、B 的一个部位先到**。示例 05 的写法是范例：怒相的"头向前顶"停下 → 颈部绷紧松动 → 内眉角上提（这是 19 的 hinge 先到）→ 露出的牙被合拢的双唇遮住（4 的 hinge 退场）→ 嘴角下拉。

索引 `neighbors` 字段为每条列出最常衔接的条目和桥梁部位。写过渡时的三个检查：

1. **一次只换一个部位**作为铰链，其余部位在下一句跟上；同一秒里眉、嘴、头全换会读成跳变。
2. **持续项要点名**："鼻间粗重的呼吸还在"——B 到来时 A 的哪个证据仍在，观众靠它知道这是同一个人在变，不是两条表演拼接。
3. **末态归属**：过渡后的末态按 B 的原文，不自动回平静（`emotion-performance.md` 的规则），也不为对称把 A 的末态搬过来。

## 7. 面具与泄漏：一张脸演两层

人物很少只有一种情绪：他在笑，但眼睛在说别的。Ekman 把这叫 leakage——试图掩饰情绪时，真实情绪会从脸上泄漏出来，或局限在一个区域，或作为快速闪过的表情 `[一手·摘要]`。条目 25（紧张的假笑）本身就是一个现成的面具模板：**嘴在笑、眼是平的、眨眼加快、吞咽、视线掉下、笑迅速回位**。

写双层表演的分配法 `[推论]`：

- **表层条目占嘴、下巴、姿态**（能自主控制的部位）：25 假笑、24 自豪、11 得意、16 坚定、10 调情、12 无聊都常做表层。
- **泄漏条目占眼、眉内侧、呼吸、手**（难以自主控制的部位）：19 的内眉角、6 的下眼睑积泪、18 的眨眼加快与下唇夹齿、3 的胸口浅快呼吸、4 的鼻翼与颈腱。
- **句式**：表层句 →"但 / 同时"→ 泄漏句 →"面具回位"句。回位句是这层写法的标志：没有它，读起来只是情绪切换。

```
她把嘴角拉成一个笑，下巴微抬；但眉毛内侧的角向上聚拢了一下，眨眼明显加快。喉咙用力吞咽一次，视线掉下去，随后那个笑迅速回到脸上，眼角仍然没有纹。
```

Caine 在表演课上说特写里越少越强，眨眼会削弱你，而不眨眼的人让观众开始听他说话 `[一手·摘要]`。这解释了为什么"憋住"在近景里比"哭出来"更有力量：控制行为（不眨、合唇、稳住下颌）本身是可见证据，而且它把观众的注意力钉在等待失控上。所以高强度 + 强克制的写法不是把幅度调小，而是**写控制动作**（`emotion-performance.md` 的克制维度），泄漏只给一个部位。

## 8. 听者与反应镜：让剪辑替脸干活

Kuleshov 的实验（Pudovkin 记述）：同一张中性的脸，接在一碗汤、一具棺材、一个女人后面，观众分别读出饥饿、悲痛与欲望，并"称赞演员的表演" `[一手·摘要]`。Hitchcock 在 1964 年的电视访谈里用自己的脸重演了这个效果，称之为"纯电影"：换掉他看到的东西，他从慈祥的人变成"老色鬼" `[一手·摘要]`。

对反应镜的含义：**听者的脸不必自己完成全部情绪，前一镜已经替它说了一半。** 所以：

- 反应镜优先用 subtle 条目（9 怀疑、13 困惑、14 领悟、19 悲伤、25 假笑、8 翻白眼、12 无聊）或只写一个部位的变化；explosive 条目留给动作镜。
- 反应镜的顺序是"看见 → 变化"：先写视线落到哪里（或前一镜给了什么），再写部位变化。倒过来就是"先看脸再报名"的反向节奏（`stage-5-directing-storyboard.md` 5.1d）。
- 听者的地位由他人的反应赋予：Patty Jenkins 谈《神奇女侠》那一镜时说，她挑选群众演员就是为了他们的反应，"这一镜全是表演" `[一手·摘要]`——亮相与宣布场里，群体反应镜是主角情绪的一部分，写成一个可观察量（"桌边三人同时停下筷子"）。
- 听可以是持续控制住的状态，不强迫每句配新动作（`stage-4-performance.md`）。

**切点落在思想完成处**：Murch 发现好演员在一个完整想法结束时眨眼，剪辑点应落在那里；他的"六律"把情绪放在第一位（51%），其后是故事、节奏、视线、二维、三维，放弃时从底部放起 `[一手·摘要]`。25 条原文里的"眨了一次眼"（2）、"缓慢的眨眼"（19、24、10）、"吞咽"（19、20、25）、"呼气结束"（23、17、22）正是自然切点：**把镜头边界放在条目的眨眼 / 吞咽 / 呼气完成之后，而不是放在表情中途。** 这也是为什么"一句一切"不能机械执行——切点要落在听者的眨眼上，而不是说话者的句号上。

## 9. 多人与群体

一人一条目，同一节拍里各写各的主语与部位；群体反应写成一个动作（"三人同时抬头"），不给一群人贴一个情绪词。两人同框时给每人一个不同的 hinge（一个在眉、一个在嘴），观众才分得出谁在变。

## 10. 语言

索引的 `zh` 字段是每条原文的中文译写（保留顺序、同步关系与末态，不加戏）。用它进 Prompt 属于 adapt，记录里写"中文译写"即可；raw 模式仍只交付英文原文。译写有歧义的地方（条目 17 末句）在 `notes` 里说明，译写时选定一种并写在 changes。

## 11. 检索

```bash
python3 scripts/emotion_library.py --id 19 --zh          # 原文 + 译写 + hinge / readability / neighbors
python3 scripts/emotion_library.py --neighbors 4         # 从暴怒能滑向哪些条目，桥梁部位是什么
python3 scripts/emotion_library.py --ladder Sadness      # 一个家族的强度阶梯
python3 scripts/emotion_library.py --readability 特写    # 在特写里 hinge 可读的条目
python3 scripts/emotion_library.py --listener            # 适合反应镜的条目
```

检索只找候选；选择前仍要读完整正文与关系提示。

## 12. 误用信号

- 每个节拍都贴一整条原文，10 秒里三条首尾相接（部署密度）。
- 特写里写肩膀与双臂，全景里写单侧嘴角（可读性地板）。
- "更悲伤"写成同一条原文加"剧烈"，而不是走阶梯。
- 过渡一句话里眉、嘴、头同时换，没有持续项。
- 面具层没有回位句，读成情绪切换。
- 反应镜从脸开始写，不写他看见了什么。
- 用亚秒时间戳钉顺序，而不是相对时间。
- 把 `min_seconds`、`readability` 当作硬限制向用户宣布；它们是本 skill 的估算，成片验证后按 `validation-log.md` 修订。
