# S5b 参考资产准备

本阶段适用于完整 production。performance/raw 是文本表演交付，不因缺少图而等待，不把情绪库条目当成视频参考；实际有素材时才登记引用。

**图 + 文是核心生产路径，文生视频是兜底。** `[官方]` Seedance 2.5 的主体参考、场景参考、关键帧参考是它区别于前代的能力；`[第三方]` 多家实践一致：没有参考图时跨 clip 角色一致性风险较高。所以在完整生产的 S6 编译之前，先有资产计划。本 Skill 不生成图片，但产出**资产清单 + 每张图的图像简报**（模型无关），先读取并复用用户已有角色、场景与视觉资源；只为实际缺口写简报，不要求重做已可用素材。详细生产绑定见 `production-workflow.md`。

输入：`03_script/` 剧本 + `04_shots/` 分镜卡（含 S5 §5.0 的决策载体行）。输出：`05_assets/asset-plan.md`（模板 `templates/reference-asset-brief.md`）+ 更新 IP 级 `assets/assets.md` 登记表。

## 5b.0 从决策载体推资产

素材不只是一致性保险，也是导演决策的载体（`director-grammar.md` §七）。S5 已按决策类型定了载体，本阶段据此列资产：

| 决策载体 | 资产 | 规格与写法 |
|---|---|---|
| 关键帧（严格构图） | 每镜一张，按镜头顺序上传 | 构图 = 分镜卡；首句「以图片 1 至图片 N 的顺序作为关键帧」（T4）`[官方]` |
| 白模（运镜与走位时序） | 粗粒度白模视频，含切镜 / 运镜 / 光照 | 简单几何体、主体只留躯体、不含轨迹线 / 坐标线 / 相机 cone；Prompt 声明只参考运镜与调度，不参考画面内容（T3b）`[官方]` |
| 动作参考（具体动作节奏） | 5–10 s 视频，只含要参考的那一件事 | 「严格参考视频 1 的动作与运镜，顺序一致」（T3）`[官方]` |
| 宫格分镜（结构与顺序） | ≤15 格线稿 | 不严格对齐，Prompt 补动作 / 运镜 / 台词（T5）`[官方]` |
| 文字 | 无 | 景别、角度、单一运镜、起止状态、台词、声音 |

真人人脸不能直接上传 `[官方]`；角色参考用生成图、预置虚拟人像或已授权素材。

## 5b.1 从分镜推资产清单

| 资产类型 | 什么时候需要 | 规格 | 数量建议 `[官方]` |
|---|---|---|---|
| 角色主体图 | 每个有脸的角色 | 正面中近景、中性表情、干净背景、服装与外观锁一致；侧面一张（2.5 支持多视图，**拆成多张单视图上传**，不拼图） | 每角色按需选视图；指南图像主体 1–8 更稳（非保证） |
| 服装图 | 角色本条要穿的衣服与形象图里的不同，且文字说不清（款式、纹样、队服）时 | 只有衣服：平铺、人台或无脸穿搭，正面为主，必要时加背面；颜色、纹样、领口袖口清楚；干净背景 | 每套 1 张；换装另起一张 |
| 场景空镜 | 每个机位方向一张 | 无人物；含主光源与方向、主要陈设、门窗位置；与分镜卡的景别一致 | 每场景 1–3 张 |
| 道具 | 有特写或归属变化的物件 | 干净背景、真实尺寸感 | 每件 1 张 |
| 关键帧 | 走 T4 关键帧路径时 | 按镜头顺序，每镜首帧；构图 = 分镜卡 | 按关键画面选，约 15 格以下为建议 |
| 音色 | 有台词角色需要固定音色时 | 5–10s 干净人声，语言与台词一致 | 每角色 1 段 |
| 动作 / 运镜参考 | 复杂动作或精确运镜 | 5–10s，只含要参考的那一件事 | 按需 |

上限核对：图 ≤ 30、视频 ≤ 10 总 ≤ 30s、音频 ≤ 10 总 ≤ 30s、合计 ≤ 50。`[官方]`

## 5b.2 图像简报（每张一份，模型无关）

```
资产 ID：img_（上传顺序编号在 5b.4 定）
用途：角色 A 主体参考 / 场景 X 机位 1 空镜 / …
主体：外观锁原文（角色）或空间描述（场景）
构图：景别、角度、主体位置、背景是否干净
光：主光源 + 方向 + 质地（必须与该场景所有镜头一致）
风格：媒介 / 质感 / 色调（与 ip.md 视觉总则一致）
一致性标记：这张图里必须出现、后续每个 clip 都靠它认人的 2–3 个特征（疤、配饰、发型、服装颜色）
不要：文字、水印、多人、道具堆、极端表情、复杂背景（角色图）
```

一致性标记同时写进外观锁；每个 clip Prompt 的【贯穿要求】重写这 2–3 个特征。

服装图的简报另写：用途（哪个角色、哪几条 clip）· 衣物（上装 / 下装 / 鞋 / 配饰，逐件写颜色与材质）· 呈现（平铺 / 人台 / 无脸穿搭，不带可认的脸）· 不要：人脸、文字、多套衣服同框。

## 5b.3 编排原则

- **明确参考范围**：可用独立角色/场景图，也可使用已确认的合成图、首帧图或多用途参考；说明引用哪些内容，不为满足模板强制拆图。
- **同一角色多张图必须同一服装、同一发型**，除非剧本有换装，换装另起一组。
- **场景图的光要和剧本时刻一致**：夜戏不能用白天空镜。
- **不在图上写字**，不靠图上文字指代角色。`[官方]`

## 5b.3a 形象图与服装图的分工（1.10.0，硬规则 21）

形象图管"这个人是谁"（脸、发型、体态），服装图管"这条 clip 穿什么"。模型会从形象图里带衣服：两次成片都穿成了形象图里的衣服，绑定里写的"不参考图中白色 polo / 黑色毛衣"没有压住（`[用户判定]`，THE ORDER EP03 场 4 与 2026-09-24 片场戏 v4，`validation-log.md`）。所以每个有形象图的角色，本条衣着只能有一个来源，并且用正向的句子写出来：

| 情形 | 衣着来源 | 【素材绑定】写法 |
|---|---|---|
| 形象图与服装图是两张 | 服装图 | `图1 = A外观，只参考面部与发型；本条A的衣着一律按图4`；`图4 = 本条A身上唯一的服装：{衣物}` |
| 形象图里穿的就是本条要穿的 | 形象图里的衣服 | `图1 = A外观与服饰参考：参考面部、发型与图中衣服：{逐件写}`；形象图只露上半身时下装另用文字补（"下身按文字：深色长裤"） |
| 没有服装图，衣着只靠文字（赤裸上身 + 浴巾、制服没有图、形象图的衣服不能用） | 每一镜的文字 | `图1 = A外观，只参考面部与发型；本条A的衣着一律按每一镜的文字：{衣物}` |
| 同一 clip 内换装 | 换装前后各一个来源 | 绑定写"镜N起：…"；换装后的衣服有图就另起一张服装图 |

选择：
- 形象图的衣服不是本条要穿的，又说不清新衣服 → 做服装图（5b.1），不靠"不参考图中衣服"。
- 用户决定就穿形象图里那身 → 第二行；每镜照样复述那身衣服。
- 裸露、湿身、浴巾这类没法做成服装图的 → 第三行，逐镜文字写明。
- 群演没有形象图，一句集体衣着即可；有形象图的主要角色不能被"全队都穿 @队服"代替。

每条 clip 在分镜卡头部写"衣着来源"一行（`templates/shot-card.md`），S6 逐镜编译（S6 §6.2 衣着）。服装图也按实际上传顺序编号，写进资产清单与登记表的"衣着来源"字段。

## 5b.4 上传顺序与编号

在 `asset-plan.md` 里定最终上传顺序：按任务实际需要编排，不设跨任务固定类型顺序；关键帧优先满足首句声明的图像顺序。编号即 Prompt 里的 图1 / 音频1 / 视频1。每条 clip 使用自己的局部编号并映射稳定资产 ID；顺序改动时更新受影响 Prompt 和生产记录，不强制其他片段上传无关素材。

## 5b.5 回填与降级

- 用户已有或补齐素材后：检查实际文件与内容，把路径回填到 `assets/assets.md` 登记表，再完成可提交包；缺素材时仍可交付明确标注缺口的文本草稿。
- 缺角色图：该角色只能靠外观锁文字，跨 clip 一致性标 ⚠️ 高风险；可先用 T1 文生视频出一条，从中抽帧当参考图（自举）。`[推论]`
- 缺场景图：可用第一条成片的末帧或抽帧当场景参考。`[第三方]` 末帧续接。
- 缺服装图：衣着来源改为"每一镜的文字"（§5b.3a 第三行），逐镜写明；形象图里的衣服不是本条要穿的时，同时在形象图那一行写"只参考面部与发型"。
- 用户明确接受不一致风险且要求快出：走 T1 兜底，Prompt 文件 E 层标"兜底路径"。

## 5b.6 停靠

S5b 不单独停靠。资产清单随 S5 分镜一起交付，用户确认分镜时一并确认资产清单；用户生成图并回填是一个自然的等待点。
