# 生产档案（production-profile）：一个项目只说一次的事

同一项目里反复被用户重申的生产常量——画幅、Prompt 语言、素材绑定约定、调色段、声音与旁白策略、节奏约定、字幕、首帧策略——写进 `<story-slug>/production-profile.md`（模板 `templates/production-profile.md`），S1 每条 clip 开工先读；没有档案时从 `ip.md` §视觉声音总则和用户已明确的要求提炼一份草稿，在对话里回显一次，确认后落盘。档案是 E 层元数据的来源，不进入 Prompt 正文；进入正文的是它派生出的可见描述（调色段、声音策略行、素材绑定行）。

## 字段与用法

| 字段 | 例 | 进入 Prompt 的位置 |
|---|---|---|
| 画幅 · 时长上限 | 9:16 竖屏；clip ≤30s，目标按场景 | 【总述】；E 层 ratio / duration |
| Prompt 语言 / 台词语言 | Prompt 中文；台词英文，逐字引号 | 全文；台词行注语言 |
| 素材绑定约定 | 每人一张人物形象图（面部/发型/体型，跨场稳定）＋每场一张服饰图（该场服装/配饰，换装态各一张，用户提供）；形象与服饰在【素材绑定】里硬拆两条（§4.2 一图一职责）；场景图 1 张；主体图数=角色数×2，>8 需抽卡 | 【素材绑定】 |
| 调色段 | 深橄榄绿与近黑阴影主导；中间调烟草棕与琥珀；红限氧化砖红与暗酒红；白为脏奶油白；低调曝光、无 HDR | 【画面基调】逐字复用 |
| 声音与旁白 | 无 bgm；环境音按场；旁白由模型原生生成（女声）；对白清晰 | 【贯穿要求】声音策略行；旁白行 |
| 节奏约定 | 对白场一句一切；对白镜 2–4s；逐镜换景别 / 角度 / 运镜；hero 特写保留 1–2s | 【分镜时间线】设计依据（不写入正文） |
| 字幕 | 不要字幕 | 【贯穿要求】 |
| 首帧 / 衔接策略 | 独立重生成为默认；不用上一 clip 尾帧作首帧，除非用户指定 | E 层上游 clip 行 |
| 台词预算口径 | 英语 2.5 词/s；对白 ≤2/3 clip | 回传创作侧 |
| 人设场合差异 | 某人物球场沉静 / 派对自信；造型按场（球衣＋帽 / 礼服无帽） | 【贯穿要求】外观锁；S4 表演 |

## 规则

- 档案里的字段在每条 clip 里**不再向用户重问**；用户当场改口时更新档案再编译。
- 档案与 `ip.md` 冲突时以 `ip.md` 为准并修档案；档案与用户本次明确要求冲突时以本次要求为准并更新档案。
- 档案不替代场景参数卡（强度 / 方向 / 信息 / 权力 / 进场温度 / 密度），后者仍逐场判断。
- 生成前把用到的行回显在交付的参数建议表里，方便用户一眼核对。
