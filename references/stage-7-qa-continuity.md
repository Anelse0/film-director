# S7 连续性与质量检查

两个入口：**生成前**（Prompt 校验）与 **生成后**（成片问题定位）。产出 `07_qa/scene-XX-clipYY.qa.md`。

实际生产包按 `production-workflow.md` 运行严格预检。基础文本检查不读取实际媒体，也不证明参数、素材或审阅已齐备。

## 7.1 生成前：脚本 + 语义审阅

分别报告：格式、保真、表演质量、成片验证。无错误不等于四项通过。调用及 sidecar 见 `performance-record.md`；没有记录写保真未自动核对，没有成片写未验证。performance/raw 不检查与任务无关的完整生产字段。

1. 运行 `python3 scripts/validate_prompt.py <prompt.md>`；表演片段加 `--artifact performance`，原文加 `--artifact raw --entry-id N`，上游记录用 `--record`。
   - ERROR 必须修。
   - WARN 逐条写"保留理由"或修改。
2. 人工过下表（脚本查不了的）：

| 检查 | 问 |
|---|---|
| 可回溯 | D 层表演能指回 C 层及所选条目？关键细节、顺序、同步与末态有无改变？有意改编记录了吗？ |
| 因果 | 每个反应前面有起因？每镜：上一镜给了什么、这一镜为什么需要（`causal-chain.md`）；台词质量属创意侧，只查执行 |
| 导演语法 | 每镜一个主要事件？运镜有动机与终点？画面里最大的东西是此刻最重要的东西？部位级表情是否写在可见景别？纵深走位 / 环绕是否交给了关键帧或白模（`director-grammar.md` §九、S5 §5.0） |
| 运镜库 | 用了库条目的镜：动机写了吗？五段是这一镜的主体、方向、速度、保持不变的东西和终点，还是库里的通用句（W34 只认英文原句，译成中文的通用句要人看）？原文是否是用户指定的？ |
| 摄影机身份与支撑 | 本场摄影机身份前后一致吗？换身份的镜写了理由吗？支撑 / 质感写成看得见的结果了吗？命中 `director-grammar.md` §2.5 风险 ①–⑦ 的组合（人群、快速运动、说台词时的侧跟 / 弧移 / 手持、长时间复合运动、新空间、主观镜头露手）换载体或登记了吗？ |
| 轴线 | 屏幕方向是否可理解？有意越轴/走位是否交代，不与全局锁矛盾？ |
| 交付变化 | 本 clip 在场级方案里交付事件轨哪几行（`交付变化` 列）？峰值事件是其中一次变化吗？删掉这条 clip 观众少知道什么（= 那几行的"删掉损失"）？只交付余韵、或写不出行号 → 回 S5 §5.1 第 6 条；多 clip 场先跑 `python3 scripts/scene_track.py <剧本页> --plan <场级方案>` |
| 起止状态 | clip 首尾状态写了？与上下游 clip 对得上？ |
| 外观锁 | 每个角色每个 clip 都有？出画再入画时重复了？ |
| 衣着 | 每个有形象图的角色，绑定用正向句写了唯一的衣着来源（服装图 / 图中衣服 / 逐镜文字）？每镜每个在画面里的角色——含监视器、画中画、镜子里的——第一次出现都带了衣着？换装从哪一镜起、前后接得上吗？写的衣服和服装图、关键帧、首尾帧里的一致吗？"两人 / 全队"只用于群演？沿用形象图里衣服的角色，是用户指定的、E 层登记了吗（默认形象图与服装图分开，W37）？（E23 必须改；W36 逐条改或写明属于哪种误报边界；硬规则 21） |
| 光源 | 光源与空间/时间一致？多光源有分工，不强制只用一盏？ |
| 台词 | 逐字引号、说话人、时间窗、语言、非说话者嘴部？依据显式语速及占比估时，不从情绪强度推算 |
| 多人说话 | 重叠是否有戏剧动机、听辨层次和口型安排？必要时改覆盖方式，不自动删打断 |
| 表演与时间 | 高光有足够发展与可见持续？控制是否有证据？同步多部位不按逗号算任务；检查无关事件挤占与动作矛盾 |
| 素材 | 编号 = 上传顺序？用途与实际内容一致？超限没有？ |
| 参数 | 有锁定任务 ratio=adaptive？编辑 duration=-1？首尾帧画幅不同时是否明确拉伸风险？ |
| 风险登记 | 快动作、文字、手部精细动作、图像参考主体 9–12 / 音视频参考主体 6–10、日/韩长台词 —— 标 ⚠️ 抽卡 |

## 7.2 生成后：成片问题定位

用户给成片 + 问题描述。步骤：

1. **定位秒数** → 找到对应镜头卡（时间戳）。
2. **归类**：

| 现象 | 最可能原因 | 修正层 |
|---|---|---|
| 人物换脸 / 换衣 | 外观锁缺失或素材职责混 | C 层贯穿要求 + 素材绑定 |
| 衣服跟了形象图、服装图没被采用、该赤裸的穿上了衣服、换装前后乱了 | 三种写法问题（`[用户判定]` THE ORDER EP03 场 4；片场戏 v4 校验 0 error）：① 绑定只写"不参考图中衣服"，没有正向衣着来源；② 服装图只夹在形象图那一行的括号里，镜头里没出现；③ 镜头里没逐人写衣着，或用"两人 / 全队都穿"代替，监视器里的人也没写 | 回 S5 分镜卡的衣着来源与逐镜衣着字段，S6 按硬规则 21 重编（E23 / W36）；是写法问题，不抽卡 |
| 切镜后人物换边 | 轴线未写 | C 层每镜加画左/画右 |
| 动作被跳过 / 赶 | 该镜负载超过一个事件；窗口不足；遮挡；执行失败 | 先定位；保留高光，减少无关负载或协商增时，不自动删表演 |
| 静止不动 | 先确认是否用户目标；也可能细节不可见或未执行 | 查景别、遮挡与表演，不能自动补走位/道具/运镜 |
| 反应先于起因 | 因果顺序 | 拆成两句，先因后果 |
| 情绪不对 | 可能细节丢失、强度/控制错配、时序或可见性不足 | 对照有序表演块与成片逐节拍定位 |
| 台词念错 / 漏 | 引号外描述、时间窗太短、密度高 | 4.5 表 |
| 口型对不上 | 多人归属、时间窗、台词超预算、侧脸、遮挡或执行问题 | 先核对说话人、窗口与能力表 §7 预算；改覆盖（正面 / 3/4 侧中近景）、分轨、语言或重叠均涉及创作选择，不能擅改用户锁定项 |
| 机器乱动 / 该动不动 | 运镜没写终点；复合运镜没写同步 / 先后；文字承载了应交给白模 / 关键帧的时序 | 补动机与终点；换载体（S5 §5.0） |
| 长镜头中途构图崩 | 15 秒以上纵深走位或环绕靠文字驱动 | 关键帧或白模；或拆镜 |
| 出现字幕 / bgm | 没写负向 | 贯穿要求加"不要字幕 / 无 bgm" |
| 节奏慢 / 拖、句间有空、镜头停着 | 模型按时间戳执行 `[实测]`：窗口比估时宽、无台词段没功能、减速词（停住 / 放慢 / 不动）被执行、30 s 未按内容推导 | `measure_clip.py` 量切点与有声占比；按 `duration-rhythm.md` §二–§五收窗口、删无功能空档、按 §八加节奏指令；W22–W27 |
| 画面始终没有变化的感觉（切点都在、口型都对） | 成片 = 设计 `[实测]`：镜长等长、全固定机位、景别一路相近、光不变、每镜一个同等幅度的微动作、峰值事件放在最不可见的镜里、同构图第二次没多东西 | `measure_clip.py` 视觉变化谱（拼图 / Δ直方图 / 镜内运动 / clip 级镜长对比与边缘密度极差）对照变化轨：平在设计 → 回 S5 §5.1f 重排峰值镜与四维变化，W30–W33；平在渲染 → 换载体或抽卡 |
| "这 N 秒存在的意义是？"（执行都对，但删掉观众什么也不少） | 设计问题，不是渲染：这条 clip 没有交付任何变化（余韵行或没有事件的段落被排成整条 clip） | 回 S5 §5.1 第 6 条：`scene_track.py --plan` 看交付变化；并进前一条 clip 尾部或删掉并在差异行写"不拍"；不抽卡、不换载体 |
| 运动质感不对（要克制手持出来是固定或明显晃；要斯坦尼康出来像稳定器） | 质感词的执行未验证（`director-grammar.md` §2.5 风险 ⑤）；只写了器材名、没写看得见的结果 | 改写成可见结果（幅度、快慢、有无起伏）；成片结论记 `validation-log.md`（质感在抽帧里看不出，要看成片） |
| 多出人或物 | 正向描述不完整 | "画面中只有 A 和 B" |
| 素材元素错位（背景被复制） | 素材未写"不参考什么" | 素材绑定 |
| 快动作形变 | 模型限制 `[第三方]` | 降速 / 减少动作 / 换景别，标风险 |
| 后段崩坏 | 可能为时序超载、连续性冲突或模型执行波动 | 定位实际失败原因；必要时拆 clip，不以第 25 秒作通用阈值 |
| 编辑后时长/画幅变 | 参数没锁 | ratio=adaptive, duration=-1 |

3. **只改一个变量**再生成。`[第三方]` 记录到 E 层版本号与抽卡记录。
   同时在 `references/validation-log.md` 记一行：测试的写法、对应规则、是否被执行。重复结果仅说明该条件下的经验，不能自动升级成通用能力结论。
4. 若 24/30 秒可用：把可用部分当作素材，只重写坏段的起止状态，用编辑（时间戳范围）或延长处理。`[第三方]`
