# S7 连续性与质量检查

两个入口：**生成前**（Prompt 校验）与 **生成后**（成片问题定位）。产出 `07_qa/scene-XX-clipYY.qa.md`。

实际生产包按 `production-workflow.md` 运行严格预检。基础文本检查不读取实际媒体，也不证明参数、素材或审阅已齐备。

## 7.1 生成前：脚本 + 语义审阅

分别报告：格式、保真、表演质量、成片验证。无错误不等于四项通过。调用及 sidecar 见 `performance-record.md`；没有记录写保真未自动核对，没有成片写未验证。performance/raw 不检查与任务无关的完整生产字段。

八道在用户看到 Prompt 之前做完（停靠 C 回显的是审完的 Prompt 全文 + 数字块 + 第 7 道处置表 + 未决）；停靠 C 的反馈回来后，措辞 / 执行层的改动只回 S6、QA 只改受影响的行并 `check.py qa --sync`，设计层的反馈先回分镜卡（停靠 A / B）再重编译。

1. 运行 `python3 scripts/validate_prompt.py <prompt.md>`；表演片段加 `--artifact performance`，原文加 `--artifact raw --entry-id N`，上游记录用 `--record`。
   - ERROR 必须修。
   - WARN 分两类：**成片教训类**——W35、W46–W48、W51、W52、W54、W55、W57（原 W40 / W49 并入）和 W24 的「最长连续无台词」子项，每一条都来自一次做错的成片——默认改，保留要用户点头，QA 里记用户的原话；**其余** WARN 逐条写"保留理由"或修改。用户已对本条点名过的类别（QA 现行状态「用户已点名」行：节奏 / 剪辑 / 空间 / 表演 / 台词 …），同类 WARN 不得再写理由保留，只能改或记用户原话（`qa_check.py` Q04；证据：CHANGELOG 1.11.0）。脚本最后的 INFO 行"成片教训类提醒 …"列出本条命中的成片教训类代码。
   - 有分镜卡时再跑 `python3 scripts/camera_plan_check.py --prompt <prompt.md> <分镜卡>`：机位表和 Prompt 的画左 / 画右明确矛盾是 C10（ERROR），以机位设计为准对齐。
2. 人工过下表（脚本查不了的），按下面第 3 步的七道走：

| 检查 | 问 |
|---|---|
| 可回溯 | D 层表演能指回 C 层及所选条目？关键细节、顺序、同步与末态有无改变？有意改编记录了吗？ |
| 因果 | 每个反应前面有起因？每镜：上一镜给了什么、这一镜为什么需要（`causal-chain.md`）；台词质量属创意侧，只查执行 |
| 导演语法 | 每镜一个主要事件？运镜有动机与终点？画面里最大的东西是此刻最重要的东西？部位级表情是否写在可见景别？焦点在谁、过肩前景的虚实与位置写了吗（W43）？纵深走位 / 环绕是否交给了关键帧或白模（`director-grammar.md` §九、S5 §5.0） |
| 轴线 | 屏幕方向是否可理解？有意越轴/走位是否交代，不与全局锁矛盾？ |
| 机位设计 | 分镜卡有 `## 机位设计` 且 `camera_plan_check.py` 0 ERROR？五项核对有结论？Prompt 里的画左 / 画右、机位朝向、门和人物的位置和机位表一致？反打镜有没有在正文里描写镜头身后东西的样子（方向句除外，S5 §5.1g） |
| 成片教训措辞 | 台词括号没有快慢词、声音行没写"快"（W47）？左右写画左 / 画右、过肩的肩和下角同侧（W46）？手机 / 杯 / 瓶写了哪只手怎么握、没写捂话筒（W48）？分镜正文和括号没有 A 层词（情绪 / 判断 / 意图词、慌张 / 瞪眼类词；W57，原 W49）？接上一条末帧的第一镜接着动（W51）？镜头身后的东西只提一次、没有只服务一个反向镜的场景图（W52）？机位表写了方位和朝向、C09 无 ERROR？ |
| 节奏与剪辑 | 最长连续无台词 ≤3 s？有没有一句跨镜、后半句画外（W54）？画外句所在镜画里有没有别的近景人脸（W55）？每个「看 / 撞上 / 被点名」的拍子有没有反应镜或双人镜？分镜卡执行卡 25 行都有证据？ | W24 子项、W54 / W55、S5 §5.2 第 6a / 8a 步、§5.11、`stage_check.py` |
| 翻译完整性 | S4 设计稿的每个要素在 D 里都有可见写法或写明了去处（`stage-4` §4.4c 去处表）？台词括号里的意图词在同镜有这个人的可执行拍子（载体由设计定，不限于眼神）、动作没留在括号里、括号里的词没删（W44；分镜卡"表演翻译"行写"放在语气里"的在这里拦）？篇幅删减有没有删到表演？强情绪镜有没有「正常人眼不发光」？ |
| 起止状态 | clip 首尾状态写了？与上下游 clip 对得上？ |
| 外观锁 | 每个角色每个 clip 都有？出画再入画时重复了？ |
| 光源 | 光源与空间/时间一致？多光源有分工，不强制只用一盏？ |
| 台词 | 逐字引号、说话人、时间窗、语言、非说话者嘴部？依据显式语速及占比估时，不从情绪强度推算 |
| 多人说话 | 重叠是否有戏剧动机、听辨层次和口型安排？必要时改覆盖方式，不自动删打断 |
| 表演与时间 | 高光有足够发展与可见持续？控制是否有证据？同步多部位不按逗号算任务；检查无关事件挤占与动作矛盾 |
| 素材 | 编号 = 上传顺序？用途与实际内容一致？超限没有？服装图与穿着状态不同时绑定行写了状态、【起始状态】与【贯穿要求】写了开场 / 分段状态（W45）？ |
| 参数 | 有锁定任务 ratio=adaptive？编辑 duration=-1？首尾帧画幅不同时是否明确拉伸风险？ |
| 风险登记 | 快动作、文字、手部精细动作、图像参考主体 9–12 / 音视频参考主体 6–10、日/韩长台词 —— 标 ⚠️ 抽卡 |

3. **八道审阅**：Claude 的生成前审阅固定按八道走，每道在 QA 里留一张表或一段逐镜结论，不能只写"已审"；数字能从脚本抄的从脚本抄，不自填；空间那道是默认步骤，不等用户追问（证据：CHANGELOG 1.10.0——只核起始状态的文字时，做不出来的动作和写反的左右都是用户追问后才查出来）。

| 道 | 查什么 | 依据 | 在 QA 里留什么 |
|---|---|---|---|
| 1 台词 | 逐字、顺序、说话人、窗口、非说话者嘴部；每句：说话人在本镜是否可见、画里有谁的脸、有没有画外 / 跨镜（W54 / W55） | 上表"台词""多人说话" | 句数对照表加「说话人可见」「画内其他人的脸」两列 + 不一致处 |
| 2 括号与声音行 | 括号只有语言、情绪 / 口气、音量、距离；声音行年龄与音色对得上 `ip.md`，不写快 | W47、硬规则 6 | 逐镜一行 |
| 3 机位与空间 | 机位表 C09 / C10 无 ERROR；Prompt 每镜的画左 / 画右、门和人物的位置和机位表一致；左右没写人物自己的（W46） | 上表"机位设计""轴线"、S5 §5.1g | 逐镜一行：机位、画左、画右、人物 |
| 4 动作可行与负载 | 按空间锚点的"可达"核每个动作做不做得出来；一镜的事塞不塞得下（硬规则 15；W50 暂停，人工审） | 上表"表演与时间"、硬规则 15 | 逐镜一行 |
| 5 衔接 | 首帧接上一条**成片**末帧（§5.1g 复核）；第一镜接着动（W51）；末态和下一条起点 | §7.3、S5 §5.1 第 3 条 | §7.3 表 |
| 6 基调与表演 | 轻松场没有悬疑语法（W35）；正文和括号没有 A 层词（W57）；分镜卡每镜表演翻译是三段、第二段是词典行（S04 / S05）；轻松场没有"都不笑"这类禁掉日常证据的约束（S4 §4.4b） | 上表"可回溯""翻译完整性" | 指出证据或问题 |
| 7 校验处置 | 每条 WARN：成片教训类改了还是用户同意保留（原话）；其余写理由；用户已点名类别的 WARN 不得写理由保留（Q04） | 第 1 步 | WARN 处置表 |
| 8 节奏与剪辑 | 最长连续无台词、一句一镜句数 / 总句数、反应镜数、画外句数、句尾后停留 ≥1 s 的镜——全部抄 `validate_prompt.py` 的 WARN / INFO 和分镜卡执行卡，不自填 | W22–W29、W54 / W55、`stage_check.py` | 一行数字 + 不达标项的处置（只能「改了」或「用户同意保留：原话」） |

## 7.2 生成后：成片问题定位

用户给成片 + 问题描述。步骤：

1. **定位秒数** → 找到对应镜头卡（时间戳）。
2. **归类**：

| 现象 | 最可能原因 | 修正层 |
|---|---|---|
| 人物换脸 / 换衣 | 外观锁缺失或素材职责混 | C 层贯穿要求 + 素材绑定 |
| 脱下的外套又穿回去 / 卷起的袖子放下了 / 敞开的衣服扣上了 | 服装图是整套的样子，绑定行写的是图 = 状态的写法（「唯一的服装 / 衣着一律按图」），穿着状态只在镜头行 `[推论]` | 人物行 / 服装行改为写状态的写法（一律按每一镜的文字：外套落座时脱下搭在凳上），【起始状态】写开场状态，【贯穿要求】写分段状态（镜 N 起 …，不穿回）；可选另出一张该状态的服装图（S5b §5b.3，W45） |
| 该清楚的脸虚了 / 焦点在错的人 / 过肩前景占得太多 | 标注没写焦点在谁；过肩或虚化层没写在画面哪里、占多少；默认景深没声明（峰值镜放在越肩里是 W33） | 每个画内人物镜写 焦点在 X；过肩 / 虚化层写位置与占比、主体在哪里清楚；【画面基调】声明默认景深（S5 §5.2 第 3 步，W43） |
| 语气没出来 / 表演平（括号里明明写了真诚、不推销） | 意图只在台词括号里，镜头行没有这个人的任何可执行拍子；动作写进了括号（是否被执行 `[未验证]`） | S4 §4.4c 第 7 条：按设计的载体（眼神 / 身体 / 声音与停顿 / 互动）写一拍进镜头行，动作移出括号；口气词（轻松 / 随口）留在括号里即可；括号里的词不删（W44） |
| 切镜后人物换边 | 轴线未写 | C 层每镜加画左/画右 |
| 门 / 名牌跑到人物另一侧，或过肩前景在错的下角 | 左右写成人物自己的（"门框在他右肩旁边"：人面对镜头时右肩在画左）；过肩写"右肩"却放在画左下角（证据 #8） | 一律写画左 / 画右，指手写"靠门那只手（画左那只）"；机位表写方位与朝向，C09 核对（W46、S5 §5.1g） |
| 人物走反方向（背对镜头走远，像在离开） | 地标写在人物"前面"（朝门走 / 前面的门 / 退向门）而场景图与机位把它放在镜头身后；全局的机位朝向没拦住镜内写法（证据 #6） | 地标写相对镜头的位置，运动写朝镜头 / 背对镜头，【贯穿要求】加方向句，每镜重写（E23，`director-grammar.md` §3.7） |
| 成片像惊悚 / 像有事要发生（基调是轻松） | 悬疑语法混进反应镜：手停住、固定正面近景里慢转头朝画外来人、盯住 + 压低声音、来人无状态地逼近、低头抬眼 / 只转眼珠（证据 #7） | S4 §4.4b：改成继续做的事（嚼、手上的活不停）、下巴放平顺着看一眼、压着笑、来人写状态、环境声照常；【贯穿要求】写基调句；W35 |
| 动作被跳过 / 赶 | 该镜负载超过一个事件；窗口不足；遮挡；执行失败 | 先定位；保留高光，减少无关负载或协商增时，不自动删表演 |
| 静止不动 | 先确认是否用户目标；也可能细节不可见或未执行 | 查景别、遮挡与表演，不能自动补走位/道具/运镜 |
| 反应先于起因 | 因果顺序 | 拆成两句，先因后果 |
| 情绪不对 | 可能细节丢失、强度/控制错配、时序或可见性不足 | 对照有序表演块与成片逐节拍定位 |
| 台词念错 / 漏 | 引号外描述、时间窗太短、密度高 | 4.5 表 |
| 口型对不上 | 多人归属、时间窗、台词超预算、侧脸、遮挡或执行问题 | 先核对说话人、窗口与能力表 §7 预算；改覆盖（正面 / 3/4 侧中近景）、分轨、语言或重叠均涉及创作选择，不能擅改用户锁定项 |
| 机器乱动 / 该动不动 | 运镜没写终点；复合运镜没写同步 / 先后；文字承载了应交给白模 / 关键帧的时序 | 补动机与终点；换载体（S5 §5.0） |
| 长镜头中途构图崩 | 15 秒以上纵深走位或环绕靠文字驱动 | 关键帧或白模；或拆镜 |
| 出现字幕 | 没写"不要字幕"；台词后复述词语并追加语气 / 表情括号（官方 FAQ）；参考视频自带字幕 | 语气 / 音色写到冒号前，动作写进镜头行（W36 / W44），台词后不复述片段；换无字幕参考视频 |
| 出现 bgm / 铺底音乐 | 同义词没穷举，模型换个说法绕过；约束只写在结尾（官方 FAQ） | 开头与结尾各写一遍，穷举音乐、背景音乐、BGM、配乐、器乐、旋律、铺底音（W37） |
| 眼睛发光 / 表情夸张 | 强烈情绪词或堆叠的强表情（官方 FAQ 情绪过度响应） | 改常规描述，加「人物为正常人眼，不发光」；表演按 `stage-4` §4.4c 翻译（W57，原 W40） |
| 轻松场里表演浮夸（瞪眼、张嘴、整张脸皱起来） | 慌张类词：慌慌张张、眉毛还抬着、牙关一咬、狼狈（证据 #8） | 写平常的样子加一个小动作（一愣、闭一下眼）（W57，原 W49） |
| 成片在"演"一个形容词（皱眉对质、一脸不信、瞪着） | A 层词漏进 C / D 层：剧本形容词 → 卡上"X → 括号口气" → Prompt 括号或正文（证据 #12） | 把词留在 A 层，经词典「（轻松）」行翻成部位 · 先后 · 声音；括号只留声音参数（W57，S5 §5.2 第 1 步，S4 §4.4b 基调是参数） |
| 拿手机两手捧着、平放在掌心；"捂话筒"变成捂嘴 | 没写哪只手、怎么握；动作对象太小，模型落到最近的显眼部位（证据 #8） | 写哪只手、正常握法、另一只手在干什么；不写捂话筒，改成把手机从耳边拿下来（W48） |
| 先出场的人物被别的参考角色替换 | 上传顺序不是首次出场顺序（官方 FAQ 角色对应错误） | 按首次出场顺序上传并同步编号 / @名（W39） |
| 节奏慢 / 拖、句间有空、镜头停着 | 模型按时间戳执行（证据 #1）：窗口比估时宽、无台词段没功能、减速词（停住 / 放慢 / 不动）被执行、30 s 未按内容推导 | `measure_clip.py` 量切点与有声占比；按 `duration-rhythm.md` §二–§五收窗口、删无功能空档、按 §八加节奏指令；W22–W27 |
| 台词挤成一团 / 偏快 | 台词括号或声音行里有快慢词（语速快 / 飞快 / 赶 / 捂着话筒压低）（证据 #8） | 删掉这些词，先不动时长和窗口；用户已经说了原因时按用户说的改（W47） |
| 反打镜被生成成参考图的视角（机位跑到另一侧） | 一张场景图只为这一个反向镜绑定，图的视角比文字强；正文多处提镜头身后的东西（证据 #9） | 在现有参考图覆盖的视角里改选机位，或这一镜不绑这张图、材质和光写进文字；镜头身后的东西只留一句方向句（W52、S5 §5.1g）；不要求用户补图 |
| 下一条开头像定格 | 接上一条末帧的第一镜把上一条最后一拍又演了一遍（证据 #9） | 从末帧那一刻正在做的事的下一步开始（W51、S5 §5.1 第 3 条） |
| 听者替说话人开了口 | 一句拆成两段跨镜、后半句画外落在听者的近景；或他人的整句画外落在画里清楚的脸上（证据 #10） | 一句不跨镜（W54）；画外句所在镜不能有别的近景人脸，或按画外整句镜写全——整句、≥3 s、听者闭嘴、【贯穿要求】加「排除错误人物发声、多人同时说话」（W55，S5 §5.2 第 6 步） |
| 画面始终没有变化的感觉（切点都在、口型都对） | 成片 = 设计（证据 #5）：镜长等长、全固定机位、景别一路相近、光不变、每镜一个同等幅度的微动作、峰值事件放在最不可见的镜里、同构图第二次没多东西 | `measure_clip.py` 视觉变化谱（拼图 / Δ直方图 / 镜内运动 / clip 级镜长对比与边缘密度极差）对照变化轨：平在设计 → 回 S5 §5.1f 重排峰值镜与四维变化，W30–W33；平在渲染 → 换载体或抽卡 |
| 多出人或物 | 正向描述不完整 | "画面中只有 A 和 B" |
| 素材元素错位（背景被复制） | 素材未写"不参考什么" | 素材绑定 |
| 快动作形变 | 模型限制 `[第三方]` | 降速 / 减少动作 / 换景别，标风险 |
| 后段崩坏 | 可能为时序超载、连续性冲突或模型执行波动 | 定位实际失败原因；必要时拆 clip，不以第 25 秒作通用阈值 |
| 编辑后时长/画幅变 | 参数没锁 | ratio=adaptive, duration=-1 |

3. **只改一个变量**再生成。`[第三方]` 记录到 E 层版本号与抽卡记录。
   同时在 `references/validation-log.md` 记一行：测试的写法、对应规则、是否被执行。重复结果仅说明该条件下的经验，不能自动升级成通用能力结论。
4. 若 24/30 秒可用：把可用部分当作素材，只重写坏段的起止状态，用编辑（时间戳范围）或延长处理。`[第三方]`

## 7.4 qa.md 结构

模板：`templates/qa.md`。要点：

- **第一节是 `## 现行状态`**：Prompt 与分镜卡的路径和版本、成片状态（未生成 / 由哪一版 Prompt 生成 / 定版）、上游末帧、两个脚本的最新结果（ERROR 数、WARN 代码、成片教训类）、未决事项。每次改了 Prompt 或分镜卡就**重写**这一节，不往下追加。
- 每次实质改动都升 Prompt 版本号，E 表"版本"行最前面写新版本。版本行一行制（1.14.1）：E 表"版本"行只写版本号和日期，分镜卡版本行只写版本、日期、状态、skill 版本、Prompt 版本——改了什么、用户原话、剧本来源不写在版本行里（10-21 一张卡的版本行堆到 2000 多字，Prompt 的到近 3000 字，每次改稿都要整行重写）；`check.py` 对超过 200 字的版本行给 NOTE。
- 现行状态加 `用户已点名：<类别（用户原话、哪一版）>` 一行（没有写"无"）和 `执行卡：stage_check <n> ERROR` 一行；`qa_check.py` Q04：点名类别的 WARN 处置只能是「改了」或「用户同意保留：原话」。
- 审阅按 §7.1 八道，每道留表或逐镜结论；WARN 处置表写清类别与处置（成片教训类写用户原话）。
- 被推翻的旧节不删，在标题后加"（已被 vX / <节名> 替代）"；历史按时间倒序放在最后。`## 历史` 一版一条：版本（日期）：改了什么（镜号 · 改前 → 改后，抄改稿回路的变更摘要）；用户原话（有则）；证据 #n（有则）；分镜卡在 QA 建档前的几轮也各一条，写在第一条里。
- 改完跑 `python3 scripts/qa_check.py <qa.md>`：Q01 没有现行状态或缺行、Q02 记的 Prompt 版本和 E 表不一致、Q03 记的校验结果和重跑结果不一致，都是 ERROR（证据：CHANGELOG 1.10.0——QA 只追加不改写时，下一个会话先读到的是过期的左右和校验表）。
