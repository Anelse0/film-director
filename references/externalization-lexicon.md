# 外化词典：抽象情绪 → 可观察量

用法：这是库外可选写法，不是通道清单。优先按 `emotion-performance.md` 调用完整情绪条目；只有需要补充时参考本表。允许复用通用动作，不强制至少两条或角色化改写。表中的停顿只是示意，不能覆盖用户高光与末态。

**定位：本表是 S5「表演翻译」的字典**（`stage-4` §4.4c）。S4 的设计稿写满；翻译时从一行里挑本镜看得见的一两个部位，眼神先，按先后写成一句，不整行粘贴，不把五个部位同时堆进一拍——官方 FAQ 说强烈情绪词和堆叠的强表情会被过度响应（眼睛发光、表情夸张）。

**最后一列只写声音与可见性条件，不写运镜。** 旧版把「悲伤 → 缓慢推近」「释然 → 后拉」当作情绪的伴随运镜，等于把机位决定交给了情绪词；运镜由 S5 按 `director-grammar.md` 的动机（信息、人物内部变化、跟随、空间）决定，同一情绪可以固定、推近或画外。

| 抽象词 | 动作 | 表情（部位） | 视线 | 空间/节奏 | 声音 / 可见性条件 |
|---|---|---|---|---|---|
| 悲伤（压着的） | 手指反复摩挲物件边缘；肩膀下沉 | 下唇内收，眼睑半垂，吞咽一次 | 看物件不看人；看人一眼立刻移开 | 说话前延迟 1–2s；动作变慢 | 环境音不变；手部与下唇需同框可见 |
| 悲伤（崩溃） | 手撑桌沿；蹲下或坐下 | 嘴角向下拉，眼眶泛红，泪滑落一侧 | 看地；抬头看对方 | 突然停止所有动作 2s | 只有呼吸声；泪的一侧面颊需入画 |
| 愤怒（压抑） | 手握拳后松开；把东西轻放而不是摔 | 下颌收紧，鼻翼扩张，眉头压低 | 直视对方不眨眼 | 向前半步后停住 | 物件放下的闷响；下颌与鼻翼需近景可见 |
| 愤怒（爆发） | 拍桌 / 挥手扫开物件 / 逼近 | 张嘴露齿，眉眼绷紧 | 盯住 | 距离从两步缩到半步，用时 1s | 碰撞音；逼近的距离变化需全/中景可见 |
| 紧张 | 摆弄衣领 / 手指敲桌 / 反复看表 | 频繁眨眼，抿嘴 | 瞟门口或窗外，再看回 | 小动作密集；重心前后移 | 环境音里加一个规律声（钟、滴水）；小动作需中近景 |
| 恐惧 | 后退半步；手护住身前物件 | 瞳孔放大（写"眼睛睁大"），嘴微张 | 盯住威胁源，或不敢看 | 呼吸变快；动作停顿 | 声音突然安静；威胁源与人物的视线关系需可见 |
| 释然 | 肩膀放下；长出一口气；把手里东西放回原处 | 眉头松开，嘴角轻抬 | 从对方移向窗外或远处 | 动作变慢、变轻 | 环境音回来；肩膀与呼吸需入画 |
| 爱意（说不出口） | 帮对方整理衣角 / 递东西时手停留 1s | 看对方时嘴角微抬又收回 | 对方看过来时移开，对方不看时看 | 距离保持一臂，不缩短 | 无 bgm；手的停留需入画 |
| 决绝 | 放下物件后不再碰；转身 | 面部不动，只眨一次眼 | 最后看对方一眼再转开 | 转身动作干脆，不回头 | 转身与出画需空间可见 |
| 犹豫 | 手伸出又收回；脚步迈出半步停住 | 嘴唇张开又闭上 | 在对方和门之间来回两次 | 每个动作前停 1s | 手与物件同框，焦点可见 |
| 羞耻 | 低头；手遮住脸一侧或摸脖子 | 脸颊泛红，眼睑下垂 | 看地 | 身体缩小，侧身 | 脸颊与手需可见 |
| 轻蔑 | 靠回椅背；双臂交叉 | 单侧嘴角上提，眼睛半眯 | 上下打量对方 | 不靠近，甚至后退坐下 | 上半身与椅背需入画 |
| 惊讶 | 手中动作停住；身体后仰 | 眉毛上抬，眼睛睁大，嘴张开 | 猛看向来源 | 静止 1s 后动作 | 一个突发声；来源方向与视线一致 |
| 疲惫 | 揉眼；靠墙；把包放地上 | 眼睑沉重，眨眼慢 | 看地或看远处不聚焦 | 所有动作慢半拍 | 环境音闷；眼睑需近景可见 |
| 亲密（放松） | 肩膀相碰；分吃一样东西 | 自然的笑，眼角有纹 | 互看后一起看向前方 | 距离 ≤ 半臂 | 两人肩部需同框 |
| 试探 | 问一句后停住看反应；递东西不松手 | 眉毛微挑 | 盯住对方眼睛 2s | 说话前停 1s | 听者的眼睛需在画内可见 |
| 隐忍 | 手指抓紧衣角 / 桌角；吞咽 | 嘴唇抿成一条线，下颌微颤 | 看着对方然后看向侧下方 | 身体不动，只有手在动 | 无 bgm；手与下颌需可见 |
| 骄傲 | 挺胸；把成果推向对方 | 下巴微抬，嘴角上扬 | 看对方等反应 | 靠近一步 | 下巴与胸口需入画 |
| 尴尬 | 摸后颈；整理本来整齐的东西 | 假笑（嘴笑眼不笑） | 到处看，不看对方 | 小动作多、快 | 手与后颈需入画 |
| 专注 | 身体前倾；手停在物件上 | 眉头微皱，嘴微张 | 锁定物件 | 环境里其他人动而 TA 不动 | 手或眼需在画内足够大 |
| 发现 / 被提醒看（轻松） | 手上的活不停（继续嚼、继续搅）；抬头、下巴放平 | 嘴角的笑意深一点，眉毛轻轻一挑 | 顺着对方的方向看一眼（视线落在对方所在的画面方向），再瞥回对方 | 不停顿；来人有状态（手里、步子、肩膀） | 环境音照常；不写停住、慢转头、盯住、低头抬眼（S4 §4.4b，W35）`[实测]` |
| 不信 / 被拆穿（轻松） | 回头或抬眼的同时开口；手上的活不停（领子、袖扣）；一只手摊一下，或食指朝对方点一下 | 眉毛一抬，鼻子里笑出一口气，嘴角一边先挑起来 | 看着对方的眼睛一拍，再瞥回手上 | 回头和开口是同一拍，不停顿 | "啊？"的口气，声音不高；不写皱眉、一脸不信、不可思议、觉得 X （证据 #12） |
| 被逗到 / 认了（轻松） | 摇一下头；继续或转身去做手上的事；头往后一仰靠住 | 合着嘴笑，嘴角一边先挑起来，鼻子里轻轻出一口气 | 看对方一眼再移开 | 顺着动作走，不停顿 | 不笑出声（Offset）；EP04 s02-clip01 镜 7 "头往后一仰，嘴角一翘"、EP06 s02 clip01 镜 2 "抿了一下嘴，笑意从眼角出来，食指点他一下" |
| 被看着 / 撞上目光（轻松） | 手上的事停一拍再接着 | 眉毛一挑，嘴角压着笑 | 稳稳看住一拍再移开 | 一拍；对方的反应给独立反应镜或双人镜 | "What?" 带笑；不写盯住、不眨眼、手停住不动 |
| 等对方（出去 / 回答）（轻松） | 提着 / 拿着东西不动；往门那边偏一下头；把手里的东西举一举 | 嘴角一点没办法的笑，眉毛一抬 | 扫一眼屋子再落回对方 | 一镜内完成，"停住等"和"左顾右盼等"是同一状态，不拍两遍 | 清嗓一声 / "So." |
| 装无辜 / 明知故问（轻松） | 两手举到肩高；手上的活不停 | 眉毛轻轻一扬，嘴角挂着笑 | 看着对方 | 边做边说 | 不写"一脸无辜""故意"；EP06 s02 剧本"举起两只手，领结还捏在指间" |
| 随口 / 不当回事（轻松） | 不抬头，手上不停；朝对方那边扬一下下巴 | 嘴角挂着笑 | 眼睛在手上的东西上，瞟一下对方 | 边做边说 | 轻描淡写、声音平常；EP04 s01-clip02 镜 4 "冲着海的方向扬了扬下巴，笑着答" |

## A 层词：抽象情绪 / 判断 / 意图——只在分镜卡 A 层与「表演翻译」第一段出现，不进 C / D 层

`scripts/layer_checks.py`（W57）读这一节和上表第一列当字典；原 W49 幅度词、原 W40 强情绪词并入这里。这些词是**输入**：每个都要经上表的一行翻成两半——动作 / 表情 / 视线那几列进镜头行，最后一列「声音」进台词括号（口气 / 音量 / 停顿）；轻松场用「（轻松）」变体。括号里只留语言、音量、音色、距离和可执行声音词（轻声 / 顿一拍 / 带笑 / "啊？"的口气）。是翻译，不是删词：不可思议 → 镜头行「眉毛一抬，鼻子里笑出一口气」+ 括号「声音不高，"啊？"的口气」。

- 情绪名：悲伤、难过、伤心、委屈、愤怒、生气、恼火、不耐烦、紧张、害怕、恐惧、害羞、羞耻、羞愧、尴尬、不好意思、释然、爱意、决绝、犹豫、轻蔑、不屑、惊讶、惊喜、震惊、诧异、错愕、愕然、疲惫、试探、隐忍、骄傲、得意、专注、开心、高兴、兴奋、失望、心虚、愧疚、内疚、嫉妒、怀疑、狐疑、质疑、疑惑、困惑、不解、不信、不敢相信、难以置信、不可思议、感动、心疼、心动、深情、冷漠、厌恶、嫌弃、嘲讽、嘲弄、挑衅、慌张、慌乱、无辜、认真的、你认真的
- 意图 / 态度词：真诚、不推销、是真想知道、认出熟客、没有要拒绝的意思、不是玩笑、明知故问、故意、不服、服软、示好、讨好、拆穿、逗他、逗她、堵他、堵她
- 强情绪词（原 W40）：极度、狂热、疯狂、歇斯底里、惊骇、崩溃、暴怒、狂怒、癫狂、狂喜、发狂、眼睛发光、眼睛放光、瞳孔发光
- 幅度词（原 W49）：慌慌张张、慌着、手忙脚乱、吓了一跳、吓一跳、瞪大、瞪眼、睁圆、睁大、张大嘴、嘴张成、牙关一咬、咬牙切齿、狼狈、面无人色、脸色大变、整张脸皱
- 形态（脚本按模式判，不是词）：一脸 X、满脸 X、显得 X、看起来 X、觉得 X、感到 X

不在表里、也算 A 层词的：凡是回答"他心里怎么样"而不是"他哪里动了"的词。口气词（随口、懒洋洋、轻描淡写、平平的、干脆、带笑、轻快）是声音参数，留在括号里；"没办法的笑""压着笑"这类修饰可见部位的写法保留。


## 使用注意

- 同一部位的连续变化或有意持续允许保留，只审阅无意义复制。
- 每个可观察量都要有**主语与部位**："手指停住"优于"停住"；"左手"优于"手"（模型对左右的执行不稳，但写了比不写好 `[推论]`）。
- 时长要写数字："停 2 秒"优于"停了一会"。
- 强度与克制通过幅度、速度、呼吸、控制等具体关系表达；保留有执行意义的修饰词。
- "惊讶 / 恐惧 / 专注"行里的"动作停住、静止 1 s、盯住威胁源、声音突然安静"是悬疑线索 `[实测]`：轻松场里用"发现（轻松）"行，不借用这些写法；成片会按线索而不是按基调词读（S4 §4.4b，校验 W35）。
