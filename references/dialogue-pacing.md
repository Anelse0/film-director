# 对白场节奏与亮相：一句一切、逐镜变化、hero beat

S5 分镜与 S6 编译在处理**对白为主的场**（宣布、争执、两人对谈、群戏点名）和**人物亮相**时读本文件。它把一组反复出现的返工整理成默认做法：把整段发言装进一个 6–9 秒的镜头、连续三镜同一机位、人物亮相先看脸再知道是谁、亮相没有他人反应衬托。以下是本 skill 的本地写作约定 `[推论]`，不是模型能力断言；校验 W22 / W23 只提示不拦。

## 1. 一句一切（默认）

- 一句台词 = 一个切点。说话人镜头承载这一句，下一句切听者反应或换机位再回说话人。
- 对白镜默认 2–4s；一镜 ≥7s 只承载一句、或 ≥9s 承载对白时，要么拆镜，要么在 QA 写"有意长镜"的理由（镜内有走位 / 揭示 / 动作节拍才配得上长度）。
- 同一发言人连续说三句以上，中间至少插一个反应镜（听者 / 全场 / 物件），反应镜 1.5–2.5s，不停留。
- 旁白或画外音压在建立镜上不算长镜承载台词；W22 对旁白镜免检。

## 2. 逐镜变化

- 相邻镜头至少改变一项：景别 · 角度 · 运镜 · 拍谁。三镜连续标注完全相同触发 W23。
- 固定机位可以连续使用，但配合景别或角度变化；"中近景，正面，固定 ×3"是常见的偷懒形态。
- 竖屏 9:16：纵深优先（台在上、过道向下、人物由远及近），特写占竖幅中部，全景收人群与落位。

## 3. 台词预算先于分镜

按 `handoff-contract.md` §四估时：30s ≈ 5–7 句英语。先把台词窗口排进 clip，再决定镜数与镜长；超预算回传创作侧精简，不用长镜硬装、不擅自删词。目标时长小于上限时不要"排满 30s"，用户要求 15s 就做 15s。

## 4. 亮相与 hero beat

人物引荐 / 亮相的顺序规则见 `stage-5-directing-storyboard.md` 5.1d「引荐与亮相的顺序」：**介绍先行，特写作揭示落在名字或头衔上**，禁止"先看脸再报名"。在此之上，hero beat 的可执行模板：

| 节拍 | 镜头 | 可见证据 |
|---|---|---|
| 介绍 | 介绍者镜（画外报名 / 手势指引） | 名字 / 头衔落点；手势方向给出空间 |
| 他人反应 | 人群 / 对手 / 盟友反应镜 1–2s | 目光聚拢、让道、停杯、转头——**地位由他人的反应赋予** |
| 亮相 | 快推或跟移到人物，特写停 1–2s | 步速稳、下颌平、目光不躲、嘴角带笑 / 或沉静，按人设 |
| 落定 | 到位镜（与谁并肩、站哪） | 位置关系建立后续戏的空间 |

- 荷尔蒙 / 魅力不是形容词：写步幅、肩线、视线是否迎住、对他人目光的反应速度、手做什么。
- 人设区分场合：同一人物球场沉静、派对自信，以 `ip.md` 与造型参考图为准，不沿用上一场的动作习惯（帽檐、球衣号码等造型依赖动作在换装后失效）。
- hero 面部特写是用户常要保留的镜头；被要求"提速"时压缩人群走位与空走，不删特写停留。

## 4b. 从台词设计表到 Prompt 的映射（有表时不重推）

film-creative 交接的台词设计表（每句：目的动词 · 潜台词 · 说法 · 听者可见反应 · 递进 · 收尾）按下表进入 C 层与 D 层；缺表时在对话里按同一列补出并标"生产侧补写、待创作侧确认"。

| 设计表列 | 进入哪里 | 怎么写 |
|---|---|---|
| 说法（音量 / 语速 / 停顿 / 重音） | 每句台词后的〔说法〕 | 先写交付情绪一词，再写可观察量：慢、带钩、尾音微扬 |
| 目的动词 + 递进 | 每镜段首〔情绪〕 | 情绪词来自该句在阶梯上的位置；同镜多句取主导句 |
| 递进（全场阶梯） | 【整体情绪弧线】 | 每角色一行：起态（镜X，可见落点）→ … → 末态；落点只写眼神 / 下颌 / 身姿 / 口型 / 节奏 / 走位 |
| 听者可见反应 | 台词句末"此时 B 闭着嘴，…"与反应镜 | 反应镜 1.5–2.5s，不停留 |
| 目的动词 | S4 有序表演块 | 动词决定手 / 视线 / 距离的变化（求→前倾伸手；挡→抬手不看） |
| 收尾标记 | 末镜结束状态 | 收尾句所在镜给 1s 停留或切黑，硬切则写明 |

表里的**台词逐字不动**（硬规则 7）；只有〔说法〕〔情绪〕与表演正文是本 skill 新增的外化信息。

## 5. 修订交付

- 每次修订交付完整 Prompt 全文（代码块）+ 校验摘要，不给 diff。
- 修订只动被批评的镜及其直接衔接镜；未被批评的镜保留原文，避免"顺手重排"引入新的漂移。

## 6. 与校验的关系

`validate_prompt.py`：W22 含台词长镜、W23 三镜同标注、W04 单镜 <1.5s 或 >8 镜且平均镜长 <2s（按 2–4s 一句一切切出的 9–12 镜不触发）、W05 台词接近窗口、W17 同一运镜连续 3 镜。它们都是审阅提示：一句一切与逐镜变化是约定，不是模型限制；有意长镜与有意重复要留下理由，不要为消警告删台词或删细节。
