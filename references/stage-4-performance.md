# S4 表演外化

输入可以是剧本页，也可以是直接表演需求。先读 `emotion-performance.md` 并按需检索完整条目，产出有序表演块（C 层）及内部核对信息。写回剧本页对应字段，或直接交付测试片段；本阶段不停靠。无台词测试跳过语音信息和语域选择。

## 4.0 承接人物声音，只取执行需要的信息

人物语言的开发（词汇、句法、回避方式、口头禅）属创意侧（film-creative 或用户）。本阶段不重新规定人物怎么说话，只从剧本页、`ip.md` 或用户说明里取**模型执行需要的可观察语音信息**，缺什么补什么，不要求先填表：

```
语音：语速 / 音量 / 方言或口音 / 音色描述（年龄段、沙哑或清亮、音高）
当前说法：本句已选定的重音、停顿、呼吸或音高变化（只写确需呈现的）
用户锁定：逐字台词 / 口音 / 既定表演，不自动修改
```

倾听可以保持不动，也可以发生变化；不为表现"听见了"让每句都触发新动作。共用的日常短句不必刻意独特。

## 4.0b 语域

台词检查属创意侧，默认正剧语域。按创意侧确认的基调选语域，它只影响表演与镜头的选择空间，不改写台词：

| 语域 | 表演与镜头上的差异 | 透镜 |
|---|---|---|
| 正剧（默认） | 潜台词可选；表演按选定条目 | — |
| 冷面 | 内容与平常语气可产生反差；停顿和视线按人物决定 | L7 |
| 反讽 | 可来自语境、信息差或言行反差；不要求动作反说，也不规定灾难必须短句 | L8 |
| 喜剧 | 可用铺垫 / 落差 / 加码，也可让语言或表演本身成立；打断不是必需 | L9 |
| 高语域 | 修辞、排比、长句须符合人物；可以连续表达，不强加日常动作 | — |

## 4.0c 意图动词留在 A 层，不映射成固定动作（L12）

给"演员"沟通意图时可用及物动词（恳求她、审问他、无视他）。它们留在 A 层，帮助选择表演与机位；**不建立"恳求 = 前倾 + 手伸出"之类映射**——同一意图可以有不同表演，同一动作也可以出于不同意图（Weston《Directing Actors》给演员动词、不给结果的本意即在此，见 `director-grammar.md` §3.6）。C 层承接本场已经选择的可见可听表现，允许持续状态和无新增肢体动作；表演测试不强制策略列。

## 4.4 表演外化

强度、克制与动作幅度分别判断；峰值由用户目标与选定条目决定，可持续爆发或受控。完整规则统一在 `emotion-performance.md`，不以场景参数覆盖原文。

抽象情绪由可观察证据支持，按需选择以下通道；不设最少通道数。库外写法可查 `externalization-lexicon.md`：

| 通道 | 写什么 |
|---|---|
| 动作 | 手在干什么、脚步、身体重心、与物件的接触 |
| 表情 | 具体部位：眉、眼睑、嘴角、下颌、吞咽；描述性语句优先、少用成语 `[官方建议]` |
| 视线 | 看对方 / 看物件 / 看地 / 看窗外 / 避开后又看回 |
| 空间 | 靠近 / 后退 / 侧身 / 背对 / 坐下站起；距离数字化（一步、一臂、半米） |
| 节奏 | 停顿秒数、动作快慢、说话前的延迟 |
| 摄影（S5 可见性条件，不计表演通道） | 景别、遮挡、焦点是否能呈现关键细节；机位与运镜由 S5 按 `director-grammar.md` 决定，不是情绪的伴随物 |
| 声音 | 呼吸、吞咽、物件碰撞、环境音突然安静 |

**表演编排**：按内容划分持续或变化的节拍；需要弧线时从起态通向目标高光与末态，不固定四拍。同步与先后关系保留在完整正文，末态不强制静止或平静。

**每镜负载**：官方建议动作"概括优先、记忆点细写、不重复"，时段内容过多会被过度剪切或遗漏 `[官方]`。外化时先定本镜的一个主要事件与至多一个记忆点细节，其余用概括句；部位级细节只给高光节拍，不给每一秒。概括句管的是无关动作与背景活动；表演要素（眼神落点、心理拍子、呼吸、小动作、语气）每镜都写，不被"概括"吞掉（§4.4a）。

**听与回应**：听者可以变化，也可以持续控制住反应；不强迫每句配新动作，也不为每句台词补一个听者反应。

## 4.4a 表演开发清单（S4 先写满，再翻译）

Prompt 变短不能以表演变薄为代价：篇幅从元数据、复述与重复里省（S6 §6.2、W38 的删减顺序不含表演），不从表演里省。S4 的产物是**设计稿**，每个角色每场戏把下面几项写满，放在剧本页 / 分镜卡的有序表演块里（C 层，不逐字进 Prompt）：

| 项 | 写什么 | 例（EP05 酒吧） |
|---|---|---|
| 状态基线或弧线 | 全条一种状态，或从哪到哪 | 放松、带一点笑意，表情不随对话变化 |
| 每镜一个心理拍子 | 这一镜他内心发生了什么（不是情绪名） | 第三问落在身后：他决定不答 |
| 控制证据 | 压着的东西怎么看出来 | 嘴角压着笑；步子不停 |
| 高光与末态 | 必须看见的变化；结束时还在做什么 | 嚼着薯条抬头看一眼；结束在瞥她的笑 |
| 眼神落点 | 每镜看谁 / 看什么（不放空、不看镜头） | 手上的活 → Zadie → 画左的 Rhett |
| 呼吸 | 看得见的呼吸怎么写 | 胸口随呼吸轻轻起伏 |
| 自发小动作 | 每镜一个、幅度小 | 搅酒 / 拿薯条 / 滤酒 / 推杯 |
| 语气（声音） | 每句台词的音量、语速、音色、口气——写进冒号前的括号（§4.5） | 声音不高，随口 |
| 态度的可见拍子 | 每镜每个括号里带意图词的说话人（真诚、认出熟客、不推销、是真想知道——这句话对对方做什么；轻松 / 随口 / 带笑是口气，留在括号里即可）至少一个可执行的拍子，在台词窗口内；载体由导演设计定，不限于眼神（1.7.1）：眼神 / 脸、手与身体、声音与停顿、与对方的互动，任一种 | 开口前眼睛先亮一下再开口；手指在台面上点一下；说得慢半拍、句尾不扬；把酒单推过去一点 |
| 取材 | 情绪库条目 id 与模式（raw / adapt / blend）或 free | 21 害羞 adapt |

这张表是深度的来源：S6 不能添加 S4 没开发的东西，也不能删 S4 开发了的东西，只能翻译（§4.4c）。

## 4.4b 基调由线索决定，不由基调词决定 `[实测]`

模型读的是可见线索，不是"轻松"两个字。下面几种写法是悬疑 / 惊悚的语法，放进轻松场里，成片就"像惊悚"（offset EP05 场 03 clip02 v1：两个同事在吧台边聊替班，常客走进来；`validation-log.md` 2026-10-13）：

| 悬疑线索 | 它在说什么 | 轻松场的写法 |
|---|---|---|
| 停住：拿着薯条的手停在半路、动作僵住 | 被吓到 / 察觉威胁 | 继续做：嚼、搅、手上的活不停 |
| 硬切固定正面近景，人物居中，慢慢转头看向画外走来的人 | "有东西来了" | 不转头，或抬头、下巴放平，顺着对方的方向看一眼；镜头轻轻跟一点 |
| 盯着一个方向 + 压低声音 | "小心" | 压着笑、眼睛亮起来、扬下巴示意；声音放低但轻快、带笑意 |
| 来人长焦朝镜头直走，没写状态 | 逼近 / 跟踪 | 写他手里、步子、肩膀、神情：边走边看手机、一手插兜、肩膀放松、步子随意 |
| 低着头、眼睛抬起来看镜头；头不动只转眼珠斜看 | 阴狠的凝视（Kubrick stare）/ 怀疑的侧目 | 抬头、下巴放平，视线落在对方所在的画面方向；保持一个小的连续动作（嚼） |

规则：轻松 / 温暖的日常场，每个反应镜都带一个"日常证据"（手上的活不停、嚼、笑意、聊），来人必须有状态，环境声照常；【贯穿要求】写一句基调（"整条是轻松、温暖的上班日常，两个好朋友之间的玩笑和八卦，光、声音和节奏从头到尾一样"）。词典里"惊讶 / 恐惧 / 专注"行的"动作停住、静止 1 s、盯住、声音突然安静"就是这些线索，只在要那种读法时用（`externalization-lexicon.md`「发现（轻松）」行是对应的轻松写法）。停住与冷面是喜剧（G5）和悬疑（G2）各自的手法：声明了那两类基调，校验 W35 只给 INFO；声明了轻松就逐镜报，没声明基调时线索成簇才报。

## 4.4c 翻译成模型能执行的描述（S5 分镜卡的"表演翻译"行，S6 原样承接）

设计稿写满之后，每一镜把它翻成模型看得见的写法。翻译是换写法，不是删内容——每个要素都要有去处：

| S4 要素 | 翻成 | 本镜看不见时的去处 |
|---|---|---|
| 心理拍子 | 一句描述性的话：眼神先（落点 + 变化），再一两个部位或一个手 / 身体动作，按先后写 | 下一镜的第一拍，或画外声音（呼吸、一声轻哼） |
| 控制证据 | 被压住的部位怎么动一下又收回（嘴角、下颌、手指） | 手或肩的近景插入 |
| 高光 | 峰值镜里按先后写完整，动作在镜内发生 | 不允许丢；回 S5 换景别或加时 |
| 眼神落点 | 每镜一句"视线：看着 X（画左 / 画右 / 镜头后方）" | 画外时写"看向画外的 X" |
| 呼吸 | "胸口随呼吸轻轻起伏"一句，进【贯穿要求】表演桶 | 声音：一次轻呼气 |
| 自发小动作 | 写进本镜主要事件或记忆点 | 下一镜 |
| 语气（声音） | 写进台词冒号前的括号（§4.5）：音量 / 语速 / 音色 / 口气 | — |
| 意图 / 潜台词 | 开口前或说话中的一拍，载体按导演设计任选其一——眼神 / 脸、手与身体、声音与停顿、对对方的动作——写在镜头行里紧挨台词，在台词窗口内发生、不另占秒数（`duration-rhythm.md` §三 反应行）；括号里写 轻声 / 放慢 / 顿一拍 这类可执行的声音词也算载体，口气词只是颜色；括号里的情绪 / 口气词照官方格式「角色台词（情绪）：内容」`[官方]` 保留 | 说话人画外、背对或在后景虚着时落在听者的反应里；中景以上的镜用身体动作 / 互动 / 停顿写在本镜，或落在下一个近景的第一拍 |

写法规则（官方 FAQ `[官方]` + 本项目实测 `[实测]`）：
1. 每个拍子一句话，眼神先；一镜有几个可见的拍子（由 S4 的节拍数决定）就写几句，不合并、不删。官方范例的部位细节一镜一处（"眼含不舍""瞳孔骤缩泪滑落""嘴唇闭合"），说的是一拍不堆整列部位，不是一镜只能一拍。
2. 一两个部位，按先后（"先…再…"），不写五个部位同时发生；`externalization-lexicon.md` 与情绪库是挑部位的字典，不整行粘贴。
3. 保留执行词（逐渐、缓慢、轻轻、一下），去掉强度标签（极度、狂热、疯狂、崩溃）——官方 FAQ：它们会被渲染成眼睛发光、表情夸张（校验 W40）；要强就写幅度与时长。
4. 突变只给峰值拍子，并写完整（起 → 变 → 停在哪）；其余用延续词（还在、继续、仍）。
5. 强情绪镜在【总述】或【贯穿要求】加「人物为正常人眼，不发光」`[官方]`。
6. 轻松场按 §4.4b 的对照表，不借悬疑线索。
7. 台词括号 = 语言 + 声音（音量 / 语速 / 音色 / 口气）+ 情绪或口气词（官方格式「角色台词（情绪）：内容」`[官方]`：轻松 / 随口 / 带笑 / 语气平常都可以写，不删）。意图词是潜台词——这句话对对方做什么（真诚、不推销、认出熟客、是真想知道、没有要拒绝的意思、让他知道这不是玩笑）——它不是去处：S4 为每个意图定一个可见载体，S6 把它写成可执行的表演描述。载体由导演设计定，不限于眼神（1.7.1，用户决定）：眼神 / 脸（开口前眼睛先亮一下再开口；开口时眼睛留在对方脸上，嘴角带着笑）、手与身体（手指在台面上点一下；肩膀松下来；偏过头）、声音与停顿（说得慢半拍；句尾顿一拍再接；括号里写 轻声 / 放慢 / 顿一拍 这类可执行的声音词也算，轻松 / 随口 这类口气词只是颜色）、与对方的互动（把酒单推过去一点；递还手机时补一句；冲他勾一下手指）；近景 / 特写 / 中近景里同镜每个带意图词的说话人至少一个，写在镜头行里紧挨台词，在台词窗口内发生、不另占秒数、不写说完后的停留（`duration-rhythm.md` §八）；拍子的幅度按人物的状态基线（§4.4a）；分镜卡写"真诚放在台词语气里"不算翻译（S7 §7.1 核对分镜卡，W44 核对 Prompt）。说话人画外、背对或在后景虚着时拍子落在听者的反应或下一镜第一拍；中景以上不写部位级表情，意图用身体动作 / 互动 / 停顿写在本镜，或留给下一个近景。动作（抬眼、看向、笑一下、抬杯、点头）不写进括号：括号是语气位，动作写进镜头行（开口前或开口时，由导演定）才是本表的去处，写进去后它就是这句意图的拍子 `[推论]`（触发案例 offset EP05 s03 clip03 v1：括号里堆了意图与动作；括号内动作是否被执行 `[未验证]`，`validation-log.md` 待验证 19）。校验 W44（近景以内同镜没有这个人的任何可执行拍子才报，一镜一条，不删括号里的词）。

去处表写在分镜卡的"表演翻译"行（`templates/shot-card.md`），S7 用它核对翻译完整性（`stage-7` §7.1）。表演测试（performance / raw）不走这一步，原文保真。

## 4.5 Seedance 2.5 对台词的执行约束

技术执行与创作语感分开：估时取显式语速，不由情绪推算。台词给独立时间窗，和表演可以同步，见 `production-workflow.md`。

| 约束 | 规则 | 标签 |
|---|---|---|
| 逐字 | 引号内写期望逐字输出的文字；不在引号外写"说了一句安慰的话" | `[官方示例]` API 文档建议对话置于双引号 |
| 说话人 | `台词（角色，a-bs，语言，语气 / 音量 / 语速）："…"` 或 `台词 (角色): "…"`；语气、音量、语速都写在冒号前的同一个括号里，引号后只接「；此时 B 闭着嘴」——不写语气括号、不复述台词片段（官方 FAQ 字幕约束不生效：台词后复述词语并追加语气 / 表情 / 动作描述会诱发字幕，官方改法「角色台词（情绪）：内容」分行；校验 W36）；官方另有 `{}` 标台词、`()` 音乐、`<>` 音效、`【】` 字幕的符号规范，可选用但整篇一致 | `[官方]` |
| 语言 | Prompt 里点明语言 / 口音（"中文普通话"、"东北口音"、"英语"）；非中文台词在台词前标语言；一段台词内不中英混用 | `[官方]` |
| 括号里的意图与动作 | 括号可写情绪 / 口气词（官方格式），但意图词不是去处：近景以内同镜要有这个人的一个可执行拍子（眼神 / 身体 / 声音与停顿 / 互动，载体由导演定；括号里的可执行声音词也算）；动作不进括号，写进镜头行（§4.4c 第 7 条，W44） | `[推论]` |
| 时间窗与长度 | 每句给起止秒；长度按 `seedance-2.5-capabilities.md` §7 预算：英文默认 2.5 词/s、中文 4 字/s、占比 ≤2/3（密对白 3/4）；快慢语速显式写在说法里并可在 E 层覆盖估时参数；强度与外放不自动提速 | `[一手]` 语音学标准 + `[推论]` |
| 嘴部状态 | 非说话时段写"闭着嘴 / 抿嘴 / 嘴微张但不出声" | `[第三方]` |
| 密度 | 按语速与时间窗估算，为必要反应留时，不设通用句数或固定间隔；第三方经验 5–10 词一句、一镜两句以内最稳 | `[推论]` + `[第三方]` |
| 多人 | 同框同时说话是需验证的风险（2.0 报告与 2.5 博客均承认多主体互动不稳）。给各说话人实际时间窗、标出重叠；双人镜头仍可用，说话者近景 / 越肩 / 分轨 / 改轮流是可协商方案，不因执行方便擅改锁定对白、重叠或镜头 | `[官方]` + `[推论]` |
| 口型语言 | 中文最稳，英文其次，日 / 韩长句易漂；正面或 3/4 侧脸的中近景口型比侧脸稳 | `[第三方]` |
| 画外音 | 允许，写"画外传来 A 的声音："…""；画面里的人不动嘴 | `[推论]` |
| 音色 | 有音频参考时"图 1 使用音频 1 音色"；无参考时用可观察描述（年龄段、沙哑 / 清亮、音高）；多音字 / 生僻字换同音常用字 | `[官方]` |
