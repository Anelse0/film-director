# 镜头语汇（中英对照，Seedance 写法）

`[官方]`：通识术语与热门运镜可直接写；小众术语用"术语 + 描述性解释"。下表"直接写"列可原样进 Prompt；"需解释"列必须附解释。术语只是拼写，**什么时候用哪个**看 `director-grammar.md`。官方教程范例给出的完整写法是 **景别 + 机位 / 角度 + 运镜方式 + 速度 + 质感**（"低角度大远景定场，斯坦尼康在黄金夕照与海雾中缓缓推进"），本表按这五项组织。

## 景别

| 中文 | 英文 | 直接写 | 用途（§一） |
|---|---|---|---|
| 大远景 / 大全景 | extreme wide shot | ✅ | 尺度、渺小、地理 |
| 全景 | wide shot / full shot | ✅ | 空间关系、走位 |
| 中景 | medium shot | ✅ | 关系镜、手部动作 |
| 中近景 | medium close-up | ✅ | 台词与口型最稳的景别 |
| 近景 | close-up | ✅ | 情绪、部位 |
| 特写 | close-up（面部特写 face close-up） | ✅ | 此刻最重要的东西 |
| 大特写 | extreme close-up（眼睛 / 手部） | ✅ | 单一部位或物件 |
| 插入镜头 | insert | ✅（写"插入镜头，固定机位，只拍 X"） | 转折点物件 |

## 机高与角度

| 中文 | 英文 | 直接写 | 含义 |
|---|---|---|---|
| 平视 | eye level | ✅ | 对等 |
| 低角度仰拍 / 机位低于视线 | low angle | ✅ | 威压、英雄 |
| 高角度俯拍 / 机位高于视线 | high angle | ✅ | 审判、渺小 |
| 顶视 / 垂直俯拍 | top-down / overhead | ✅ | 图案、上帝视角 |
| 第一人称 / 主观视角 | POV / first person | ✅ | 观众成为人物 |
| 越肩 | over-the-shoulder | ✅（写清谁的肩） | 关系镜 |
| 3/4 侧 | three-quarter | ✅（官方范例用法） | 口型可见且有立体感 |
| 荷兰角 / 倾斜 | dutch angle | ⚠️ 加"画面微微倾斜" | 失衡 |
| 一点透视 | one-point perspective | ⚠️ 加"消失点在画面正中，走廊两侧对称" | 秩序、威压、冷面 |

## 焦距与景深（写可见结果，不写毫米数）`[推论]`

| 想要的效果 | 写法 | 不要写 |
|---|---|---|
| 广角：空间感、人和环境绑在一起、贴脸略变形 | "广角镜头，机位贴近人物，背景的整个房间都在画内，脸部略有透视变形" | "24mm" |
| 长焦：压缩、隔离、偷窥 | "长焦压缩，背景虚化成色块，人物像被从远处窥视" | "135mm" |
| 浅景深 | "浅景深，只有面部清晰，背景柔和虚化" | — |
| 深焦 | "前景的手与后景的门同时清晰" | "deep focus"（可写但加解释） |
| 移焦 | ❌ 需解释："移焦，画面焦点平滑转变，前景清晰的 X 变模糊，背景的 Y 由模糊变清晰" `[官方示例]` | 单写"rack focus" |
| 变形宽银幕 | ⚠️ "横向椭圆光斑、画面略宽的电影镜头质感" | "anamorphic" 单写 |
| 微距 | ✅ "微距特写，蜜蜂腿部的花粉颗粒清晰" `[官方示例]` | — |

## 运镜（每条写：动机 → 动作 → 速度 → 终点）

| 中文 | 英文 | 直接写 | 终点写法示例 |
|---|---|---|---|
| 推 | push in / dolly in | ✅ | "用 3 秒缓推到面部近景，止于眼睛在画面上三分之一" |
| 拉 | pull back / dolly out | ✅ | "缓拉到全景，止于她一个人在走廊中央" |
| 摇（左右） | pan | ✅ | "向右缓摇 2 秒，止于两人同框" |
| 上摇 / 下摇 | tilt up / tilt down | ✅ | "从手上摇到脸，止于近景" |
| 横移 | truck / lateral move | ✅ | "向左横移，保持她在画面右三分之一" |
| 跟拍 | tracking / follow | ✅ | "跟拍至门前，人物停镜头停" |
| 反向跟拍 | reverse tracking | ⚠️ "人物朝镜头走来，镜头以同速后退" | "止于她停在门口的中景" |
| 环绕 | orbit / arc | ✅ | "顺时针环绕四分之一圈，从背影到正脸" |
| 升 / 降 | crane up / down | ✅ | "升到俯视全景，止于两人成为两个点" |
| 俯冲 | dive | ✅ | — |
| 手持 | handheld | ✅（写幅度："轻微 / 明显 / 富攻击性的手持"，官方范例用法） | — |
| 斯坦尼康 / 平稳跟拍 | steadicam | ✅（官方范例直接用"斯坦尼康……缓缓推进"）；保守写"平稳跟拍" | — |
| 固定机位 | locked / static | ✅ | "全程不动" |
| 一镜到底 | one continuous take | ✅ | 写清中途的构图变化与秒数 |
| 希区柯克变焦 | dolly zoom | ✅（热门） | "人物大小不变、背景被拉远" |
| 航拍 | aerial / drone | ✅ | — |
| FPV | FPV | ✅ | — |
| 子弹时间 | bullet time | ✅ | — |
| 回弹变速 | speed ramp | ✅ | "第 5 秒动作放慢到四分之一速，第 6 秒恢复" |
| 甩镜 | whip pan | ⚠️ "快速横摇，画面短暂拖影" | "止于门口的中景" |
| 急推变焦 | crash zoom | ⚠️ "极快推近到脸，半秒内完成" | — |
| 变焦 | zoom | ✅ | 与推区分：变焦背景关系不变 |

速度用秒数（"3 秒缓推"）或官方范例的副词（"缓缓 / 快速 / 猛推"）；不用时间戳控频次 `[官方]`。

## 构图位置（写给模型）

- "人物在画面左三分之一 / 右三分之一 / 中心 / 中轴线上"
- "人物看向画左，左侧留出视线空间" / "背后留空，观众看见她看不见的门"
- "前景是 A 的后背肩膀，占画面左三分之一，焦点在 B 的面部"
- "人物占画面高度约一半 / 十分之一（大远景）"
- "两人并排面向镜头，与后墙平行，等距"（平面调度）
- "A 在前景左侧背对镜头，B 在后景门口，两人之间是整张餐桌"（纵深调度）
- "保持 X 始终在画面内"
- 对称："消失点在画面正中，左右对称"

## 转场（写触发时间 + 方式）`[官方]`

- "第 5s 快速向左横移转场（向左擦除＋自然叠化）"
- "第 12s 硬切到镜头 4" / 镜头末尾写"硬切"（官方范例用法）
- "第 20s 画面渐黑 1 秒"
- 匹配转场（Wright）："第 8 秒他关门的动作硬切到下一镜她开门的动作，门的位置对齐"

## 光

写光源 + 方向 + 质地 + 动机：

- "唯一光源是画面左侧的窗，午后侧光，柔和，她面部朝窗的一侧亮"
- "头顶一盏钨丝灯，硬光，人物面部一半在阴影里"
- "夜，路灯从画面右上方打下来，冷白；室内只有电视的蓝光闪动"
- 高调 / 低调："整体明亮均匀，几乎没有阴影" / "大面积黑，只有脸的一侧受光"

避免：只写"电影级光影"；无理由的"黄金时刻逆光"（W15）。

## 声音标记（官方符号规范，可选）`[官方]`

台词 `{}`、音乐 `()`、音效 `<>`、字幕 `【】`。本 Skill 默认用 `台词（角色，a-bs，语言）："…"`；选用符号规范时整篇一致，不混用。

## 禁用空泛词（校验脚本会警告）

电影感、唯美、震撼、史诗感、高级感、氛围感、大片、cinematic、stunning、epic、beautiful、premium、dramatic（作为形容词单独出现时）。风格要写可见的东西：媒介（35mm 胶片 / 手机实拍 / 3D 动画）、光、色调、质地、颗粒、景深。
